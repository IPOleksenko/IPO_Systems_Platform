### How Assembly Dispatches System Calls:
1. `push msg`: Pushes the address of the string buffer onto the stack.
2. `mov ecx, esp`: Sets `ECX` to point to the arguments array on the stack.
3. `mov eax, 0x1001`: Sets `EAX` to the system call number (`IPO_SYSCALL_PRINT`).
4. `mov ebx, 1`: Sets `EBX` to the argument count (`1`).
5. `int 0x80`: Triggers the software interrupt trap gate, executing the kernel dispatcher.

## 🔨 3. Compiling the C Application

To compile `main.c`, we need the startup stub `entry.s` and linker script `app.ld`:

```bash
# Варіант A: Стандартна система збирання IPO_OS_Software
# Розмістіть вихідний код у applications/hello/hello.c та виконайте:
make applications

# Варіант B: Пряма компіляція та компонування через GCC
# 1. Компіляція вихідного коду C із заголовками IPO_OS_Software
gcc -m32 -O2 -ffreestanding -fno-pie -fno-pic -nostdlib -Iinclude -c main.c -o main.o

# 2. Асемблювання точки входу entry.s
gcc -m32 -c applications/entry.s -o entry.o

# 3. Лінкування зі скриптом app.ld та бібліотеками рантайму (libc, libapp)
gcc -m32 -no-pie -Wl,-T,applications/app.ld entry.o main.o \
    -Wl,--start-group build/lib/libc.a build/lib/libm.a build/lib/libapp.a -lgcc -Wl,--end-group \
    -nostdlib -nostartfiles -o hello.bin
```

---

## 🚀 4. Deploying to the Storage Disk

Copy `hello.bin` into the `/applications` directory of your IPO_OS disk using `tools/disk_editor.py`:

```bash
python3 tools/disk_editor.py -i /path/to/disk.img put hello.bin /applications/hello.bin
```

---

## 🖥️ 5. Running in the Shell

Start IPO_OS in QEMU:
```bash
make run
```

At the interactive prompt (`> `), invoke your binary:
```
> /applications/hello.bin
Hello, World!
> /applications/hello.bin test_arg1 test_arg2
Hello, test_arg1
Hello, test_arg2
> 
```
