# Обзор программной экосистемы IPO_OS_Software

**IPO_OS_Software** — это официальный репозиторий пользовательского окружения, стандартных библиотек, инструментария разработчика и прикладных программ для операционной системы **[IPO_OS](https://github.com/IPOleksenko/IPO_OS)**. Он предоставляет полноценную среду исполнения C/C++, 3D-графику, оконные интерфейсы, внутрисистемные компиляторы, интерпретаторы, портированные игры и дисковые утилиты.

<Callout type="tip" title="Модульное разделение проектов">
Репозиторий `IPO_OS` сфокусирован исключительно на архитектуре ядра, низкоуровневых драйверах железа, управлении памятью и планировщике процессов. Все пользовательские программы, стандартные библиотеки, компиляторы и средства формирования дисков вынесены в **IPO_OS_Software**.
</Callout>

## 🏛️ Архитектура программной экосистемы

Репозиторий `IPO_OS_Software` структурирован по ключевым функциональным подсистемам:

1. **Библиотеки времени исполнения (`lib/`):**
   - **`libc.a`:** Реализация стандарта C99 (динамическая память через `sbrk`, форматированный ввод-вывод stdio, строки, POSIX-файлы, сокеты, сигналы и динамическая загрузка модулей `dlopen`/`dlsym`).
   - **`libm.a`:** Математическая библиотека с поддержкой тригонометрии, логарифмов и операций с плавающей точкой.
   - **`libstdc++.a`:** Базовый рантайм C++ (`new`/`delete`, RTTI, обработка исключений).
   - **`libapp.a`:** Системные API для оконного менеджера (WM), переключения экранных шрифтов, обработки клавиатуры/мыши и вывода звука.
   - **TinyGL:** Встроенный 3D-растеризатор, совместимый с OpenGL 1.1 (отсечение граней, стек матриц, освещение).
   - **Модули запуска CRT (`crt0.o`, `crti.o`, `crtn.o`):** Стандартные точки входа для бинарников и динамических библиотек.

2. **Заголовочные файлы (`include/`):**
   - Полный набор стандартных заголовков C99, POSIX, TinyGL и системных структур (`stdio.h`, `stdlib.h`, `unistd.h`, `GL/gl.h`, `wm.h`, `syscall.h`).

3. **Внутрисистемный инструментарий разработчика (`build/toolchain/`):**
   - **TinyCC (`tcc`):** Быстрый C99-компилятор, работающий прямо внутри запущенной IPO_OS.
   - **Lua 5.3 (`lua`, `luac`):** Скриптовый интерпретатор и компилятор байткода.
   - **MicroPython (`python.elf`):** Компактный рантайм Python 3 для скриптов и системной автоматизации.
   - **NASM:** 32-битный x86-ассемблер, компилирующий код непосредственно в среде ОС.
   - **GNU Binutils (`gcc`, `g++`, `as`, `ld`, `ar`, `ranlib`, `objcopy`, `objdump`, `readelf`, `nm`, `strip`).

4. **Приложения и утилиты (`applications/`):**
   - **DOOM (`doom.bin`):** Порт официального `linuxdoom-1.10`, работающий на «голом железе» в разрешении 320x200 со звуком Sound Blaster 16 и 60 FPS.
   - **Текстовый редактор (`edit.bin`):** Интерактивный редактор с отображением синтаксиса.
   - **3D-демонстрации (`gl_gears.bin`, `gl_cube.bin`, `gl_teapot.bin`):** Графические тесты TinyGL.
   - **Сетевые клиенты и серверы (`hosting_server.bin`, `hosting_client.bin`, `ping.bin`):** Веб-сервер HTTP, клиент и диагностика ICMP.
   - **Консольные утилиты:** `echo.bin` выводит переданные аргументы; `hello.bin` — пример Hello World; `player.bin` воспроизводит мультимедиа; `setfont.bin` показывает доступные шрифты консоли и переключает их; `term_ctl.bin` передаёт текст в терминал, при необходимости выполняя команду.

## 💾 Модели распространения ПО

Для удобства пользователей и разработчиков предусмотрено два официальных варианта поставки:

### Вариант 1: Отдельно чистый диск + отдельно скомпилированные приложения
- **`disk-clean.img`:** Чистый 512 МБ образ диска, размеченный файловой системой `IPO_FS`. На нём нет предустановленных программ — это чистый накопитель для ваших файлов и проектов.
- **`applications.zip`:** Архив, содержащий **только готовые скомпилированные файлы** (без исходников и сборочных скриптов):
  - Бинарники приложений (`applications/*.bin` + `doom1.wad`)
  - Исполняемые файлы тулчейна (`toolchain/*.elf`)
  - Статические библиотеки и линкерный скрипт (`lib/*.a`, `lib/*.o`, `lib/linker.ld`)
  - Заголовочные файлы SDK (`include/`)
  - Базы шрифтов (`fonts/*.fnt`)

### Вариант 2: Диск с предустановленными приложениями
- **`disk-installed.img`:** Полностью готовый к работе 512 МБ образ диска, на который уже развёрнуты все приложения, DOOM, тулчейн, библиотеки и шрифты в каталогах `/applications`, `/lib`, `/include` и `/fonts`. Достаточно подключить его к виртуальной машине QEMU или записать на реальный диск.

## 🛠️ Утилиты управления дисками

Репозиторий `IPO_OS_Software` содержит готовые автономные инструменты для работы с дисками:

- **`tools/load_applications.py`:** Автоматизирует копирование скомпилированных файлов на раздел диска с IPO_FS.
- **`tools/disk_editor.py`:** Полнофункциональный консольный файловый менеджер для чтения, записи, извлечения и удаления файлов внутри образов дисков IPO_FS.
- **`load_to_disk.sh`:** Удобный скрипт-обёртка для форматирования и наполнения любого целевого диска одной командой.
