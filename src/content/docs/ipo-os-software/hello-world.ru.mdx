### Механизм передачи параметров в системный вызов:
1. `push msg`: Помещает адрес строки в стек.
2. `mov ecx, esp`: Устанавливает регистр `ECX` на указатель массива аргументов `argv` в стеке.
3. `mov eax, 0x1001`: Помещает в `EAX` номер системного вызова (`IPO_SYSCALL_PRINT`).
4. `mov ebx, 1`: Помещает в `EBX` количество аргументов (`argc = 1`).
5. `int 0x80`: Вызывает системный шлюз ядра в Ring 0.

## 🔨 3. Компиляция и компоновка приложения на C

Для сборки программы необходимы ассемблерная заглушка точки входа `entry.s`, реализация вывода `printf.c` и скрипт компоновщика `app.ld`:

```bash
# Вариант A: Стандартная система сборки IPO_OS_Software
# Поместите исходный код в applications/hello/hello.c и выполните:
make applications

# Вариант B: Прямая компиляция и компоновка через GCC
# 1. Компиляция исходного кода C с заголовками IPO_OS_Software
gcc -m32 -O2 -ffreestanding -fno-pie -fno-pic -nostdlib -Iinclude -c main.c -o main.o

# 2. Ассемблирование точки входа entry.s
gcc -m32 -c applications/entry.s -o entry.o

# 3. Линковка со скриптом app.ld и библиотеками рантайма (libc, libapp)
gcc -m32 -no-pie -Wl,-T,applications/app.ld entry.o main.o \
    -Wl,--start-group build/lib/libc.a build/lib/libm.a build/lib/libapp.a -lgcc -Wl,--end-group \
    -nostdlib -nostartfiles -o hello.bin
```

---

## 🚀 4. Размещение на диске операционной системы

Скопируйте полученный файл `hello.bin` в каталог `/applications` виртуального диска IPO_OS с помощью утилиты `tools/disk_editor.py`:

```bash
python3 tools/disk_editor.py -i /path/to/disk.img put hello.bin /applications/hello.bin
```

---

## 🖥️ 5. Запуск в командной строке

Запустите операционную систему в QEMU:
```bash
make run
```

В интерактивном терминале ядра (`> `) запустите собранную программу:
```
> /applications/hello.bin
Hello, World!
> /applications/hello.bin test_arg1 test_arg2
Hello, test_arg1
Hello, test_arg2
> 
```
