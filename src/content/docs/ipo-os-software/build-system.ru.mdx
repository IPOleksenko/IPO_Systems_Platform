# Система сборки и утилиты развертывания

Проект **IPO_OS_Software** содержит независимую экосистему пользовательских библиотек, компиляторов, утилит и демонстрационных программ. Сборка управляется модульной системой GNU Make и специализированными инструментами для создания и наполнения дисковых образов с файловой системой **IPO_FS**.

---

## 🔨 Структура и цели Makefile

Сборочный конвейер разделен на модульные правила в каталоге `mk/`:
- `mk/config.mk` — Определение компиляторов, флагов (`-m32`, `-ffreestanding`) и путей.
- `mk/lib.mk` — Сборка стандартных библиотек (`libc.a`, `libm.a`, `libstdc++.a`, `libapp.a`, `libapp_api.a`, `crt0.o`).
- `mk/applications.mk` — Сборка всех прикладных программ (DOOM, TinyCC, MicroPython, Lua, NASM, редактор, 3D-демо).
- `mk/toolchain.mk` — Подготовка встроенных инструментов разработки.
- `mk/disk.mk` — Операции с дисковыми образами (создание, форматирование, установка ПО).
- `mk/clean.mk` — Очистка промежуточных объектов и скомпилированных пакетов.

### Основные цели Makefile:
```bash
# Сборка всех библиотек, приложений, тулчейна и шрифтов:
make all

# Сборка стандартных библиотек (libc, libm, libstdc++, libapp, crt0):
make lib

# Сборка всех прикладных программ:
make applications

# Генерация баз данных консольных шрифтов (.fnt):
make font-databases

# Создание чистого дискового образа объемом 512 МБ:
make create-disk DISK=/path/to/disk.img

# Форматирование раздела со смещением LBA 2048 в IPO_FS:
make format-disk DISK=/path/to/disk.img

# Развертывание всех приложений, библиотек, заголовков и шрифтов на диск:
make load-apps DISK=/path/to/disk.img

# Очистка скомпилированных файлов:
make clean
```

---

## ⚙️ Параметры конфигурации (`mk/config.mk`)

- `CC ?= gcc` — 32-битный C-компилятор (используются флаги `-m32 -O2 -ffreestanding -fno-pic -fno-pie`).
- `CXX ?= g++` — Компилятор C++ для приложений с поддержкой `libstdc++.a`.
- `ASM ?= nasm` — Ассемблер NASM для сборки 32-битных объектных файлов и плоских бинарников.
- `DISK ?= /path/to/disk.img` — Путь к целевому образу диска (можно также задать через переменную окружения `DISK`).
- `START_LBA ?= 2048` — Начальный сектор раздела IPO_FS (смещение первого раздела MBR, по умолчанию: 2048).

## 📦 Пакетное развертывание через `load_applications.py` и `load_to_disk.sh`

Для быстрого наполнения диска всеми компонентами операционной системы используются автоматические скрипты:

```bash
# Развертывание с автоматическим форматированием чистого диска:
python3 tools/load_applications.py --disk /path/to/disk.img --format

# Или с помощью удобного скрипта-обёртки:
./load_to_disk.sh /path/to/disk.img

# Или через Makefile:
make load-apps DISK=/path/to/disk.img
```

Утилита проверяет наличие суперблока `IPO_FS`. При необходимости форматирует раздел и разворачивает каталоги:
- `/applications/` — Исполняемые бинарные файлы приложений и игр.
- `/lib/` — Статические библиотеки (`libc.a`, `libm.a`, `libapp.a`) и объектные файлы CRT.
- `/include/` — Стандартные заголовочные файлы C99/POSIX/GL.
- `/fonts/` — Базы консольных шрифтов для поддержки нескольких языков.

## 🔤 Генерация шрифтов (`tools/build_font_db.py`)

Утилита `tools/build_font_db.py` компилирует растровые шрифты в специализированный бинарный формат `.fnt` для консольного видеодрайвера IPO_OS, поддерживая латиницу, кириллицу и китайские иероглифы. Команда `make font-databases` выполняет компиляцию перед развертыванием файлов на диск.
