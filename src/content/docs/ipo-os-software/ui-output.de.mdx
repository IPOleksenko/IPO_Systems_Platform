# User Interface, Shell, GUI and Multimedia

**IPO_OS** provides a comprehensive user experience:
1. **Interactive Console Shell:** 31 built-in commands, multitasking virtual workspaces (`run &`), result-value argument passing (`|`), scrollback history, and ANSI colors.
2. **Window Manager (WM):** 2D graphical desktop running in VGA Mode 13h (320x200x256); compositor updates run from the active process/console loop without a fixed FPS cap, with a PS/2 software mouse pointer and event-driven windows.
3. **TinyGL 3D Engine (OpenGL 1.1):** Software 3D rasterizer inside kernel space, featuring Z-buffering, dynamic lighting, texture mapping, and flat/smooth shading.
4. **Audio Architecture:** Sound Blaster 16 DSP hardware driver (16-bit DMA Ch 5, 22050 Hz stereo mixer) and fallback PC Speaker PWM.

### ⚡ Multitasking Pipeline Operators in `run`

```bash
# 1. '&' operator — separate virtual workspaces (Ctrl+PgUp / Ctrl+PgDn to switch):
run edit & player & hosting_server

# 2. '&&' operator — asynchronous shared workspace (run multiple GUI/3D apps on same desktop):
run gl_cube && gl_gears && fps_meter

# 3. '|' operator — pass the previous command's return value as arguments:
run producer | consumer

# 4. ';' operator — sequential execution:
run setfont /fonts/terminus.fnt ; startwm
```

### ⌨️ Terminal Navigation Shortcuts
- **`Ctrl + Page Up` / `Ctrl + Page Down`:** Cycle between multitasking workspaces.
- **`Ctrl + Left Shift` / `Ctrl + Right Shift`:** Cycle active keyboard layout.
- **`Ctrl + C`:** Interrupt active task or close current workspace.
- **`Page Up` / `Page Down`:** Scroll terminal output buffer (dynamic scrollback).
- **`Up / Down Arrows`:** Command history recall.

## 🪟 2. Window Manager (WM)

The graphical desktop compositor is updated by the active process/console loop in VGA Mode 13h (320x200x256), without a fixed 60 FPS cap:
- Window decoration styles: `WM_DECOR_DEFAULT`, `WM_DECOR_THIN`, `WM_DECOR_NONE`.
- Event model: `WM_EVENT_CLICK`, `WM_EVENT_KEY_DOWN`, `WM_EVENT_MOVE`, `WM_EVENT_RESIZE`, `WM_EVENT_CLOSE`.
- Drag a standard window by its title bar only; clicking the client area sends `WM_EVENT_CLICK` and does not move the window. Resize using the window borders, and maximize/restore with the title-bar button or a double-click on the title bar.
- Use the taskbar's **Close** button to end the WM session and return to text mode.

### 🔘 Vereinheitlichte 3D-Close-Schaltfläche & VGA Mode 13h Overlay

IPO_OS verfügt über eine vereinheitlichte **Close**-Schaltfläche, die identisch zwischen der Fenster-Manager-Taskleiste (`startwm`) und nativen VGA Mode 13h Vollbildanwendungen geteilt wird (`wm_draw_close_button`):
- **Abmessungen & Positionierung:** $40 \times 10$ Pixel verankert bei Koordinate $(2, 188)$ in der unteren linken Ecke des $320 \times 200$ Bildschirms.
- **Design:** 3D-Reliefrahmen, $6 \times 6$ Farbindikator und zentrierter Text "Close".
- **Verhalten:** Klick ruft `wm_handle_close_button_click()` auf und stellt den $80 \times 25$ Textmodus wieder her.

### 👁️ VGA Overlay-Sichtbarkeitssteuerung (`<vga_gfx.h>`)

Anwendungen im VGA Mode 13h können die Sichtbarkeit der Close-Schaltfläche und des Mauszeigers über Syscalls `0x10C5` (`IPO_SYSCALL_VGA_SET_OVERLAY_FLAGS`) und `0x10C6` (`IPO_SYSCALL_VGA_GET_OVERLAY_FLAGS`) steuern:
- **`VGA_OVERLAY_SHOW_ALL`** (`0x00`): Standard (Schaltfläche und Maus sichtbar).
- **`VGA_OVERLAY_HIDE_BUTTON`** (`0x01`): Schließt Schaltfläche aus.
- **`VGA_OVERLAY_HIDE_CURSOR`** (`0x02`): Blendet System-Mauszeiger aus.
- **`VGA_OVERLAY_HIDE_ALL`** (`0x03`): Verbirgt beides für unterbrechungsfreies Vollbild.

Helferfunktionen in `<vga_gfx.h>`: `vga_hide_close_button()`, `vga_show_close_button()`, `vga_hide_overlay_cursor()`, `vga_show_overlay_cursor()`.

### 🖱️ Mausbereichs- & Klick-Prüfungs-API (`<driver/input/mouse.h>`)

- **`void mouse_get_position(int32_t *out_x, int32_t *out_y);`** — Liefert aktuelle $(x, y)$ Bildschirmkoordinaten.
- **`bool mouse_is_pressed(int button);`** — Prüft, ob Taste gedrückt gehalten wird.
- **`bool mouse_is_in_region(int32_t x, int32_t y, int32_t w, int32_t h);`** — Prüft, ob Zeiger innerhalb $[x, x+w) \times [y, y+h)$ liegt.
- **`bool mouse_is_clicked_in_region(int32_t x, int32_t y, int32_t w, int32_t h, int button);`** — Klick-Prüfung im Bereich.
- **`bool mouse_check_click(int32_t x, int32_t y, int32_t w, int32_t h);`** — Linksklick-Prüfung im Rechteckbereich.

## 🧊 3. TinyGL 3D Graphics (OpenGL 1.1)

Integrated bare-metal software 3D rasterizer:
- **Primitives:** Points, lines, triangles, quads, polygons.
- **Lighting:** Up to 8 light sources, diffuse/specular/ambient illumination, normal vectors.
- **Z-Buffer:** 16-bit depth buffer for hidden surface removal.
- **Applications in `applications/`:** `gl_gears`, `gl_teapot`, `gl_cube`, `fps_meter`, `doom` (offizieller id Software `linuxdoom-1.10` Port; ruft automatisch `vga_hide_close_button()` und `vga_hide_overlay_cursor()` auf).

## 🔊 4. Sound Blaster 16 & PC Speaker Audio

- **Sound Blaster 16:** Base port `0x220`, 16-bit DMA Channel 5, double buffering at `0x600000`, 22050 Hz stereo mixer.
- **PC Speaker:** Dynamic PWM frequency tracking using Zero-Crossing rate analysis.
- **Audio & Multimedia applications:** `player` (plays media files from `/music/`), `doom`.
