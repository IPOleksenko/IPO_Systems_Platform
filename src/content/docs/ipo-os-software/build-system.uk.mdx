# Система збирання та утиліти розгортання

Проєкт **IPO_OS_Software** містить незалежну екосистему користувацьких бібліотек, компіляторів, утиліт та демонстраційних програм. Збирання керується модульною системою GNU Make та спеціалізованими інструментами для створення й наповнення дискових образів із файловою системою **IPO_FS**.

---

## 🔨 Структура та цілі Makefile

Складальний конвеєр розділений на модульні правила в каталозі `mk/`:
- `mk/config.mk` — Визначення компіляторів, прапорців (`-m32`, `-ffreestanding`) та шляхів.
- `mk/lib.mk` — Збирання стандартних бібліотек (`libc.a`, `libm.a`, `libstdc++.a`, `libapp.a`, `libapp_api.a`, `crt0.o`).
- `mk/applications.mk` — Збирання всіх прикладних програм (DOOM, TinyCC, MicroPython, Lua, NASM, редактор, 3D-демо).
- `mk/toolchain.mk` — Підготовка вбудованих інструментів розробки.
- `mk/disk.mk` — Операції з дисковими образами (створення, форматування, встановлення ПЗ).
- `mk/clean.mk` — Очищення проміжних об'єктів та скомпільованих пакетів.

### Основні цілі Makefile:
```bash
# Збирання всіх бібліотек, застосунків, тулчейну та шрифтів:
make all

# Збирання стандартних бібліотек (libc, libm, libstdc++, libapp, crt0):
make lib

# Збирання всіх прикладних програм:
make applications

# Генерація баз даних консольних шрифтів (.fnt):
make font-databases

# Створення чистого дискового образу об'ємом 512 МБ:
make create-disk DISK=/path/to/disk.img

# Форматування розділу зі зміщенням LBA 2048 в IPO_FS:
make format-disk DISK=/path/to/disk.img

# Розгортання всіх застосунків, бібліотек, заголовків та шрифтів на диск:
make load-apps DISK=/path/to/disk.img

# Очищення скомпільованих файлів:
make clean
```

## ⚙️ Параметри конфігурації (`mk/config.mk`)

- `CC ?= gcc` — 32-бітний C-компілятор (використовуються прапорці `-m32 -O2 -ffreestanding -fno-pic -fno-pie`).
- `CXX ?= g++` — Компілятор C++ для застосунків із підтримкою `libstdc++.a`.
- `ASM ?= nasm` — Асемблер NASM для збирання 32-бітних об'єктних файлів та плоских бінарників.
- `DISK ?= /path/to/disk.img` — Шлях до цільового образу диска (можна також задати через змінну оточення `DISK`).
- `START_LBA ?= 2048` — Початковий сектор розділу IPO_FS (зміщення першого розділу MBR, за замовчуванням: 2048).

## 📦 Пакетне розгортання через `load_applications.py` та `load_to_disk.sh`

Для швидкого наповнення диска всіма компонентами операційної системи використовуються автоматичні скрипти:

```bash
# Розгортання з автоматичним форматуванням чистого диска:
python3 tools/load_applications.py --disk /path/to/disk.img --format

# Або за допомогою зручного скрипта-обгортки:
./load_to_disk.sh /path/to/disk.img

# Або через Makefile:
make load-apps DISK=/path/to/disk.img
```

Утиліта перевіряє наявність суперблока `IPO_FS`. За потреби форматує розділ та розгортає каталоги:
- `/applications/` — Виконувані бінарні файли застосунків та ігор.
- `/lib/` — Статичні бібліотеки (`libc.a`, `libm.a`, `libapp.a`) та об'єктні файли CRT.
- `/include/` — Стандартні заголовні файли C99/POSIX/GL.
- `/fonts/` — Бази консольних шрифтів для підтримки кількох мов.

## 🔤 Генерація шрифтів (`tools/build_font_db.py`)

Утиліта `tools/build_font_db.py` компілює растрові шрифти у спеціалізований бінарний формат `.fnt` для консольного відеодрайвера IPO_OS, забезпечуючи підтримку латиниці, кирилиці та китайських ієрогліфів.
