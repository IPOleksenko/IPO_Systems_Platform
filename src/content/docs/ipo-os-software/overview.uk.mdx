# Огляд програмної екосистеми IPO_OS_Software

**IPO_OS_Software** — це офіційний репозиторій середовища користувача, стандартних бібліотек, інструментів розробника та прикладних програм для операційної системи **[IPO_OS](https://github.com/IPOleksenko/IPO_OS)**. Він надає повноцінне середовище виконання C/C++, 3D-графіку, віконний інтерфейс, внутрішньосистемні компілятори, інтерпретатори, портовані ігри та дискові утиліти.

<Callout type="tip" title="Модульне розділення проектів">
Репозиторій `IPO_OS` сфокусований виключно на архітектурі ядра, низькорівневих драйверах обладнання, управлінні пам'яттю та планувальнику процесів. Усі користувацькі програми, стандартні бібліотеки, компилятори та засоби формування дисків винесені в **IPO_OS_Software**.
</Callout>

## 🏛️ Архітектура програмної екосистеми

Репозиторій `IPO_OS_Software` структуровано за ключовими підсистемами:

1. **Бібліотеки часу виконання (`lib/`):**
   - **`libc.a`:** Реалізація стандарту C99 (динамічна пам'ять через `sbrk`, форматований ввід-вивід stdio, рядки, POSIX-файли, сокети, сигнали та динамічне завантаження модулів `dlopen`/`dlsym`).
   - **`libm.a`:** Математична бібліотека з підтримкою тригонометрії, логарифмів та операцій із рухомою комою.
   - **`libstdc++.a`:** Базовий рантайм C++ (`new`/`delete`, RTTI, обробка винятків).
   - **`libapp.a`:** Системні API для віконного менеджера (WM), зміни екранних шрифтів, клавіатури/миші та звуку.
   - **TinyGL:** Вбудований 3D-растеризатор, сумісний з OpenGL 1.1 (відсікання граней, стек матриць, освітлення).
   - **Модулі CRT (`crt0.o`, `crti.o`, `crtn.o`):** Точки входу для бінарних файлів та модулів.

2. **Заголовні файли (`include/`):**
   - Уніфіковані заголовки C99, POSIX, TinyGL та системних викликів (`stdio.h`, `stdlib.h`, `unistd.h`, `GL/gl.h`, `wm.h`, `syscall.h`).

3. **Внутрішньосистемний інструментарій (`build/toolchain/`):**
   - **TinyCC (`tcc`):** Швидкий C99-компілятор, що працює безпосередньо в середовищі IPO_OS.
   - **Lua 5.3 (`lua`, `luac`):** Інтерпретатор скриптів та компілятор байт-коду.
   - **MicroPython (`python.elf`):** Компактний рантайм Python 3 для скриптів і автоматизації.
   - **NASM:** 32-бітний x86-асемблер, що компілює код всередині ОС.
   - **GNU Binutils (`gcc`, `g++`, `as`, `ld`, `ar`, `ranlib`, `objcopy`, `objdump`, `readelf`, `nm`, `strip`).**

4. **Програми та утиліти (`applications/`):**
   - **DOOM (`doom.bin`):** Порт офіційного `linuxdoom-1.10`, що працює на голому залізі у 320x200 з 60 FPS та звуком SB16.
   - **Текстовий редактор (`edit.bin`):** Інтерактивний редактор із підсвічуванням.
   - **3D-демонстрації (`gl_gears.bin`, `gl_cube.bin`, `gl_teapot.bin`):** Графічні тести TinyGL.
   - **Мережеві інструменти (`hosting_server.bin`, `hosting_client.bin`, `ping.bin`):** Веб-сервер HTTP, клієнт та діагностика ICMP.
   - **Консольні утиліти:** `echo.bin` виводить передані аргументи; `hello.bin` — приклад Hello World; `player.bin` відтворює мультимедіа; `setfont.bin` показує доступні шрифти консолі та перемикає їх; `term_ctl.bin` передає текст у термінал і за потреби виконує команду.

## 💾 Моделі розповсюдження ПЗ

Для зручності користувачів та розробників передбачено два офіційні варіанти постачання:

### Варіант 1: Окремо чистий диск + окремо скомпільовані програми
- **`disk-clean.img`:** Чистий 512 МБ образ диска, розмічений файловою системою `IPO_FS`. На ньому немає встановлених програм — це чистий накопичувач для ваших файлів.
- **`applications.zip`:** Архів, що містить **виключно готові скомпільовані файли** (без вихідного коду та скриптів збірки):
  - Бінарні файли додатків (`applications/*.bin` + `doom1.wad`)
  - Виконувані файли тулчейну (`toolchain/*.elf`)
  - Статичні бібліотеки та лінкерний скрипт (`lib/*.a`, `lib/*.o`, `lib/linker.ld`)
  - Заголовні файли SDK (`include/`)
  - Бази консольних шрифтів (`fonts/*.fnt`)

### Варіант 2: Диск із попередньо встановленими програмами
- **`disk-installed.img`:** Готовий до роботи 512 МБ образ диска з усіма додатками, DOOM, компіляторами, бібліотеками та шрифтами, встановленими у `/applications`, `/lib`, `/include` та `/fonts`. Достатньо підключити цей диск до QEMU або прошити на фізичний накопичувач.

## 🛠️ Утиліти управління диском

`IPO_OS_Software` надає автономні Python-інструменти для створення, перевірки та запису дисків:

- **`tools/load_applications.py`:** Автоматизований запис скомпільованих файлів на розділ IPO_FS.
- **`tools/disk_editor.py`:** Повнофункціональний командний файловий менеджер для перегляду, витягування, запису та видалення файлів в образі `IPO_FS`.
- **`load_to_disk.sh`:** Зручний shell-скрипт для розмітки та встановлення програм в одну команду.
