# Ввод/вывод, видео та текстовая консоль

IPO_OS имеет двухрежимную архитектуру вывода изображения: аппаратную текстовую консоль VGA 80x25 с поддержкой загружаемых шрифтов та графический віконний менеджер (Window Manager) с поддержкой Bochs VBE/BGA.

---

## 📺 Текстовая консоль VGA (`0xB8000`)

Основной терминал работает в стандартном текстовом режиме VGA Mode 03h:
- **Базовый адреси:** Физический адреси `0x000B8000` (выделено 32 КБ, активное окно 4000 байт).
- **Сетка экрана:** 80 колонок на 25 рядків = 2000 знакомест.
- **Формат знакоместа:** Каждая ячейка состоит з двух байт:
  - Байт 0: Индекс символа (ASCII / знакогенератор).
  - Байт 1: Байт атрибутов (Биты 0–3: цвет символа 0–15; Биты 4–6: цвет фона 0–7; Бит 7: мерцание/яркость).

### Аппаратный курсор:
Позиционирование мерцающего курсора виконується через контролер CRTC:
```c
void vga_set_cursor(uint16_t x, uint16_t y) {
    uint16_t pos = y * 80 + x;
    outb(0x3D4, 0x0E);          /* Регістр CRTC 0x0E: Старший байт позиції */
    outb(0x3D5, (pos >> 8) & 0xFF);
    outb(0x3D4, 0x0F);          /* Регістр CRTC 0x0F: Молодший байт позиції */
    outb(0x3D5, pos & 0xFF);
}
```

### Загрузка шрифтов та поддержка кириллицы:
Системний виклик `IPO_SYSCALL_FONT_LOAD` (`0x1052`) дозволяє загружать матричные шрифты 8x16 напрямую в пам'ять знакогенератора VGA (Plane 2), обеспечивая корректное отображение русских букв без переключения в графический режим.

## 🖼️ Віконний менеджер (Window Manager)

При переходе в графический режим ядро взаимодействует с адаптером **Bochs VBE / BGA (Bochs Graphic Adapter)**:
- **Порты ввода-вывода:** Индекс `0x01CE`, Данные `0x01CF`.
- **Разрешения:** 1024x768 (32 bpp), 800x600 (32 bpp).
- **Линейный фреймбуфер:** Пам'ять MMIO, сопоставленная видеокарте через регістр PCI BAR 0.

### Системні виклики віконного менеджера:
Приложения создают окна та управляют ими через системні виклики:
- `IPO_SYSCALL_WM_CREATE_WINDOW` (`0x1070`): Створення окна с заданными координатами, розмірами та заголовком.
- `IPO_SYSCALL_WM_DESTROY_WINDOW` (`0x1071`): Закрытие окна та освобождение буфера.
- `IPO_SYSCALL_WM_SET_FOCUS` (`0x1077`): Перевод окна на передний план та передача фокуса ввода.
- `IPO_SYSCALL_WM_INVALIDATE` (`0x107A`): Пометка области окна для перерисовки композитором.
