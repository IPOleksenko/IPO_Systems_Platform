## 🔍 Детальный разбор этапов запуска

### 1. Сигнал Power Good та вектор апаратного скидання
1. При нажатии кнопки увімкнення блок живлення стабилизирует напряжения (+12V, +5V, +3.3V) та выдаёт сигнал **Power Good (PWR_OK)** на материнську плату.
2. Процесор снимает внутренний сигнал сброса `RESET`.
3. В аппаратном реальному режимі вказівник команд выставляется на вектор апаратного скидання x86: `CS:IP = 0xF000:0xFFF0` (Физический адреси: `0xFFFFFFF0`).

### 2. Ініціалізація Boot ROM та прошивки (Контракты 2 та 3)
1. **IPO_Boot_ROM** переводит кэш CPU в режим Cache-as-RAM (CAR), определяет чипсет (i440FX або Q35), запускает код тренировки контролера пам'яті (MRC), копирует та блокирует код в Shadow RAM та передаёт управление в прошивку за адресиу `0xF000:0004` (**Контракт 2**).
2. **IPO_Firmware** настраивает векторы переривань реального режиму (IVT: INT 10h–1Ah), открывает вентиль Fast A20 через порт `0x92`, формирует карту пам'яті E820, сканирует дисківые контролеры та загружает LBA 0 (сектор MBR) в пам'ять за адресиу `0x0000:7C00` (**Контракт 3**).

### 3. Виконання первичного завантажувача Stage 1 (`0x7C00`)
1. Прошивка совершает дальний переход на `0x0000:7C00`, передавая в регістре `DL` номер загрузочного диска (`0x80`).
2. Первичный 512-байтный завантажувач настраивает стек реального режиму, считывает сектори второй стадии (Stage 2) з зарезервированной области диска та передаёт им управление.

### 4. Переход в 32-битный захищений режим (Protected Mode)
1. Завантажувач второй стадии формирует 32-битную глобальную таблицу дескрипторов (**GDT**) с плоской моделью пам'яті 4 ГБ:
   - Сегмент кода: база `0x00000000`, лимит `0xFFFFFFFF`, Ring 0, Execute/Read.
   - Сегмент данных: база `0x00000000`, лимит `0xFFFFFFFF`, Ring 0, Read/Write.
2. Завантажувач переключает процесор в захищений режим установкой бита `PE` (бит 0) в регістре управления `CR0`:
   ```asm
   mov eax, cr0
   or eax, 1
   mov cr0, eax
   jmp 0x08:.protected_entry   ; Далекий перехід скидає конвеєр інструкцій
   ```

### 5. Загрузка ядра та старт подсистем (`0x10000`)
1. В 32-битном режиме завантажувач считывает бинарный файл ядра в фізичну пам'ять за адресиу `0x10000` (64 КБ).
2. Управление передається на точку входу `_start` (`src/kernel/arch/x86/entry32.asm`).
3. Ядро последовательно инициализирует подсистемы:
   - Настраивает ядріную GDT та стек ядра.
   - Встановлює таблицю IDT з обробниками винятків ЦП (`0x00`–`0x1F`) та вектором системного виклику `0x80` (периферія працює за моделлю опитування в `kmain()`).
   - Инициализирует менеджер фізичної пам'яті (PMM) та кучу ядра (`kmalloc`).
   - Монтирует корневой розділ `IPO_FS` с сектора LBA 2048.
   - Запускает драйвери пристроїв: контролер дисків ATA, клавиатуру/мышь PS/2, сетевую карту RTL8139 та віконний менеджер.
   - Запускає вбудовану командну оболонку та консоль терміналу (`terminal_initialize()`, `terminal_console()`).
