# Межпроцессное взаимодействие (IPC)

Для обмена данными и фоновой координации между процессами и драйверами IPO_OS предоставляет три основных механизма межпроцессного взаимодействия (IPC).

---

## 🔑 Реестр системных переменных ядра

Подсистема системных переменных (`IPO_SYSCALL_VAR_SET` `0x1042`, `IPO_SYSCALL_VAR_GET` `0x1043`, `IPO_SYSCALL_VAR_DELETE` `0x1044`) выступает в роли резидентной шины данных формата ключ-значение (in-memory key-value bus):

```c
// Установка типизированных переменных
ipo_var_set_int("net.active_connections", 4);
ipo_var_set_str("system.hostname", "ipo-node-01");

// Чтение типизированных переменных
int conns;
ipo_var_get_int("net.active_connections", &conns);

char hostname[32];
ipo_var_get_str("system.hostname", hostname, sizeof(hostname));
```

### Характеристики:
- **Хранение в куче ядра:** данные размещаются в динамически выделяемой таблице `ipo_shared_vars` в памяти кучи ядра (`kmalloc`) с копированием имени и содержимого.
- **Гибкость типов:** поддерживаются произвольные бинарные буферы, нуль-терминированные строки, 32-битные целые числа, вещественные числа и булевы флаги.
- **Межпроцессное сохранение:** переменные, заданные родительским процессом или скриптом, остаются доступными последующим программам до явного удаления или перезагрузки системы.

---

## 🔄 Управление асинхронными задачами

Процессы могут регистрировать периодические фоновые функции обратного вызова (callbacks) через асинхронный планировщик ядра:
- `IPO_SYSCALL_ASYNC_START` (`0x1030`): регистрирует обратный вызов функции (`async_task_fn_t`) с заданным интервалом выполнения в миллисекундах.
- `IPO_SYSCALL_ASYNC_STOP` (`0x1031`): отменяет регистрацию и останавливает активную задачу.

```c
typedef void (*async_task_fn_t)(void);

int async_start_task(const char *name, uint32_t interval_ms, async_task_fn_t fn);
```

### Кооперативное выполнение:
- Асинхронные задачи вызываются в главном цикле ядра через `async_scheduler_tick()`.
- При срабатывании таймера задачи планировщик временно переключает отображение памяти процесса-владельца (`process_map_app(owner)`), выполняет функцию и восстанавливает прежний контекст.

## 🌐 Локальные сокеты замыкания на себя (Loopback `127.0.0.1`)

Для полнодуплексной потоковой или датаграммной передачи сообщений процессы устанавливают локальные соединения через встроенный стек TCP/IP:
- Передача данных выполняется через внутренний псевдоинтерфейс loopback (`src/net/loopback.c`).
- Используются стандартные сокетные вызовы в стиле POSIX/BSD (`socket()`, `bind()`, `connect()`, `send()`, `recv()`).
- Обмен происходит в обход физической сетевой карты без потерь пакетов с микросекундной задержкой.
