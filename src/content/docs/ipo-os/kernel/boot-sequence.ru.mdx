## 🔍 Детальный разбор этапов запуска

### 1. Сигнал Power Good и вектор аппаратного сброса
1. При нажатии кнопки включения блок питания стабилизирует напряжения (+12V, +5V, +3.3V) и выдаёт сигнал **Power Good (PWR_OK)** на материнскую плату.
2. Процессор снимает внутренний сигнал сброса `RESET`.
3. В аппаратном реальном режиме указатель команд выставляется на вектор аппаратного сброса x86: `CS:IP = 0xF000:0xFFF0` (Физический адрес: `0xFFFFFFF0`).

### 2. Инициализация Boot ROM и прошивки (Контракты 2 и 3)
1. **IPO_Boot_ROM** переводит кэш CPU в режим Cache-as-RAM (CAR), определяет чипсет (i440FX или Q35), запускает код тренировки контроллера памяти (MRC), копирует и блокирует код в Shadow RAM и передаёт управление в прошивку по адресу `0xF000:0004` (**Контракт 2**).
2. **IPO_Firmware** настраивает векторы прерываний реального режима (IVT: INT 10h–1Ah), открывает вентиль Fast A20 через порт `0x92`, формирует карту памяти E820, сканирует дисковые контроллеры и загружает LBA 0 (сектор MBR) в память по адресу `0x0000:7C00` (**Контракт 3**).

### 3. Выполнение первичного загрузчика Stage 1 (`0x7C00`)
1. Прошивка совершает дальний переход на `0x0000:7C00`, передавая в регистре `DL` номер загрузочного диска (`0x80`).
2. Первичный 512-байтный загрузчик настраивает стек реального режима, считывает секторы второй стадии (Stage 2) из зарезервированной области диска и передаёт им управление.

### 4. Переход в 32-битный защищённый режим (Protected Mode)
1. Загрузчик второй стадии формирует 32-битную глобальную таблицу дескрипторов (**GDT**) с плоской моделью памяти 4 ГБ:
   - Сегмент кода: база `0x00000000`, лимит `0xFFFFFFFF`, Ring 0, Execute/Read.
   - Сегмент данных: база `0x00000000`, лимит `0xFFFFFFFF`, Ring 0, Read/Write.
2. Загрузчик переключает процессор в защищённый режим установкой бита `PE` (бит 0) в регистре управления `CR0`:
   ```asm
   mov eax, cr0
   or eax, 1
   mov cr0, eax
   jmp 0x08:.protected_entry   ; Дальний переход сбрасывает конвейер инструкций
   ```

### 5. Загрузка ядра и старт подсистем (`0x10000`)
1. В 32-битном режиме загрузчик считывает бинарный файл ядра в физическую память по адресу `0x10000` (64 КБ).
2. Управление передаётся на точку входа `_start` (`src/kernel/arch/x86/entry32.asm`).
3. Ядро последовательно инициализирует подсистемы:
   - Настраивает ядреную GDT и стек ядра.
   - Устанавливает таблицу IDT с обработчиками исключений ЦП (`0x00`–`0x1F`) и вектором системного вызова `0x80` (периферия работает по модели опроса в `kmain()`).
   - Инициализирует менеджер физической памяти (PMM) и кучу ядра (`kmalloc`).
   - Монтирует корневой раздел `IPO_FS` с сектора LBA 2048.
   - Запускает драйверы устройств: контроллер дисков ATA, клавиатуру/мышь PS/2, сетевую карту RTL8139 и оконный менеджер.
   - Запускает встроенную командную строку и консоль терминала (`terminal_initialize()`, `terminal_console()`).
