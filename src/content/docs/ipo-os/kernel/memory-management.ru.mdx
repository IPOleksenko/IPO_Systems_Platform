## 📦 Подсистемы управления памятью

### 1. Аппаратное определение RAM (Адрес 0x8FF0)
Общий объём доступной оперативной памяти определяется MBR-загрузчиком в реальном режиме с помощью вызовов BIOS `INT 15h, AX=E820` (с резервным `AX=E801`).
- Загрузчик суммирует доступные байты и записывает 32-битное число напрямую по физическому адресу `0x8FF0`.
- Ядро считывает значение через `*(volatile uint32_t *)0x8FF0` в `get_process_heap_capacity()` для расчёта доступного пула кучи процессов.

### 2. Динамическая куча ядра (`src/kernel/mm/kmalloc.c`)
Куча ядра инициализируется с базового физического адреса `0x1000000` (16 МБ) с максимальным размером 16 МБ (`KMALLOC_HEAP_SIZE = 0x1000000`):
- Каждый блок памяти имеет 16-байтный заголовок `kmalloc_block_t` с защитным магическим числом `0xDEADBEEF` (в активном состоянии) или `0xDEADC0DE` (после освобождения).
- Функция `kmalloc_coalesce_and_shrink()` автоматически объединяет соседние освобождённые блоки и уменьшает границу `heap_used`.

### 3. Куча и адресное пространство процессов
Пользовательские программы в IPO_OS загружаются по базовому адресу `0x800000`.
- При вызове системного вызова `IPO_SYSCALL_SBRK` (`0x1045`) ядро динамически управляет границей `user_heap_break`.
- Для изоляции памяти процессов каждому PID выделяется собственный диапазон: `0x08000000 + (pid - 1) * 0x04000000` (до 64 МБ на процесс).
