# Виртуальная файліва система (VFS) та IPO_FS

Подсистема хранения данных **IPO_OS** состоит з независимого абстрактного слоя VFS, собственной 64-битной файлівої системи **IPO_FS** та низкоуровневого драйвера блочных пристроїв **ATA PIO**.

## 💾 Архитектура IPO_FS на диску

Файлова система размещается со смещением LBA 2048 (1 МБ від начала диска) та использует 512-байтные блоки:

```text
LBA 2048:      [ Суперблок IPO_FS (64 байти заголовок) ]
LBA 2049:      [ Бітова карта вільних інодів (Inode Bitmap) ]
LBA 2050..N:   [ Бітова карта вільних блоків даних (Block Bitmap) ]
LBA N+1..M:    [ Таблиця дескрипторів Inode Table (128 байтів на інод) ]
LBA M+1..END:  [ Пул блоків даних (Data Blocks Pool) ]
```

### 1. Суперблок (`struct ipo_superblock`)
- Магическая сигнатура: `'IPO_FS\0\0'` (8 байт).
- 64-битный счетчик общего числа блоков пула.
- 64-битный счетчик доступных инодов.
- Указатели на начальные физические LBA-блоки битовых карт та пула данных.

### 2. Дескриптор файлу (`struct ipo_inode`, 128 байт)
Каждый 512-байтный сектор таблицы инодов вмещает ровно 4 дескриптора:
- `mode` (uint32_t): Тип файлу (`0x1` = каталог, `0x2` = файл, бит `0x80000000` = защищенный системный файл).
- `links_count` (uint32_t): Количество жестких ссылок.
- `size` (uint64_t): Точный 64-битный розмір файлу в байтах.
- `extents[4]` (`struct ipo_extent[4]`, 96 байт): 4 первичных непрерывных экстента:
  - `start_block` (uint64_t): Физический LBA блок начала экстента.
  - `block_count` (uint64_t): Количество непрерывных 512-байтных секторів.
  - `file_offset` (uint64_t): Логическое смещение блока в файлі.
- `next_extent_node` (uint64_t): Вказівник на связанный блок расширенных экстентов для файлів гигантского розміра.

## 🔌 Драйвер ATA PIO (Primary & Secondary IDE)

Читання та запис секторів на физические жесткие диски осуществляется через параллельный интерфейс ATA PIO Mode:

| Порт ввода-вывода | Назначення |
| :--- | :--- |
| `0x1F0` | Data Register (16-битный порт передачи слов данных) |
| `0x1F1` | Error Register / Features |
| `0x1F2` | Sector Count (число передаваемых секторів) |
| `0x1F3` | LBA Low (биты 0..7) |
| `0x1F4` | LBA Mid (биты 8..15) |
| `0x1F5` | LBA High (биты 16..23) |
| `0x1F6` | Drive / Head / LBA bits 24..27 (выбор диска Master 0xE0 / Slave 0xF0) |
| `0x1F7` | Command / Status Register (команди `0x20` READ, `0x30` WRITE, статус `BSY`/`DRQ`) |
| `0x3F6` | Device Control / Alternate Status (сброс шини, вимкнення переривань) |

Драйвер поддерживает 28-битный режим адресиации LBA28 (до 128 ГБ) та 48-битный режим LBA48 (команди `0x24` READ EXT / `0x34` WRITE EXT).
