# Виртуальная файловая система и IPO_FS

Хранение данных в IPO_OS организовано через слой виртуальной файловой системы (VFS) поверх **IPO_FS** — собственной 64-битной файловой системы на непрерывных блочных цепочках (экстентах).

### Принцип работы экстентов (Extents)
В отличие от классических систем с многоуровневыми косвенными блоками указателей, требующими множества позиционирований головки диска, `IPO_FS` использует непрерывные диапазоны секторов — **экстенты**:
```c
struct ipo_extent {
    uint64_t logical_block;   /* Логический блок внутри файла */
    uint64_t physical_block;  /* Начальный физический сектор в разделе */
    uint32_t block_count;     /* Число непрерывных 512-байтных блоков */
    uint32_t flags;
};
```
- Первые **4 экстента** размещены непосредственно внутри 128-байтного дескриптора inode.
- Если файлу требуется более 4 несмежных фрагментов, поле `next_extent_node` указывает на блок `ipo_extent_node`, содержащий цепочку из **20 дополнительных экстентов**.

## 📂 Записи каталога (`ipo_dir_entry`)

Каталоги в `IPO_FS` хранятся как файлы, содержимое которых состоит из массива записей переменной длины:

```c
struct ipo_dir_entry {
    uint32_t inode;       /* Номер целевого дескриптора inode */
    uint32_t rec_len;     /* Полная длина записи в байтах */
    uint32_t name_len;    /* Длина имени файла (до 64 байт) */
    uint8_t  type;        /* 0x1 = Каталог, 0x2 = Обычный файл */
    uint8_t  reserved[3];
    /* Далее следует имя файла char name[] */
};
```
