## 📑 Register Calling Convention

IPO_OS implements an efficient 3-register calling convention across the `int 0x80` software interrupt gate:

| Register | Role | Description |
| :--- | :--- | :--- |
| **`EAX` (In)** | System Call Number | 32-bit identifier (e.g., `0x1001` for print, `0x1012` for read) |
| **`EBX` (In)** | Argument Count (`argc`) | Number of 32-bit parameters passed in the argument array |
| **`ECX` (In)** | Arguments Array (`argv`) | Pointer to an array of `uint32_t` arguments on the stack |
| **`EAX` (Out)** | Return Status Code | `0` or positive on success, or a negative error code (e.g., `-1`) |

## ⚙️ Kernel Dispatch Implementation

In `src/kernel/syscall/syscall.c`, the kernel initializes the dispatch table:

```c
typedef uint32_t (*ipo_syscall_handler_t)(uint32_t num, uint32_t argc, uint32_t *argv);

void ipo_register_syscall(uint32_t num, ipo_syscall_handler_t handler);
```

### Safety and Parameter Validation:
1. **Range Checking:** The dispatcher verifies that `EAX` is within valid registered table bounds. If unregistered, it returns `IPO_SYSCALL_ENOSYS` (`0xFFFFFFFF`).
2. **Buffer Pointer Validation:** Userland buffer pointers passed in `argv` are validated against memory boundaries to ensure an unprivileged program cannot overwrite kernel memory via a malicious `read()` or `write()`.
3. **Interrupt Gate Protection:** The `int 0x80` interrupt gate (flags `0xEE`, selector `0x08`) automatically clears `IF = 0` upon entry, ensuring atomic transition into the kernel dispatcher without reentrancy and restoring caller EFLAGS upon `iretd`.
