# Processor Modes, GDT & IDT

IPO_OS transitions the CPU from 16-bit Real Mode into 32-bit Protected Mode, establishing a flat 4 GB memory model with unified segment addressing and interrupt vector gates.

---

## 🎛️ Processor Modes Transition

```
┌──────────────────────────────────────────────┐
│             16-bit Real Mode                 │
│  • 1 MB physical addressing (Segment:Offset) │
│  • BIOS interrupt services (IVT INT 10h-1Ah) │
│  • Memory detection (E820 at 0x6000 / 0x8FE0)│
└──────────────────────┬───────────────────────┘
                       │ lgdt [gdt_desc], CR0.PE = 1, Far jmp 0x08:pmode_entry
┌──────────────────────▼───────────────────────┐
│         32-bit Flat Protected Mode           │
│  • Flat 4 GB linear physical memory          │
│  • Base = 0x00000000, Limit = 4 GB (G=1)     │
│  • CS = 0x08, DS = ES = SS = FS = GS = 0x10  │
│  • IDT (256 gates) with INT 0x80 int gate    │
└──────────────────────────────────────────────┘
```

---

## 📑 Global Descriptor Table (GDT)

In `src/boot/boot.asm`, the bootloader constructs a flat Global Descriptor Table with 3 descriptors:

| Selector | Index | Privilege Level | Segment Type | Base Address | Limit | Granularity & Flags |
| :--- | :---: | :---: | :--- | :---: | :---: | :--- |
| **`0x00`** | 0 | — | Null Descriptor | `0x00000000` | `0x00000` | Reserved |
| **`0x08`** | 1 | Ring 0 | Code Segment (Execute/Read) | `0x00000000` | `0xFFFFF` | 4 KB (`G=1`, 32-bit, `0x00CF9A000000FFFF`) |
| **`0x10`** | 2 | Ring 0 | Data Segment (Read/Write) | `0x00000000` | `0xFFFFF` | 4 KB (`G=1`, 32-bit, `0x00CF92000000FFFF`) |

### Protected Mode Setup:
```asm
lgdt [gdt_desc]
mov eax, cr0
or eax, 1                      ; Set Bit 0 (Protection Enable, PE)
mov cr0, eax
jmp 0x08:pmode_entry           ; Far jump flushes prefetch pipeline

[BITS 32]
pmode_entry:
    mov ax, 0x10
    mov ds, ax
    mov es, ax
    mov ss, ax
    mov fs, ax
    mov gs, ax
    mov esp, 0x500000          ; Initial 5 MB kernel stack
    jmp 0x00010000             ; Enter kernel at _start
```

## ⚡ Interrupt Descriptor Table (IDT)

In `src/kernel/syscall/syscall.c`, the kernel allocates and loads a 256-entry IDT (`ipo_idt_table`):

- **Vectors `0x00`–`0x1F` (0–31):** Architecture CPU Exceptions (`isr_0` through `isr_31`), dispatched to `cpu_exception_handler`.
- **Vector `0x80` (128):** System Call Interrupt Gate (`IPO_IDT_ENTRY_FLAGS = 0xEE`), pointing directly to `syscall_isr_entry`.
- **Vectors `32`–`127` & `129`–`255`:** Unmapped (zeroed). IPO_OS does not remap the 8259 PIC in protected mode; all peripheral hardware (timer, keyboard, mouse, storage, network) is handled via cooperative non-blocking polling in `kmain()`.

The IDT pointer structure is loaded into the CPU using the `lidt` instruction:
```c
ipo_idt_ptr_t idt_ptr = {
    .limit = (uint16_t)(sizeof(ipo_idt_table) - 1),
    .base = (uint32_t)ipo_idt_table
};
__asm__ volatile("lidt %0" : : "m"(idt_ptr));
```

## 🔥 Symmetric Multiprocessing (SMP) & Local APIC

The SMP subsystem (`src/kernel/arch/x86/smp.c`, `smp_trampoline.asm`, `src/include/kernel/smp.h`) discovers all physical and logical processor cores, initializes the Local APIC controller, and boots secondary **Application Processors (APs)**.

### 1. CPU Topology Discovery & Dynamic ACPI / MP Descriptors
During `smp_init()`, the **Bootstrap Processor (BSP)** discovers processor cores through a three-stage fallback pipeline:
1. **ACPI Tables (RSDP → RSDT → MADT / `APIC`):** Scans the EBDA and `0xE0000`–`0xFFFFF` for `"RSD PTR "`, validates table checksums, and parses MADT Local APIC entries (Type 0).
2. **Intel MP Floating Pointer (`_MP_`):** Fallback parser for Intel Multiprocessor Specification 1.1/1.4 configuration tables.
3. **`CPUID` Enumeration:** Fallback core detection and dynamic string extraction for vendor (`smp_get_cpu_vendor`), brand (`smp_get_cpu_brand`), and instruction set extensions (`smp_get_cpu_features_str`: `FPU`, `TSC`, `MSR`, `PAE`, `APIC`, `MMX`, `SSE`, `SSE2`, `SSE3`, `SSSE3`, `SSE4.1`, `SSE4.2`, `AVX`, `LM(x64)`).

> **Zero Fixed Array Limits:** All in-memory ACPI/MP table structures (`acpi_rsdp_t`, `acpi_sdt_header_t`, `acpi_madt_t`, `mp_floating_pointer_t`) and the CPU registry (`s_cpus`) use dynamically self-expanding heap buffers (`char *` / `uint8_t *` + `_len` + `_cap` via `krealloc`) without arbitrary fixed array size limits.

### 2. Local APIC Initialization (`0xFEE00000`)
- Enables the Local APIC globally via bit 11 (`APIC_BASE_ENABLE_BIT`) of `IA32_APIC_BASE_MSR` (`0x1B`).
- Sets the Spurious Interrupt Vector Register (**SVR**, offset `0x00F0`) to `0x1FF` (Bit 8 APIC Software Enable + vector `0xFF`) and clears the Task Priority Register (**TPR**, offset `0x0080`) to `0`.

### 3. Application Processor (AP) Boot Trampoline (`0x8000`) & `INIT-SIPI-SIPI`
For each discovered AP core, the kernel allocates a 16 KB stack via `kmalloc` and copies the 16-to-32-bit trampoline (`smp_trampoline.asm`) to physical address **`0x00008000`**:
- **Trampoline Mailbox (`0x80F0`–`0x80FC`):**
  - `0x80F0` (`SMP_BOOT_STACK_ADDR`) — Top of the 16 KB stack allocated for the target AP.
  - `0x80F4` (`SMP_BOOT_CPUID_ADDR`) — Logical `cpu_id` assigned to the AP.
  - `0x80F8` (`SMP_BOOT_FN_ADDR`) — Physical address of C entrypoint `smp_ap_entry()`.
  - `0x80FC` (`SMP_BOOT_DONE_ADDR`) — Handshake flag set to `1` once the AP enters 32-bit Protected Mode.
- **`INIT-SIPI-SIPI` Sequence:** The BSP writes the target AP's LAPIC ID into `LAPIC_ICR_HIGH` (`0x0310`) and issues an `INIT` IPI (`0x00004500`) via `LAPIC_ICR_LOW` (`0x0300`), waits 10 ms, and sends two Startup IPIs (`SIPI`, `0x00004608`, vector page `0x08` = `0x8000 >> 12`).
- The waking AP starts in 16-bit Real Mode at `0x8000`, loads a temporary GDT, sets `CR0.PE = 1`, jumps to 32-bit mode, loads its `ESP` from `0x80F0`, signals `0x80FC = 1`, loads the kernel IDT, enables its own Local APIC, and enters the `smp_ap_entry()` work loop.

### 4. Hardware Spinlocks (`spinlock_t`) & Cross-Core Task Broadcast
- `src/include/kernel/smp.h` provides atomic hardware spinlocks (`spinlock_acquire`, `spinlock_release`, `spinlock_irqsave`, `spinlock_irqrestore`) built on `__atomic_test_and_set` and the x86 `pause` hint.
- `smp_broadcast_task(fn, arg)` dispatches a callback across all online CPU cores simultaneously and synchronizes completion with cross-core IPIs (`SMP_IPI_VECTOR = 0xE0`).
