### Storage Architecture in QEMU:
- **Drive 0 (`build/IPO_OS.img`):** Contains the MBR bootloader and concatenated kernel binary.
- **Drive 1 (`build/disk.img`):** 128 MB raw storage disk containing the `IPO_FS` partition and `/applications`.

### Networking Options: TAP vs. User Mode
- **TAP Mode (`NET_MODE=tap`):** Direct Layer 2 host interface (`tap0`). All 65,535 ports are routable between host (`192.168.7.1`) and guest (`192.168.7.2`).
- **User Mode (`NET_MODE=user`):** QEMU SLIRP NAT with forwarded ports (`8080`, `8000`).

## 📦 Running in Bochs x86 PC Emulator

Bochs provides cycle-accurate emulation and comprehensive hardware I/O port logging.

### `bochsrc.txt` Reference:
```ini
megs: 2048
romimage: file=/usr/share/bochs/BIOS-bochs-latest
vgaromimage: file=/usr/share/bochs/VGABIOS-lgpl-latest
ata0: enabled=1, ioaddr1=0x1f0, ioaddr2=0x3f0, irq=14
ata0-master: type=disk, path="build/IPO_OS.img", mode=flat, cylinders=1024, heads=16, spt=63
ata0-slave:  type=disk, path="build/disk.img", mode=flat
pci: enabled=1, chipset=i440fx
pnic: enabled=1, mac=52:54:00:12:34:56, ethmod=tuntap, ethdev=tap0
sb16: enabled=1, midimode=0, wavemode=1, dmatimer=250000
boot: disk
log: bochsout.txt
mouse: enabled=1, type=ps2
```

## 🖥️ Running in Oracle VirtualBox

1. **Create Virtual Machine:**
   - Type: `Other`, Version: `Other/Unknown (32-bit)`, Memory: `2048 MB`.
2. **Storage Controller:**
   - Add **IDE Controller** (PIIX4).
   - Convert raw image to VDI:
     ```bash
     VBoxManage convertfromraw build/IPO_OS.img build/IPO_OS.vdi --format VDI
     ```
   - Attach `IPO_OS.vdi` as Primary Master.
3. **Network Adapter:**
   - 适配器类型：**Realtek RTL8139**（PCI ID `0x10EC:0x8139`）。注意：内核不支持 PCnet 和 Intel PRO/1000。
