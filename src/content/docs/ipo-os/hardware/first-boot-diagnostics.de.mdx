# First Boot & POST Diagnostics

Upon switching on power to your assembled system, hardware diagnostics provide immediate feedback regarding system health and software execution checkpoints.

---

## 🖥️ Normal Boot Symptoms

Bei ordnungsgemäß funktionierender Hardware läuft der Startvorgang wie folgt ab:
1. **Netzteil und Lüfter:** Netzteil- und CPU-Lüfter laufen unmittelbar nach dem Drücken der Einschalttaste an.
2. **Mainboard-Lautsprecher:** Nach 1–3 Sekunden ertönt ein kurzer Signalton des Hardware-POST, gefolgt von einer 4-Ton-Melodie (C6-E6-G6-C7) über den PC-Lautsprecher nach Abschluss der Treiberinitialisierung des Kernels.
3. **Bildschirmausgabe:** Der Monitor erwacht aus dem Standby und wechselt in den VGA-Textmodus 80x25 (Modus 03h).
4. **Serielle Ausgabe:** Über COM1 (`0x3F8`) werden Kernel-Diagnoseprotokolle mit **115200 Baud, 8N1** ausgegeben (`[mount] success at lba 2048...`, `[driver] registered...`, `[system_state] transition...`).
5. **Bildschirmkopfzeile und Eingabeaufforderung:** In der obersten Statuszeile (Zeile 0) werden `IPO_OS` links und `Created by IPOleksenko` rechts in Hellgrün dargestellt, zusammen mit der Sprachanzeige. Darunter erscheinen die Begrüßung und die interaktive Shell-Eingabeaufforderung:
   ```text
   Type "help" or "?" on the keyboard to view commands, shortcuts, and OS features.

   > 
   ```

## 🔊 Speaker Beep Codes Referenz

| Audio Signal | Problem Description | Recommended Remedy |
| :--- | :--- | :--- |
| **1 Short Beep** | POST successfully passed | Normal operation; control handed to firmware. |
| **Continuous Rapid Beeps** | Power Delivery Failure | Check PSU rails (+12V, +5V) with a multimeter. |
| **Repeating Long Beeps** | Memory (RAM) Not Detected | Re-seat RAM sticks; test one module in Slot 0. |
| **1 Long, 2 Short Beeps** | Video Adapter Error | Re-seat PCI/AGP VGA card; inspect monitor cable. |
| **No Beep, Blank Screen** | Dead CPU, Cleared CMOS, or Short | Check 12V 4-pin CPU cable; verify chassis standoffs. |
