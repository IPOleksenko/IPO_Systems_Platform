# Підготовка носителя та разметка

Для створення загрузочного накопителя під IPO_OS формируется бинарный образ диска с таблицей розділов MBR та розділом файлівої системи **IPO_FS**, начинающимся с сектора **LBA 2048** (стандартная граница выравнивания 1 МБ).

---

## 💾 Структура дисківого пространства

```
┌─────────────────────┬───────────────────────────┬──────────────────────────────┐
│ Сектор 0 (LBA 0)    │ Сектори 1–2047            │ Сектор 2048 (LBA 2048) ...   │
│ Master Boot Record  │ Зарезервована область     │ Розділ файлової системи      │
│ (Stage 1 / 0x7C00)  │ Код Stage 2 завантажувача │ Суперблок, бітові карти, FS  │
└─────────────────────┴───────────────────────────┴──────────────────────────────┘
```

1. **Сектор 0 (MBR):** Содержит 512 байт первичного завантажувача Stage 1 та таблицу розділов с сигнатурой `0x55AA` за смещению 510.
2. **Секторы 1–2047:** Зарезервированные сектори для вторичного завантажувача Stage 2 та метаданных.
3. **Сектор 2048 та далее:** Начало файлівої системи `IPO_FS`. Суперблок розташований строго в секторі 2048.

## 🛠️ Работа с образом через `disk_editor.py`

В состав инструментов входит утилита `disk_editor.py`, позволяющая управлять файлуми внутри образа диска без необходимости root-прав та монтирования loop-пристроїв:

<SharedCode id="disk-editor-cmds" lang="ru" />

### Доступные команди:
- `format`: Инициализирует файліву систему, форматируя суперблок та очищая таблицы дескрипторов.
- `ls [path]`: Выводит содержимое каталога (номер дескриптора, розмір, имя).
- `cat <path>`: Выводит содержимое текстового файлу в терминал.
- `mkdir <path>`: Создаёт новый каталог.
- `put <src> <dest>`: Копирует бинарный файл або скрипт с хост-машини внутрь образа диска.
- `rm <path>`: Удаляет файл або пустую директорию.

## ⚡ Запис образа на физический диск (`dd`)

<Callout type="caution" lang="ru" title="Увага: Проверяйте имя целевого диска!">
Ошибка в указании буквы диска в утилите `dd` приведёт до **полной та необратимой потере данных** на вашей рабочей станции. Перед записю завжди сверяйте имя пристрої через команду `lsblk`.
</Callout>

```bash
# 1. Визначте назву підключеної флешки або CF-карти в системі Linux
lsblk -o NAME,SIZE,TYPE,MOUNTPOINT,MODEL

# 2. Розмонтуйте автоматично підключені розділи пристрою
sudo umount /dev/sdX* 2>/dev/null || true

# 3. Запишіть образ на фізичний диск (замініть sdX на ваш пристрій)
sudo dd if=build/disk.img of=/dev/sdX bs=4M status=progress conv=fsync

# 4. Скиньте системні буфери запису
sync
```
После завершения команди `sync` извлеките накопитель та подключите его до целевому компьютеру.
