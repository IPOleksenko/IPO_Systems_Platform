# Підготовка носіїв і образи дисків

Поточне збирання IPO_OS створює завантажувальний образ, допоміжний диск даних і порожній RAW-образ CD-ROM як окремі артефакти. Воно не створює об'єднаний Live USB-образ розміром 512 МіБ, описаний у старих інструкціях.

## Артефакти збирання

| Артефакт | Ціль збирання | Вміст |
| :--- | :--- | :--- |
| `build/IPO_OS.img` | `make image` | MBR-завантажувач, образ ядра та доповнення до розміру розділу. За поточної геометрії MBR за замовчуванням образ має розмір щонайменше 128 МіБ; більший мінімальний розмір ядра може збільшити образ. Це окремий файл від диска даних розміром 512 МіБ. |
| `build/disks/disk.img` | `make disks` | Окремий порожній допоміжний RAW-диск розміром 512 МіБ. IPO_OS не заповнює його програмами. |
| `build/disks/disk.iso` | `make disks` | Окремий порожній RAW-образ розміром 5 МіБ, який ціль запуску QEMU з Makefile підключає як віртуальний CD-ROM. Це не заповнена файлова система ISO. |

У поточному репозиторії немає цілі `make live-image` та утиліти `tools/create_live_image.py`.

## Керування образами дисків

У поточному дереві вихідного коду IPO_OS більше немає `disk_editor.py` та інструментів підготовки образів дисків на хості. Див. окремий проєкт [IPO_OS_Software](https://github.com/IPOleksenko/IPO_OS_Software), що містить утиліти для роботи з образами дисків.

## Фізичні носії

<Callout type="caution" title="Завантажувальний образ — це не готовий Live USB">
`build/IPO_OS.img` містить лише завантажувач і ядро; допоміжний диск даних створюється окремо. Не вважайте завантажувальний образ колишнім об'єднаним образом розміром 512 МіБ і не очікуйте, що він міститиме підготовлений том IPO_FS.
</Callout>
