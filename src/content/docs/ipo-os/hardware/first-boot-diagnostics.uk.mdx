# Первый запуск та POST-діагностика

После подачи питания на собранный компьютер аппаратная діагностика предоставляет мгновенную информацию про стані компонентов та контрольных точках загрузки.

---

## 🖥️ Признаки нормального запуска системы

При справному обладнанні запуск відбувається наступним чином:
1. **Вентилятори та живлення:** Вентилятор кулера CPU та БЖ починають обертатися одразу після натискання кнопки Power.
2. **Системний динамік (Speaker):** Через 1–3 секунди лунає один короткий одиночний сигнал апаратного POST, після чого під час завершення ініціалізації драйверів ядро програє через PC Speaker 4-нотну мелодію (C6-E6-G6-C7).
3. **Зображення на моніторі:** Монітор виходить з режиму очікування, на екрані з'являється текстовий режим VGA 80x25 (Mode 03h).
4. **Виведення в COM-порт:** До порту COM1 (`0x3F8`) надходять діагностичні логи ядра на швидкості **115200 бод, 8N1** (`[mount] success at lba 2048...`, `[driver] registered...`, `[system_state] transition...`).
5. **Заголовок екрана та командний рядок:** У верхньому рядку стану (рядок 0) світло-зеленим кольором відображаються `IPO_OS` ліворуч і `Created by IPOleksenko` праворуч, а також індикатор активної мови. Нижче відображаються привітання та інтерактивне запрошення командного рядка:
   ```text
   Type "help" or "?" on the keyboard to view commands, shortcuts, and OS features.

   > 
   ```

## 🔊 Звуковые сигналы системного динамика (Beep Codes)

| Звуковой сигнал | Описание проблемы | Способ устранения |
| :--- | :--- | :--- |
| **1 короткий сигнал** | Тест POST успішно пройден | Штатный запуск; передача керування завантажувачу. |
| **Непрерывный частый писк** | Сбой линии питания БП | Проверить напряжения БП (+12V, +5V) мультиметром. |
| **Повторяющиеся длинные** | Пам'ять RAM не обнаружена | Переустановить планки RAM; оставить один модуль в Slot 0. |
| **1 длинный, 2 коротких** | Ошибка видеоадаптера | Проверить посадку видеокарты в слоте PCI/AGP та кабель. |
| **Тишина, тёмный экран** | Нет старта CPU / КЗ | Проверить кабель 12V 4-pin CPU; проверить стойки корпуса. |
