# Выбор платформы та чипсетів

Выбор правильной материнської плати та процесора имеет решающее значення при сборке физического компьютера для платформы IPO. Поскольку `IPO_Boot_ROM` выполняет прямую ініціалізацію пам'яті через Memory Reference Code (MRC), а `IPO_OS` обращается до стандартным регістрам контролеров, аппаратная часть має строго соответствовать поддерживаемым чипсетам.

---

## 🧭 Матрица совместимости наборов микросхем

| Семейство чипсетів | Поколение CPU | Статус | Поддержка MRC в Boot ROM | Требуемый режим дисків |
| :--- | :--- | :---: | :--- | :--- |
| **Intel i440FX / i440BX** | Pentium II / III | **Полная совместимость** | Встроенный MRC для SDRAM | Нативный 40-жильный PATA / IDE Master |
| **Intel Q35 / G33 / ICH9** | Core 2 Duo / Quad | **Полная совместимость** | Поддерживается (PAM ICH9 + опрос PCI) | SATA в режиме IDE / Legacy |
| **Intel 865G / 875P / ICH5** | Pentium 4 (Socket 478) | **Поддерживается с BIOS** | Требуется заводской BIOS / прошивка | Первичный контролер PATA / IDE |
| **Современные Intel Core (i3–i9)** | 1–14 поколения | **Не поддерживаются** | Требуют Intel FSP; Boot Guard блокирует SPI | Требуется эмуляция UEFI / AHCI |
| **AMD Zen (AM4 / AM5)** | Ryzen 1000–9000 | **Не поддерживаются** | Запуск через процесор безпеки AMD PSP | Нестандартный порядок начального сброса |

<Callout type="warning" lang="ru" title="Почему современные чипсети не подходят для кастомного Boot ROM">
Современные процесоры Intel та AMD не начинают виконання кода напрямую за адресиу `0xFFFFFFF0` в открытом флеш-чипе. Технология Intel Boot Guard криптографически перевіряє микрокод та таблицы FIT до снятия сигнала апаратного скидання. Платформы AMD используют ARM-сопроцесор PSP. Для прямых аппаратных экспериментов со сборкой Boot ROM выбирайте платформы на **Intel i440FX** або **Intel Q35/ICH9**.
</Callout>

## 🔌 Режимы развёртывания системы

При запуске на физическом компьютере доступны два варианта:

### Вариант 1: Полный стек Bare-Metal (IPO_Boot_ROM + IPO_Firmware + IPO_OS)
- Микросхема Flash на материнській платі перезаписывается образом `build/bootrom.bin` або `build/spi_flash.bin`.
- Процесор начинает виконання с аппаратного вектора `0xFFFFFFF0`.
- Требуется материнська плата i440FX або Q35 со съёмным або доступным для прищепки чипом SPI/DIP Flash.

### Вариант 2: Заводской BIOS материнської плати + IPO_OS
- Плата сохраняет оригинальный заводской BIOS.
- Накопитель (HDD, SSD або USB) форматируется в `IPO_FS` с завантажувачом MBR IPO_OS.
- Заводской BIOS проходит POST та передаёт управление в сектор MBR IPO_OS за адресиу `0x0000:7C00`.
- Совместим с широким спектром материнських плат x86 (включая Pentium 4, Athlon XP).
