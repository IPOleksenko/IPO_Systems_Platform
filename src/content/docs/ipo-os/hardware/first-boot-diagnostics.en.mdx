# First Boot & POST Diagnostics

Upon switching on power to your assembled system, hardware diagnostics provide immediate feedback regarding system health and software execution checkpoints.

---

## 🖥️ Normal Boot Symptoms

When functioning correctly, the boot sequence presents the following indicators:
1. **Power Supply & Fans:** The PSU fan and CPU cooler spin up immediately upon pressing the power button.
2. **Motherboard Speaker:** A single short, crisp beep sounds within 1–3 seconds from hardware POST, followed by a 4-note melodic chime (C6-E6-G6-C7) played through the PC speaker upon completing kernel initialization.
3. **Display Output:** The monitor wakes from standby, clearing to VGA 80x25 text mode (mode 03h).
4. **Serial Logging:** If connected to COM1 (`0x3F8`) via a null-modem cable, diagnostic logs stream at **115200 baud, 8N1** (`[mount] success at lba 2048...`, `[driver] registered...`, `[system_state] transition...`).
5. **Screen Header & Shell Prompt:** The top status row (line 0) renders `IPO_OS` in green on the left, and `Created by IPOleksenko` in green on the right, alongside the active keyboard language. Below, the welcome message and interactive prompt appear:
   ```text
   Type "help" or "?" on the keyboard to view commands, shortcuts, and OS features.

   > 
   ```

## 🔊 Speaker Beep Codes Reference

| Audio Signal | Problem Description | Recommended Remedy |
| :--- | :--- | :--- |
| **1 Short Beep** | POST successfully passed | Normal operation; control handed to firmware. |
| **Continuous Rapid Beeps** | Power Delivery Failure | Check PSU rails (+12V, +5V) with a multimeter. |
| **Repeating Long Beeps** | Memory (RAM) Not Detected | Re-seat RAM sticks; test one module in Slot 0. |
| **1 Long, 2 Short Beeps** | Video Adapter Error | Re-seat PCI/AGP VGA card; inspect monitor cable. |
| **No Beep, Blank Screen** | Dead CPU, Cleared CMOS, or Short | Check 12V 4-pin CPU cable; verify chassis standoffs. |
