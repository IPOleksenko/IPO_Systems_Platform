# Подготовка носителя и разметка

Для создания загрузочного накопителя под IPO_OS формируется бинарный образ диска с таблицей разделов MBR и разделом файловой системы **IPO_FS**, начинающимся с сектора **LBA 2048** (стандартная граница выравнивания 1 МБ).

---

## 💾 Структура дискового пространства (`build/IPO_OS.img`)

```
┌───────────────────┬────────────────────────┬───────────────────────────┬───────────────────────────┐
│ Сектор 0 (LBA 0)  │ Секторы 1–2029         │ Секторы 2030–2039         │ Сектор 2048 (LBA 2048)... │
│ MBR + Таблица     │ Загрузчик Stage 2      │ Storage Pool + Журнал WAL │ Раздел IPO_FS             │
│ разделов (0x55AA) │ и образ ядра IPO_OS    │ SB (2030/2039), WAL(31-38)│ Суперблок, биткарты, файлы│
└───────────────────┴────────────────────────┴───────────────────────────┴───────────────────────────┘
```

1. **Сектор 0 (MBR):** Содержит 512 байт первичного загрузчика Stage 1 и таблицу разделов MBR (Запись 1 указывает на раздел `IPO_FS` с типом `0x83` и началом в `LBA 2048`) с сигнатурой `0x55AA`.
2. **Секторы 1–2029:** Бинарный код загрузчика Stage 2 и ядра `IPO_OS` (в едином образе `build/IPO_OS.img`, создаваемом через `make live-image` / `tools/create_live_image.py`).
3. **Секторы 2030–2039 (Метаданные пула хранения и WAL):**
   - **LBA 2030:** Первичный суперблок многодискового пула (`storage_pool_raw_sb_t`, сигнатура `'POOL'`, CRC32).
   - **LBA 2031–2038:** 8 секторов журнала транзакций Write-Ahead Logging (**WAL**, 64 записи по 64 байта, сигнатура `'TXNL'`).
   - **LBA 2039:** Резервный суперблок пула (`Backup Superblock`) для автоматического восстановления.
4. **Сектор 2048 и далее:** Начало файловой системы `IPO_FS`. Суперблок `IPO_FS` расположен строго в секторе 2048.

## 🛠️ Работа с образом через `disk_editor.py`

В состав инструментов входит утилита `disk_editor.py`, позволяющая управлять файлами внутри образа диска без необходимости root-прав и монтирования loop-устройств:

<SharedCode id="disk-editor-cmds" lang="ru" />

### Доступные команды:
- `format`: Инициализирует файловую систему, форматируя суперблок и очищая таблицы дескрипторов.
- `ls [path]`: Выводит содержимое каталога (номер дескриптора, размер, имя).
- `cat <path>`: Выводит содержимое текстового файла в терминал.
- `mkdir <path>`: Создаёт новый каталог.
- `put <src> <dest>`: Копирует бинарный файл или скрипт с хост-машины внутрь образа диска.
- `rm <path>`: Удаляет файл или пустую директорию.

## ⚡ Запись образа на физический диск (`dd`)

<Callout type="caution" lang="ru" title="Внимание: Проверяйте имя целевого диска!">
Ошибка в указании буквы диска в утилите `dd` приведёт к **полной и необратимой потере данных** на вашей рабочей станции. Перед записью всегда сверяйте имя устройства через команду `lsblk`.
</Callout>

```bash
# 0. Соберите единый загрузочный образ Live USB (128 МБ):
make live-image

# 1. Определите имя подключенной флешки или CF-карты в системе Linux
lsblk -o NAME,SIZE,TYPE,MOUNTPOINT,MODEL

# 2. Размонтируйте автоматически подключенные разделы устройства
sudo umount /dev/sdX* 2>/dev/null || true

# 3. Запишите единый образ build/IPO_OS.img на физический диск (замените sdX на ваше устройство)
sudo dd if=build/IPO_OS.img of=/dev/sdX bs=4M status=progress conv=fsync

# 4. Сбросьте системные буферы записи
sync
```
После завершения команды `sync` извлеките накопитель и подключите его к целевому компьютеру.
