# Подготовка носителей и образы дисков

Текущая сборка IPO_OS создает загрузочный образ, вспомогательный диск данных и пустой RAW-образ CD-ROM как отдельные артефакты. Она не создает объединенный Live USB-образ размером 512 МиБ, описанный в старых инструкциях.

## Артефакты сборки

| Артефакт | Цель сборки | Содержимое |
| :--- | :--- | :--- |
| `build/IPO_OS.img` | `make image` | MBR-загрузчик, образ ядра и дополнение до размера раздела. При текущей геометрии MBR по умолчанию образ занимает не менее 128 МиБ; больший минимальный размер ядра может увеличить образ. Это отдельный файл от диска данных размером 512 МиБ. |
| `build/disks/disk.img` | `make disks` | Отдельный пустой вспомогательный RAW-диск размером 512 МиБ. IPO_OS не заполняет его приложениями. |
| `build/disks/disk.iso` | `make disks` | Отдельный пустой RAW-образ размером 5 МиБ, подключаемый целью запуска QEMU из Makefile как виртуальный CD-ROM. Это не заполненная файловая система ISO. |

В текущем репозитории нет цели `make live-image` и утилиты `tools/create_live_image.py`.

## Управление образами дисков

В текущем исходном дереве IPO_OS больше нет `disk_editor.py` и инструментов подготовки образов дисков на хосте. См. отдельный проект [IPO_OS_Software](https://github.com/IPOleksenko/IPO_OS_Software), содержащий утилиты для работы с образами дисков.

## Физические носители

<Callout type="caution" title="Загрузочный образ — это не готовый Live USB">
`build/IPO_OS.img` содержит только загрузчик и ядро; вспомогательный диск данных создается отдельно. Не считайте загрузочный образ прежним объединенным образом размером 512 МиБ и не ожидайте, что в нем будет подготовлен том IPO_FS.
</Callout>
