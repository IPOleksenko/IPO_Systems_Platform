# Эталонные аппаратные конфігурації

Для гарантии надёжности та предсказуемости были протестированы та всесторонне проверены три эталонные збирання ПК.

---

## 🛠️ Матрица эталонных конфигураций

### 1. Минимальная конфігурація «Ретро» (Конец 1990-х)
- **Целевое назначення:** Аутентичный ретрокомпьютинг, демонстрация работы на оригинальном железе эпохи конца 90-х.
- **Процесор:** Intel Pentium III (Katmai / Coppermine) 500–800 МГц (Socket 370 або Slot 1).
- **Материнська плата:** Intel i440BX / i440ZX ATX (наприклад, ASUS P3B-F, Abit BF6).
- **Пам'ять:** 128 МБ — 256 МБ PC100/PC133 SDRAM (тайминги CL2).
- **Накопитель:** 4 ГБ — 20 ГБ IDE HDD (Master на первичном канале IDE).
- **Видео:** 3dfx Voodoo 3 2000 AGP або S3 Trio3D PCI (VGA Mode 03h).
- **Сетевая карта:** Realtek RTL8139D PCI 10/100 Мбит/с.
- **Звук:** Creative Sound Blaster 16 ISA (CT2940).
- **Вимоги до БП:** 250W с мощной линией +5V (не менше 20A).

### 2. Рекомендуемая конфігурація «Рабочая станция» (Середина 2000-х)
- **Целевое назначення:** Высокая производительность, быстрая збирання, многозадачность в Window Manager, хостинг сетевых сервисов.
- **Процесор:** Intel Core 2 Duo E8400 (3.0 ГГц) або Core 2 Quad Q6600 (LGA 775).
- **Материнська плата:** На чипсеті Intel Q35 / G33 / ICH9 (наприклад, Intel DQ35JO).
- **Пам'ять:** 2 ГБ DDR2-800 МГц (2x 1 ГБ в двухканальном режиме).
- **Накопитель:** 120 ГБ 2.5" SATA SSD, подключённый до порту SATA 0 в режиме IDE Legacy.
- **Видео:** Интегрированное Intel GMA 3100 або дискретная карта NVIDIA GeForce 6200 PCI/PCIe.
- **Сетевая карта:** Отдельная PCI-карта Realtek RTL8139.
- **Звук:** Встроенный AC'97 або Creative Sound Blaster Live! PCI.
- **Вимоги до БП:** Качественный блок живлення ATX мощностью 300W–350W.

### 3. Экспериментальная конфігурація «Встраиваемая / Fanless»
- **Целевое назначення:** Робототехника, встраиваемые терминалы, бесшумные серверы.
- **Процесор/SoC:** Intel Atom D525 / N270 або Vortex86DX SoC (x86 32-bit).
- **Материнська плата:** Mini-ITX промышленная плата со слотом CompactFlash.
- **Пам'ять:** 512 МБ — 1 ГБ DDR2/DDR3 SO-DIMM.
- **Накопитель:** 8 ГБ промышленная карта CompactFlash в режиме True IDE.
- **Сетевая карта:** Встроенный контролер RTL8139 або отдельная PCI плата.
- **Вимоги до БП:** Внешний адаптер питания 12V DC-DC (60W–90W).
