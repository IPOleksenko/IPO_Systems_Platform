# Выбор платформы и чипсетов

Выбор правильной материнской платы и процессора имеет решающее значение при сборке физического компьютера для платформы IPO. Поскольку `IPO_Boot_ROM` выполняет прямую инициализацию памяти через Memory Reference Code (MRC), а `IPO_OS` обращается к стандартным регистрам контроллеров, аппаратная часть должна строго соответствовать поддерживаемым чипсетам.

---

## 🧭 Матрица совместимости наборов микросхем

| Семейство чипсетов | Поколение CPU | Статус | Поддержка MRC в Boot ROM | Требуемый режим дисков |
| :--- | :--- | :---: | :--- | :--- |
| **Intel i440FX / i440BX** | Pentium II / III | **Полная совместимость** | Встроенный MRC для SDRAM | Нативный 40-жильный PATA / IDE Master |
| **Intel Q35 / G33 / ICH9** | Core 2 Duo / Quad | **Полная совместимость** | Поддерживается (PAM ICH9 + опрос PCI) | SATA в режиме IDE / Legacy |
| **Intel 865G / 875P / ICH5** | Pentium 4 (Socket 478) | **Поддерживается с BIOS** | Требуется заводской BIOS / прошивка | Первичный контроллер PATA / IDE |
| **Современные Intel Core (i3–i9)** | 1–14 поколения | **Не поддерживаются** | Требуют Intel FSP; Boot Guard блокирует SPI | Требуется эмуляция UEFI / AHCI |
| **AMD Zen (AM4 / AM5)** | Ryzen 1000–9000 | **Не поддерживаются** | Запуск через процессор безопасности AMD PSP | Нестандартный порядок начального сброса |

<Callout type="warning" lang="ru" title="Почему современные чипсеты не подходят для кастомного Boot ROM">
Современные процессоры Intel и AMD не начинают выполнение кода напрямую по адресу `0xFFFFFFF0` в открытом флеш-чипе. Технология Intel Boot Guard криптографически проверяет микрокод и таблицы FIT до снятия сигнала аппаратного сброса. Платформы AMD используют ARM-сопроцессор PSP. Для прямых аппаратных экспериментов со сборкой Boot ROM выбирайте платформы на **Intel i440FX** или **Intel Q35/ICH9**.
</Callout>

## 🔌 Режимы развёртывания системы

При запуске на физическом компьютере доступны два варианта:

### Вариант 1: Полный стек Bare-Metal (IPO_Boot_ROM + IPO_Firmware + IPO_OS)
- Микросхема Flash на материнской плате перезаписывается образом `build/bootrom.bin` или `build/spi_flash.bin`.
- Процессор начинает исполнение с аппаратного вектора `0xFFFFFFF0`.
- Требуется материнская плата i440FX или Q35 со съёмным или доступным для прищепки чипом SPI/DIP Flash.

### Вариант 2: Заводской BIOS материнской платы + IPO_OS
- Плата сохраняет оригинальный заводской BIOS.
- Накопитель (HDD, SSD или USB) форматируется в `IPO_FS` с загрузчиком MBR IPO_OS.
- Заводской BIOS проходит POST и передаёт управление в сектор MBR IPO_OS по адресу `0x0000:7C00`.
- Совместим с широким спектром материнских плат x86 (включая Pentium 4, Athlon XP).
