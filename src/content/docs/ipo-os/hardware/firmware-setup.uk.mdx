# Налаштування параметрів BIOS/UEFI

Перед первым запуском IPO_OS на физическом компьютере необхідно скорректировать параметри CMOS BIOS для корректного сопряжения с ядром та завантажувачом.

---

## ⚙️ Обязательные параметри BIOS

### 1. Режим работы контролера SATA
<Callout type="caution" lang="ru" title="Критический параметр контролера дисків">
При использовании дисків SATA HDD або SSD на платах с южными мостами ICH7/ICH9 найдите в меню розділ **SATA Configuration** (или **On-Chip Serial ATA**) та переключите его в режим **IDE / Legacy / Compatible Mode**.
Не выбирайте режимы `RAID` або `Native AHCI`, поскольку базовое ядро IPO_OS взаимодействует с накопителем через классические регістры ATA (`0x1F0`–`0x1F7`).
</Callout>

### 2. Приоритет та порядок загрузки (Boot Sequence)
- **1-е пристрій загрузки (1st Boot Device):** Укажите целевой жёсткий диск (`Primary IDE Master` або `SATA Port 0`).
- **2-е пристрій:** USB-HDD (для возможности обновления файлів с внешнего носителя).
- **Hard Disk Boot Priority:** Если в системе несколько дисків, переместите диск с разметкой `IPO_FS` на первую позицию.

### 3. Режимы UEFI / CSM та Secure Boot
- **Режим загрузки (Boot Mode):** Переключите в **Legacy BIOS** або включите модуль **CSM (Compatibility Support Module)**.
- **Secure Boot:** Обязательно **Disabled (Отключён)**. IPO_OS использует стандартную структуру MBR реального режиму.
- **Fast Boot (Быстрая загрузка):** **Disabled**. Быстрая загрузка отключает ініціалізацію части шин та урезает тайм-аут раскрутки шпинделя HDD, из-за чего накопитель може не определиться.

### 4. Налаштування портів ввода-вывода (I/O Configuration)
- **Последовательный порт 1 (COM1):** Включить (Enabled) с базовым адресиом `0x3F8` та перериванням `IRQ 4`. Ядро IPO_OS дублирует отладочные повідомлення в порт COM1 со скоростью **115200 бод, 8N1**.
- **Дисковод гибких дисків (Floppy):** Если до плате не подключён дисківод 3.5", установите параметр `Drive A:` в значення **Disabled / None**. Это сэкономит 30 секунд ожидания опроса несуществующего привода при старте.
- **Plug and Play OS:** Установите в **No / Disabled**, щоб BIOS самостоятельно инициализировал шину PCI та распределил линии IRQ.
