# Первый запуск и POST-диагностика

После подачи питания на собранный компьютер аппаратная диагностика предоставляет мгновенную информацию о состоянии компонентов и контрольных точках загрузки.

---

## 🖥️ Признаки нормального запуска системы

При исправном оборудовании запуск протекает следующим образом:
1. **Вентиляторы и питание:** Вентилятор кулера CPU и БП начинают вращаться сразу после нажатия кнопки Power.
2. **Системный динамик (Speaker):** Через 1–3 секунды раздаётся один короткий одиночный сигнал аппаратного POST, после чего при завершении инициализации драйверов ядро проигрывает через PC Speaker 4-нотную мелодию (C6-E6-G6-C7).
3. **Изображение на мониторе:** Монитор выходит из дежурного режима, на экране появляется текстовый режим VGA 80x25 (Mode 03h).
4. **Вывод в COM-порт:** В порт COM1 (`0x3F8`) поступают диагностические логи ядра на скорости **115200 бод, 8N1** (`[mount] success at lba 2048...`, `[driver] registered...`, `[system_state] transition...`).
5. **Заголовок экрана и командная строка:** В верхней строке состояния (строка 0) светло-зелёным цветом выводятся `IPO_OS` слева и `Created by IPOleksenko` справа, а также индикатор активного языка. Ниже отображаются приветствие и интерактивное приглашение командной строки:
   ```text
   Type "help" or "?" on the keyboard to view commands, shortcuts, and OS features.

   > 
   ```

## 🔊 Звуковые сигналы системного динамика (Beep Codes)

| Звуковой сигнал | Описание проблемы | Способ устранения |
| :--- | :--- | :--- |
| **1 короткий сигнал** | Тест POST успешно пройден | Штатный запуск; передача управления загрузчику. |
| **Непрерывный частый писк** | Сбой линии питания БП | Проверить напряжения БП (+12V, +5V) мультиметром. |
| **Повторяющиеся длинные** | Память RAM не обнаружена | Переустановить планки RAM; оставить один модуль в Slot 0. |
| **1 длинный, 2 коротких** | Ошибка видеоадаптера | Проверить посадку видеокарты в слоте PCI/AGP и кабель. |
| **Тишина, тёмный экран** | Нет старта CPU / КЗ | Проверить кабель 12V 4-pin CPU; проверить стойки корпуса. |
