# First Boot & POST Diagnostics

Upon switching on power to your assembled system, hardware diagnostics provide immediate feedback regarding system health and software execution checkpoints.

---

## 🖥️ Normal Boot Symptoms

Gdy sprzęt działa poprawnie, sekwencja rozruchowa wykazuje następujące symptomy:
1. **Zasilacz i wentylatory:** Wentylatory zasilacza i procesora zaczynają wirować natychmiast po naciśnięciu przycisku zasilania.
2. **Głośnik płyty głównej (Speaker):** W ciągu 1–3 sekund rozlega się pojedynczy krótki sygnał dźwiękowy sprzętowego testu POST, po czym po zakończeniu inicjalizacji sterowników jądro odtwarza przez głośnik PC melodię złożoną z 4 tonów (C6-E6-G6-C7).
3. **Obraz na ekranie:** Monitor wybudza się ze stanu uśpienia i przełącza w tryb tekstowy VGA 80x25 (Tryb 03h).
4. **Wyjście szeregowe:** Na porcie COM1 (`0x3F8`) strumieniowane są logi diagnostyczne jądra z prędkością **115200 bodów, 8N1** (`[mount] success at lba 2048...`, `[driver] registered...`, `[system_state] transition...`).
5. **Nagłówek ekranu i wiersz poleceń:** W górnym wierszu stanu (wiersz 0) na jasnozielono wyświetlane są `IPO_OS` po lewej stronie oraz `Created by IPOleksenko` po prawej, wraz ze wskaźnikiem aktywnego języka. Poniżej pojawia się komunikat powitalny i interaktywny znak zachęty:
   ```text
   Type "help" or "?" on the keyboard to view commands, shortcuts, and OS features.

   > 
   ```

## 🔊 Speaker Beep Codes Dokumentacja referencyjna

| Audio Signal | Problem Description | Recommended Remedy |
| :--- | :--- | :--- |
| **1 Short Beep** | POST successfully passed | Normal operation; control handed to firmware. |
| **Continuous Rapid Beeps** | Power Delivery Failure | Check PSU rails (+12V, +5V) with a multimeter. |
| **Repeating Long Beeps** | Memory (RAM) Not Detected | Re-seat RAM sticks; test one module in Slot 0. |
| **1 Long, 2 Short Beeps** | Video Adapter Error | Re-seat PCI/AGP VGA card; inspect monitor cable. |
| **No Beep, Blank Screen** | Dead CPU, Cleared CMOS, or Short | Check 12V 4-pin CPU cable; verify chassis standoffs. |
