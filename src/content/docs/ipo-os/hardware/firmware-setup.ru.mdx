# Настройка параметров BIOS/UEFI

Перед первым запуском IPO_OS на физическом компьютере необходимо скорректировать параметры CMOS BIOS для корректного сопряжения с ядром и загрузчиком.

---

## ⚙️ Обязательные параметры BIOS

### 1. Режим работы контроллера SATA
<Callout type="caution" lang="ru" title="Критический параметр контроллера дисков">
При использовании дисков SATA HDD или SSD на платах с южными мостами ICH7/ICH9 найдите в меню раздел **SATA Configuration** (или **On-Chip Serial ATA**) и переключите его в режим **IDE / Legacy / Compatible Mode**.
Не выбирайте режимы `RAID` или `Native AHCI`, поскольку базовое ядро IPO_OS взаимодействует с накопителем через классические регистры ATA (`0x1F0`–`0x1F7`).
</Callout>

### 2. Приоритет и порядок загрузки (Boot Sequence)
- **1-е устройство загрузки (1st Boot Device):** Укажите целевой жёсткий диск (`Primary IDE Master` или `SATA Port 0`).
- **2-е устройство:** USB-HDD (для возможности обновления файлов с внешнего носителя).
- **Hard Disk Boot Priority:** Если в системе несколько дисков, переместите диск с разметкой `IPO_FS` на первую позицию.

### 3. Режимы UEFI / CSM и Secure Boot
- **Режим загрузки (Boot Mode):** Переключите в **Legacy BIOS** или включите модуль **CSM (Compatibility Support Module)**.
- **Secure Boot:** Обязательно **Disabled (Отключён)**. IPO_OS использует стандартную структуру MBR реального режима.
- **Fast Boot (Быстрая загрузка):** **Disabled**. Быстрая загрузка отключает инициализацию части шин и урезает тайм-аут раскрутки шпинделя HDD, из-за чего накопитель может не определиться.

### 4. Настройка портов ввода-вывода (I/O Configuration)
- **Последовательный порт 1 (COM1):** Включить (Enabled) с базовым адресом `0x3F8` и прерыванием `IRQ 4`. Ядро IPO_OS дублирует отладочные сообщения в порт COM1 со скоростью **115200 бод, 8N1**.
- **Дисковод гибких дисков (Floppy):** Если к плате не подключён дисковод 3.5", установите параметр `Drive A:` в значение **Disabled / None**. Это сэкономит 30 секунд ожидания опроса несуществующего привода при старте.
- **Plug and Play OS:** Установите в **No / Disabled**, чтобы BIOS самостоятельно инициализировал шину PCI и распределил линии IRQ.
