# Инженерные чек-листы збирання та перевірки

Используйте ці контрольные списки при сборке физического компьютера та начальном запуске системы для винятки типовых помилок.

---

## ✅ Чек-лист перевірки перед сборкой железа

- [ ] **Стан конденсаторов:** Проверены всі электролитические конденсаторы вокруг сокета CPU; вздутые крышки та следы электролита отсутствуют.
- [ ] **Стойки в корпусе:** Латунные стойки установлены строго в соответствии с отверстиями на плате (**1:1**); лишние стойки під текстолитом отсутствуют.
- [ ] **Сокет процесора:** Контакты сокета Socket 370 / LGA 775 осмотрены при ярком свете; погнутые та окисленные контакты отсутствуют.
- [ ] **Термопаста:** Капля розміром 4–5 мм нанесена за центру крышки процесора; кулер зафиксирован равномерно.
- [ ] **Защёлки оперативної пам'яті:** Боковые фиксаторы слотов RAM повністю защёлкнуты с обоих концов каждого модуля.
- [ ] **Кабели блока живлення:** Разъёмы ATX 24-pin та питания процесора CPU 4/8-pin 12V надёжно вставлены; тумблер на БП переведён в положение `|` (ВКЛ).
- [ ] **Ориентация шлейфа IDE:** Контакт 1 (красная полоса на краю шлейфа) совпадает с контактом 1 на плате та диску.
- [ ] **Перемычка на жёстком диску:** Джампер на загрузочном накопителе IDE установлен в положение **Master**.
- [ ] **Разъём передней панели JFP1:** Кнопка увімкнення `PWR_SW` та системный динамик (Speaker) подключены до соответствующим контактам.

---

## ⚙️ Чек-лист параметрів BIOS / CMOS

- [ ] **Режим контролера SATA:** Установлен в **IDE / Legacy / Compatible Mode** (НЕ AHCI та НЕ RAID).
- [ ] **Приоритет загрузки:** Первичный жёсткий диск выбран як **1st Boot Device**.
- [ ] **Эмуляция Legacy USB:** Включена (Enabled), что дозволяє USB-клавиатурам работать в реальному режимі.
- [ ] **Быстрая загрузка (Fast Boot):** **Отключена (Disabled)** для полноценного опроса шин та дисків.
- [ ] **Дисковод 3.5" (Floppy):** Установлен в **Disabled / None**, якщо физический привод отсутствует.
- [ ] **Последовательный порт COM1:** Включён за адресиу `0x3F8` с `IRQ 4`.
- [ ] **Plug and Play OS:** Установлен в **No / Disabled** (BIOS самостоятельно настраивает PCI).

---

## 🚦 Чек-лист первого запуска та діагностики

- [ ] **Тест питания:** Вентиляторы кулера та БП вращаются; запахи гари та дым отсутствуют.
- [ ] **Звуковой сигнал:** Через 1–3 секунды раздаётся один короткий одиночный сигнал спикера.
- [ ] **Видеосигнал:** Монитор выходит з спящего режима та переходить в VGA Mode 03h (текст 80x25).
- [ ] **POST-карта порту 0x80:** Значения на индикаторе карты сменяются від `0x10` до `0x31` без зависания на кодах помилок (`0x2E`, `0x3E`, `0xEE`).
- [ ] **Передача керування ядру:** Завантажувач передаёт управление ядру за адресиу `0x10000`.
- [ ] **Оболочка shell:** На экране появляется интерактивное приглашение `> `.
