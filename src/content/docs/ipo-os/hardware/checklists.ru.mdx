# Инженерные чек-листы сборки и проверки

Используйте эти контрольные списки при сборке физического компьютера и начальном запуске системы для исключения типовых ошибок.

---

## ✅ Чек-лист проверки перед сборкой железа

- [ ] **Состояние конденсаторов:** Проверены все электролитические конденсаторы вокруг сокета CPU; вздутые крышки и следы электролита отсутствуют.
- [ ] **Стойки в корпусе:** Латунные стойки установлены строго в соответствии с отверстиями на плате (**1:1**); лишние стойки под текстолитом отсутствуют.
- [ ] **Сокет процессора:** Контакты сокета Socket 370 / LGA 775 осмотрены при ярком свете; погнутые и окисленные контакты отсутствуют.
- [ ] **Термопаста:** Капля размером 4–5 мм нанесена по центру крышки процессора; кулер зафиксирован равномерно.
- [ ] **Защёлки оперативной памяти:** Боковые фиксаторы слотов RAM полностью защёлкнуты с обоих концов каждого модуля.
- [ ] **Кабели блока питания:** Разъёмы ATX 24-pin и питания процессора CPU 4/8-pin 12V надёжно вставлены; тумблер на БП переведён в положение `|` (ВКЛ).
- [ ] **Ориентация шлейфа IDE:** Контакт 1 (красная полоса на краю шлейфа) совпадает с контактом 1 на плате и диске.
- [ ] **Перемычка на жёстком диске:** Джампер на загрузочном накопителе IDE установлен в положение **Master**.
- [ ] **Разъём передней панели JFP1:** Кнопка включения `PWR_SW` и системный динамик (Speaker) подключены к соответствующим контактам.

---

## ⚙️ Чек-лист параметров BIOS / CMOS

- [ ] **Режим контроллера SATA:** Установлен в **IDE / Legacy / Compatible Mode** (НЕ AHCI и НЕ RAID).
- [ ] **Приоритет загрузки:** Первичный жёсткий диск выбран как **1st Boot Device**.
- [ ] **Эмуляция Legacy USB:** Включена (Enabled), что позволяет USB-клавиатурам работать в реальном режиме.
- [ ] **Быстрая загрузка (Fast Boot):** **Отключена (Disabled)** для полноценного опроса шин и дисков.
- [ ] **Дисковод 3.5" (Floppy):** Установлен в **Disabled / None**, если физический привод отсутствует.
- [ ] **Последовательный порт COM1:** Включён по адресу `0x3F8` с `IRQ 4`.
- [ ] **Plug and Play OS:** Установлен в **No / Disabled** (BIOS самостоятельно настраивает PCI).

---

## 🚦 Чек-лист первого запуска и диагностики

- [ ] **Тест питания:** Вентиляторы кулера и БП вращаются; запахи гари и дым отсутствуют.
- [ ] **Звуковой сигнал:** Через 1–3 секунды раздаётся один короткий одиночный сигнал спикера.
- [ ] **Видеосигнал:** Монитор выходит из спящего режима и переходит в VGA Mode 03h (текст 80x25).
- [ ] **POST-карта порта 0x80:** Значения на индикаторе карты сменяются от `0x10` до `0x31` без зависания на кодах ошибок (`0x2E`, `0x3E`, `0xEE`).
- [ ] **Передача управления ядру:** Загрузчик передаёт управление ядру по адресу `0x10000`.
- [ ] **Оболочка shell:** На экране появляется интерактивное приглашение `> `.
