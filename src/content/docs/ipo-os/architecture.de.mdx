# IPO_OS Architektur

**IPO_OS** is a bare-metal 32-bit x86 monolithic Betriebssystem designed to run on physical hardware and QEMU virtual machines.

<LocalizedDiagram id="vertical_platform_stack" />

---

## 🏛️ Monolithic Kernel Architektur

- **Protected Mode Kernel (Ring 0):** GDT/IDT tables, hardware interrupt dispatching.
- **TinyGL 3D Engine (OpenGL 1.1):** Kernel-space software 3D rasterizer with Z-buffering and lighting.
- **Fenstermanager (WM):** 60 FPS compositor async task, PS/2 software mouse pointer.
- **Audio Core:** Sound Blaster 16 DSP hardware driver (16-bit DMA Ch 5) and PC Speaker PWM.
- **Network Stack:** Realtek RTL8139 NIC, Ethernet II, ARP, IPv4, ICMP, UDP, TCP state machine, and POSIX Sockets.
- **IPO_FS Filesystem:** 64-bit extent-based storage engine with ATA PIO disk driver.
