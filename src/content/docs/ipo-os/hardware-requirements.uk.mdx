# Матрица вимог до оборудованию

Операційна система IPO_OS способна работать як на физическом оборудовании PC-AT, так та в виртуальных машинах. Поддерживаются компоненты архитектурного стандарта PC-совместимых ЭВМ с конца 1990-х за конец 2000-х годов.

---

## 📊 Спецификация системных вимог

| Подсистема | Минимальная конфігурація | Рекомендуемая конфігурація | Настройки виртуальной машини |
| :--- | :--- | :--- | :--- |
| **Процесор (CPU)** | Intel Pentium II / III або AMD K6-2 (300 МГц) | Intel Core 2 Duo / Quad (LGA 775) або Pentium 4 (1.8+ ГГц) | QEMU `-cpu pentium3` або `-cpu qemu32` |
| **Оперативна пам'ять (RAM)** | 32 МБ SDRAM | 128 МБ — 512 МБ DDR / DDR2 / DDR3 | QEMU `-m 2048` (2 ГБ базово проверено) |
| **Чипсет / Мост** | Intel i440FX + PIIX3/PIIX4 | Intel Q35 + ICH9 | QEMU `-machine pc` (i440FX) або `-machine q35` |
| **Контролер дисків** | Контролер IDE / PATA (Порты `0x1F0`–`0x1F7`) | Primary Master IDE або SATA в режиме совместимости IDE/Legacy | QEMU `-drive format=raw,if=ide,index=0` |
| **Видеоадаптер** | Стандартный VGA (Mode 03h, текст 80x25, 16 цветов) | VBE 2.0 / 3.0 / Bochs VBE Display Adapter (BGA) | QEMU `-vga std` |
| **Сетевая карта (NIC)** | Не потрібно (без сети) | Realtek RTL8139 PCI Fast Ethernet (10/100 Мбит/с) | QEMU `-device rtl8139,netdev=net0` |
| **Звуковая карта** | Встроенный системный динамик PC Speaker | Creative Sound Blaster 16 (эмуляция ISA/PCI) | QEMU `-device sb16` |
| **Устройства ввода** | Клавиатура PS/2 (контролер 8042) | Клавиатура PS/2 + трёхкнопочная мышь PS/2 | Стандартные PS/2 контролеры QEMU |

## ⚡ Проверенные аппаратные конфігурації

### Физические компьютеры:
1. **Intel Core 2 Duo E8400 (LGA 775) на материнській платі Intel Q35:**
   - 2 ГБ оперативної пам'яті DDR2.
   - SATA HDD в режиме BIOS IDE Legacy.
   - Интегрированная або дискретная сетевая карта Realtek RTL8139 PCI.
2. **Intel Pentium III Katmai (Slot 1) на материнській платі i440BX:**
   - 256 МБ PC100 SDRAM.
   - 40-жильный шлейф IDE с жёстким диском Seagate на 4 ГБ.
   - Звуковая карта Creative Sound Blaster 16 ISA.

### Виртуальные среды:
- **QEMU:** `qemu-system-i386` (Основная среда разработки та CI-тестов).
- **Bochs:** Высокоточный потактовый эмулятор процесора x86.
- **VirtualBox:** Профиль «Other / Unknown PC», дисківый контролер IDE, сетевая карта Realtek RTL8139.
