# Сборка IPO_OS из исходных кодов

В этом руководстве описывается процесс компиляции микроядра IPO_OS, системных утилит, формирования загрузочных образов дисков и работы с GNU Make.

---

## 🛠️ Необходимые зависимости

Убедитесь, что в системе установлены все требуемые инструменты:

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install -y build-essential gcc-multilib nasm make python3 qemu-system-x86
```

## 📁 Структура исходного кода

Дерево каталогов проекта разделено на изолированные слои:

```
IPO_OS/
├── Makefile                    # Главный управляющий сценарий сборки ядра
├── mk/                         # Модульные правила (config.mk, boot.mk, kernel.mk, image.mk, run.mk, clean.mk)
├── src/
│   ├── boot/                   # Загрузчик Stage 1/2, E820 (0x8FE0) и переход в Protected Mode
│   ├── kernel/                 # Ядро (SMP, планировщик, E820/kmalloc, KMOD, реестр устройств, syscalls)
│   ├── drivers/                # Драйверы (Storage Pool + WAL, block_dev, partition, ATA, RTL8139, VBE, SB16)
│   ├── fs/                     # 64-битная экстентная файловая система IPO_FS
│   ├── net/                    # Сетевой стек TCP/IP с динамическим rx_packet_buf и POSIX-сокетами
│   ├── graphics/               # Оконный менеджер и графическая подсистема TinyGL
│   └── include/                # Заголовочные файлы ядра и системы
└── tools/
    ├── generate_ksyms.py       # Генератор таблицы символов ядра для загрузчика KMOD (.kmd)
    └── setup-tap.sh            # Скрипт конфигурации виртуального сетевого интерфейса TAP

IPO_OS_Software/                # Отдельный репозиторий пользовательского окружения и приложений
├── Makefile                    # Главный сценарий сборки пользовательских компонентов
├── mk/                         # Модульные правила (applications.mk, lib.mk, toolchain.mk, disk.mk)
├── applications/               # Приложения: DOOM, TCC, MicroPython, NASM, редактор, 3D-демо
├── lib/                        # Пользовательские библиотеки: libc, libm, libstdc++, libapp, TinyGL, CRT
├── include/                    # Полные стандартные заголовки C99/POSIX/GL
├── assets/fonts/               # Исходные файлы шрифтов и генераторы IFNT
├── load_to_disk.sh             # Скрипт быстрой загрузки приложений на диск
└── tools/
    ├── load_applications.py    # Автоматическое форматирование и наполнение диска IPO_FS
    ├── disk_editor.py          # Редактор разделов и файлов дискового образа IPO_FS
    ├── build_font_db.py        # Компилятор баз консольных шрифтов (.fnt)
    └── create_live_image.py    # Сборщик гибридного Live ISO/USB
```

## 🔨 Команды сборки

### 1. Компиляция ядра и загрузчика (`IPO_OS`)
```bash
cd IPO_OS
make all
```
Выполняет двухпроходную сборку ядра (с генерацией таблицы символов `generate_ksyms.py`), компилирует драйверы, загрузчик, библиотеку ядра `libk.a` и формирует загрузочный образ **`build/IPO_OS.img`**.

### 2. Сборка приложений и наполнение диска (`IPO_OS_Software`)
```bash
cd ../IPO_OS_Software
make all
./load_to_disk.sh ../IPO_OS/build/disks/disk.img --format
```
Компилирует пользовательские библиотеки (`libc.a`, `libm.a`, `libstdc++.a`, `libapp.a`), прикладные программы (DOOM, редактор, 3D-демо), внутрисистемные компиляторы (TinyCC, Lua, MicroPython, NASM, GNU binutils), генерирует шрифтовые базы и форматирует/наполняет образ диска `disk.img` объёмом 512 МБ файловой системой IPO_FS.

### 3. Очистка артефактов
```bash
make clean
```
Удаляет все скомпилированные объектные файлы `.o`, бинарники `.bin`, `.elf` и сгенерированные таблицы символов.

## ⚙️ Флаги конфигурации Makefile

| Флаг | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `DEBUG` | `0` | При `1` собирает код с отладочной информацией (`-g -O0`) |
| `NET_MODE` | `tap` | Режим сети: `tap` (виртуальный сетевой мост, по умолчанию) или `user` (NAT через SLIRP) |
| `SERIAL_LOG` | `1` | Дублирование всех сообщений ядра в последовательный порт COM1 (`0x3F8`) |

### Примеры запуска:
```bash
# Сборка с отладкой и запуск под GDB:
make run DEBUG=1 QEMU_ARGS="-s -S"

# Запуск с пользовательской сетью SLIRP NAT:
make run NET_MODE=user
```
