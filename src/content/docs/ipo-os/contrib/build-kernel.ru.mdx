# Сборка IPO_OS из исходных кодов

В этом руководстве описывается процесс компиляции микроядра IPO_OS, системных утилит, формирования загрузочных образов дисков и работы с GNU Make.

---

## 🛠️ Необходимые зависимости

Убедитесь, что в системе установлены все требуемые инструменты:

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install -y build-essential gcc-multilib nasm make python3 qemu-system-x86
```

---

## 📁 Структура исходного кода

Дерево каталогов проекта разделено на изолированные слои:

```
IPO_OS/
├── Makefile                    # Главный управляющий сценарий сборки
├── mk/                         # Модульные правила (kernel.mk, image.mk, qemu.mk, apps.mk)
├── src/
│   ├── boot/                   # Загрузчик Stage 1/2, E820 (0x8FE0) и переход в Protected Mode
│   ├── kernel/                 # Ядро (SMP, планировщик, E820/kmalloc, KMOD, реестр устройств, syscalls)
│   ├── driver/                 # Драйверы (Storage Pool + WAL, block_dev, partition, ATA, RTL8139, VBE, SB16)
│   ├── file_system/            # 64-битная экстентная файловая система IPO_FS
│   ├── net/                    # Сетевой стек TCP/IP с динамическим rx_packet_buf и POSIX-сокетами
│   └── include/                # Заголовочные файлы ядра и публичного SDK
├── applications/               # Пользовательские приложения, TCC, MicroPython, DOOM и заголовки POSIX
└── tools/
    ├── generate_ksyms.py       # Генератор таблицы ~1560 символов ядра для загрузчика KMOD (.kmd)
    ├── create_live_image.py    # Сборщик единого загрузочного образа Live USB (build/IPO_OS.img)
    ├── format_disk_via_os.py   # Форматирование образа диска силами ядра IPO_OS в QEMU
    ├── disk_editor.py          # Редактор разделов и файлов дискового образа IPO_FS
    └── setup-tap.sh            # Скрипт конфигурации сетевого интерфейса TAP
```

## 🔨 Команды сборки

### 1. Полная компиляция и сборка образов
```bash
make all
```
Выполняет двухпроходную сборку ядра (с генерацией таблицы символов `generate_ksyms.py`), компилирует драйверы и пользовательские приложения, создаёт образы `build/disk.iso`, `build/disk.img` и единый загрузочный образ **`build/IPO_OS.img`**.

### 2. Форматирование дисков и сборка Live USB образа
```bash
make disks
make live-image
```
Создаёт образ `build/disk.img` объёмом 512 МБ с метаданными Storage Pool и журналом WAL (LBA 2030–2039), размечает `IPO_FS` с сектора LBA 2048, генерирует базы шрифтов, копирует приложения через `load_applications.py` и формирует единый загрузочный образ **`build/IPO_OS.img`**.

### 3. Очистка артефактов
```bash
make clean
```
Удаляет все скомпилированные объектные файлы `.o`, бинарники `.bin`, `.elf` и сгенерированные таблицы символов.

## ⚙️ Флаги конфигурации Makefile

| Флаг | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `DEBUG` | `0` | При `1` собирает код с отладочной информацией (`-g -O0`) |
| `NET_MODE` | `tap` | Режим сети: `tap` (виртуальный сетевой мост, по умолчанию) или `user` (NAT через SLIRP) |
| `SERIAL_LOG` | `1` | Дублирование всех сообщений ядра в последовательный порт COM1 (`0x3F8`) |

### Примеры запуска:
```bash
# Сборка с отладкой и запуск под GDB:
make run DEBUG=1 QEMU_ARGS="-s -S"

# Запуск с пользовательской сетью SLIRP NAT:
make run NET_MODE=user
```
