# Сборка IPO_OS из исходных кодов

В этом руководстве описывается процесс компиляции микроядра IPO_OS, системных утилит, формирования загрузочных образов дисков и работы с GNU Make.

---

## 🛠️ Необходимые зависимости

Убедитесь, что в системе установлены все требуемые инструменты:

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install -y build-essential gcc-multilib nasm make python3 qemu-system-x86
```

---

## 📁 Структура исходного кода

Дерево каталогов проекта разделено на изолированные слои:

```
IPO_OS/
├── Makefile             # Главный управляющий сценарий сборки
├── src/
│   ├── boot/            # Загрузчик Stage 1 (MBR) и Stage 2 (Protected Mode)
│   ├── kernel/          # Ядро (планировщик, менеджер памяти, системные вызовы)
│   ├── drivers/         # Драйверы оборудования (ATA, RTL8139, PIT, PS/2, COM1)
│   ├── fs/              # Реализация файловой системы IPO_FS
│   ├── net/             # Встроенный сетевой стек TCP/IP
│   ├── userland/        # Оболочка shell, системные утилиты и libc
│   └── include/         # Заголовочные файлы ядра и интерфейсов
└── tools/
    ├── disk_editor.py   # Редактор разделов и файлов дискового образа
    └── setup-tap.sh     # Скрипт конфигурации сетевого интерфейса TAP
```

---

## 🔨 Команды сборки

### 1. Полная компиляция
```bash
make all
```
Компилирует загрузчики, ядро в формате ELF, драйверы, стандартные утилиты и формирует файл образа `build/disk.img`.

### 2. Форматирование и запись диска
```bash
make disks
```
Создаёт 128-мегабайтный образ виртуального диска (`build/disk.img`), размечает файловую систему `IPO_FS`, создаёт `build/disk.iso` (5 МБ), собирает шрифты и копирует программы через `load_applications.py`.

### 3. Очистка артефактов
```bash
make clean
```
Удаляет все скомпилированные объектные файлы `.o`, бинарники `.bin`, `.elf` и образы `.img`.

## ⚙️ Флаги конфигурации Makefile

| Флаг | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `DEBUG` | `0` | При `1` собирает код с отладочной информацией (`-g -O0`) |
| `NET_MODE` | `user` | Режим сети: `user` (NAT через SLIRP) или `tap` (виртуальный сетевой мост) |
| `SERIAL_LOG` | `1` | Дублирование всех сообщений ядра в последовательный порт COM1 (`0x3F8`) |

### Примеры запуска:
```bash
# Сборка с отладкой и запуск под GDB:
make run DEBUG=1 QEMU_ARGS="-s -S"

# Запуск с сетевым интерфейсом TAP:
make run NET_MODE=tap
```
