# Збирання IPO_OS з вихідних кодів

This guide explains how to compile the IPO_OS kernel and bootloader, generate bootable disk images, and run automated targets using GNU Make. Userland applications and libraries are maintained separately in IPO_OS_Software.

---

## 🛠️ Build Prerequisites

Verify you have installed the necessary toolchains:

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install -y build-essential gcc-multilib nasm make python3 qemu-system-x86
```

---

## 📁 Source Code Organization

The repository tree is organized into isolated modular layers:

```
IPO_OS/
├── Makefile                    # Root kernel build orchestrator
├── mk/                         # Modular build rules (config.mk, boot.mk, kernel.mk, image.mk, run.mk, clean.mk)
├── src/
│   ├── boot/                   # Stage 1/2 bootloader, E820 probe (0x8FE0), Protected Mode entry
│   ├── kernel/                 # Kernel core (SMP, scheduler, E820/kmalloc, KMOD, device registry, syscalls)
│   ├── drivers/                # Drivers (Storage Pool + WAL, block_dev, partition, ATA, RTL8139, VBE, SB16)
│   ├── fs/                     # 64-bit extent-based IPO_FS kernel implementation
│   ├── net/                    # Bare-metal TCP/IP stack with dynamic rx_packet_buf & POSIX sockets
│   ├── graphics/               # Window manager and TinyGL rendering core
│   └── include/                # Kernel and public system headers
└── tools/
    ├── generate_ksyms.py       # Extracts exported kernel symbols for runtime KMOD (.kmd) loader
    └── setup-tap.sh            # Virtual TAP network interface configurator

```

The userland ecosystem is a separate project: [IPO_OS_Software](https://github.com/IPOleksenko/IPO_OS_Software). It is not part of the IPO_OS source tree or built by IPO_OS `make all`.

---

## 🔨 Build Commands

### 1. Compile Kernel & Bootloader (`IPO_OS`)
```bash
cd IPO_OS
make all
```
The default `make all` target cleans prior outputs, builds the bootloader, kernel, and **`build/IPO_OS.img`**, creates the auxiliary disk images, and launches QEMU. Because the clean step removes `build/disks/`, back up any data stored there before running it.

### 2. Userland Applications (separate project)

IPO_OS builds its kernel and bootable image; it does not compile userland applications or populate the auxiliary disk with them. Application binaries, libraries, and disk tools are maintained in the separate [IPO_OS_Software repository](https://github.com/IPOleksenko/IPO_OS_Software).

### 3. Clean Build Artifacts
```bash
make clean
```
Removes the build outputs, including `build/IPO_OS.img` and the virtual disks under `build/disks/`. Back up any data stored in those disk images before running this command.
`make clean-disks` removes `build/disks/` without cleaning the other build outputs.

## ⚙️ Makefile Configuration Flags

| Flag | Default | Description |
| :--- | :--- | :--- |
| `DEBUG` | `0` | When set to `1`, compiles with `-g -O0` and enables verbose serial debugging |
| `NET_MODE` | `tap` | Режим мережі: `tap` (віртуальний мережевий міст, за замовчуванням) або `user` (NAT через SLIRP) |
| `SERIAL_LOG` | `1` | Mirrors all kernel console output to UART COM1 (`0x3F8`) |

### Example Invocations:
```bash
# Build in debug mode and run in QEMU with GDB stub:
make run DEBUG=1 QEMU_ARGS="-s -S"

# Run with user SLIRP NAT networking:
make run NET_MODE=user
```
