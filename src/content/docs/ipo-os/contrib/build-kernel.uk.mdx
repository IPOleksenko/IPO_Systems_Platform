# Збирання IPO_OS з вихідних кодів

В этом керівництві описывается процесс компиляции микроядра IPO_OS, системных утилит, формирования загрузочных образов дисків та работы с GNU Make.

---

## 🛠️ Необходимые зависимости

Убедитесь, что в системе установлены всі требуемые инструменты:

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install -y build-essential gcc-multilib nasm make python3 qemu-system-x86
```

---

## 📁 Структура вихідного коду

Дерево каталогов проекта розділено на изолированные слои:

```
IPO_OS/
├── Makefile             # Головний керуючий сценарій збирання
├── src/
│   ├── boot/            # Завантажувач Stage 1 (MBR) та Stage 2 (Protected Mode)
│   ├── kernel/          # Ядро (планувальник, менеджер пам'яті, системні виклики)
│   ├── drivers/         # Драйвери обладнання (ATA, RTL8139, PIT, PS/2, COM1)
│   ├── fs/              # Реалізація файлової системи IPO_FS
│   ├── net/             # Вбудований мережевий стек TCP/IP
│   ├── userland/        # Оболонка shell, системні утиліти та libc
│   └── include/         # Заголовні файли ядра та інтерфейсів
└── tools/
    ├── disk_editor.py   # Редактор розділів та файлів дискового образу
    └── setup-tap.sh     # Скрипт конфігурації мережевого інтерфейсу TAP
```

---

## 🔨 Команды збирання

### 1. Полная компиляция
```bash
make all
```
Компилирует завантажувачи, ядро в формате ELF, драйвери, стандартные утилиты та формирует файл образа `build/disk.img`.

### 2. Форматування та запис диска
```bash
make disks
```
Створює 128-мегабайтний образ віртуального диска (`build/disk.img`), розмічає файлову систему `IPO_FS`, створює `build/disk.iso` (5 МБ), збирає шрифти та копіює програми через `load_applications.py`.

### 3. Очищення артефактов
```bash
make clean
```
Удаляет всі скомпилированные объектные файли `.o`, бинарники `.bin`, `.elf` та образы `.img`.

## ⚙️ Флаги конфігурації Makefile

| Флаг | Значення за умолчанию | Описание |
| :--- | :--- | :--- |
| `DEBUG` | `0` | При `1` собирает код с отладочной информацией (`-g -O0`) |
| `NET_MODE` | `user` | Режим сети: `user` (NAT через SLIRP) або `tap` (виртуальный сетевой мост) |
| `SERIAL_LOG` | `1` | Дублирование всіх повідомлень ядра в последовательный порт COM1 (`0x3F8`) |

### Приклады запуска:
```bash
# Збирання з налагодженням та запуск під GDB:
make run DEBUG=1 QEMU_ARGS="-s -S"

# Запуск із мережевим інтерфейсом TAP:
make run NET_MODE=tap
```
