# Збирання IPO_OS з вихідних кодів

This guide explains how to compile the IPO_OS microkernel, build its userland utilities, generate bootable disk images, and run automated targets using GNU Make.

---

## 🛠️ Build Prerequisites

Verify you have installed the necessary toolchains:

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install -y build-essential gcc-multilib nasm make python3 qemu-system-x86
```

---

## 📁 Source Code Organization

The repository tree is organized into isolated modular layers:

```
IPO_OS/
├── Makefile                    # Root build orchestrator
├── mk/                         # Modular build rules (kernel.mk, image.mk, qemu.mk, apps.mk)
├── src/
│   ├── boot/                   # Stage 1/2 bootloader, E820 probe (0x8FE0), Protected Mode entry
│   ├── kernel/                 # Kernel core (SMP, scheduler, E820/kmalloc, KMOD, device registry, syscalls)
│   ├── driver/                 # Drivers (Storage Pool + WAL, block_dev, partition, ATA, RTL8139, VBE, SB16)
│   ├── file_system/            # 64-bit extent-based IPO_FS implementation
│   ├── net/                    # Bare-metal TCP/IP stack with dynamic rx_packet_buf & POSIX sockets
│   └── include/                # Kernel and public SDK headers
├── applications/               # Userland apps, TCC, MicroPython, DOOM, and POSIX headers
└── tools/
    ├── generate_ksyms.py       # Extracts ~1,560 kernel symbols for runtime KMOD (.kmd) loader
    ├── create_live_image.py    # Builds unified bootable Live USB image (build/IPO_OS.img)
    ├── format_disk_via_os.py   # Formats disk image using IPO_OS kernel in headless QEMU
    ├── disk_editor.py          # IPO_FS partition and file editor
    └── setup-tap.sh            # TAP network interface configurator
```

---

## 🔨 Build Commands

### 1. Compile Everything & Build Images
```bash
make all
```
Performs a two-pass kernel link (generating the `generate_ksyms.py` symbol table), compiles drivers and userland applications, and builds `build/disk.iso`, `build/disk.img`, and the unified **`build/IPO_OS.img`**.

### 2. Format Disks & Build Unified Live USB Image
```bash
make disks
make live-image
```
Initializes a 128 MB disk image (`build/disk.img`) with Storage Pool superblocks and WAL journal (LBA 2030–2039), formats `IPO_FS` at LBA 2048, populates applications via `load_applications.py`, and packages the unified bootable **`build/IPO_OS.img`**.

### 3. Clean Build Artifacts
```bash
make clean
```
Removes all compiled `.o`, `.bin`, `.elf`, and generated symbol files.

## ⚙️ Makefile Configuration Flags

| Flag | Default | Description |
| :--- | :--- | :--- |
| `DEBUG` | `0` | When set to `1`, compiles with `-g -O0` and enables verbose serial debugging |
| `NET_MODE` | `user` | Network mode: `user` (QEMU SLIRP NAT) or `tap` (bridged host TAP) |
| `SERIAL_LOG` | `1` | Mirrors all kernel console output to UART COM1 (`0x3F8`) |

### Example Invocations:
```bash
# Build in debug mode and run in QEMU with GDB stub:
make run DEBUG=1 QEMU_ARGS="-s -S"

# Run with bridged TAP networking:
make run NET_MODE=tap
```
