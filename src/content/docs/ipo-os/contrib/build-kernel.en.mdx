# Building IPO_OS from Source

This guide explains how to compile the IPO_OS microkernel, build its userland utilities, generate bootable disk images, and run automated targets using GNU Make.

---

## 🛠️ Build Prerequisites

Verify you have installed the necessary toolchains:

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install -y build-essential gcc-multilib nasm make python3 qemu-system-x86
```

---

## 📁 Source Code Organization

The repository tree is organized into isolated modular layers:

```
IPO_OS/
├── Makefile                    # Root kernel build orchestrator
├── mk/                         # Modular build rules (config.mk, boot.mk, kernel.mk, image.mk, run.mk, clean.mk)
├── src/
│   ├── boot/                   # Stage 1/2 bootloader, E820 probe (0x8FE0), Protected Mode entry
│   ├── kernel/                 # Kernel core (SMP, scheduler, E820/kmalloc, KMOD, device registry, syscalls)
│   ├── drivers/                # Drivers (Storage Pool + WAL, block_dev, partition, ATA, RTL8139, VBE, SB16)
│   ├── fs/                     # 64-bit extent-based IPO_FS kernel implementation
│   ├── net/                    # Bare-metal TCP/IP stack with dynamic rx_packet_buf & POSIX sockets
│   ├── graphics/               # Window manager and TinyGL rendering core
│   └── include/                # Kernel and public system headers
└── tools/
    ├── generate_ksyms.py       # Extracts exported kernel symbols for runtime KMOD (.kmd) loader
    └── setup-tap.sh            # Virtual TAP network interface configurator

IPO_OS_Software/                # Standalone userland applications & runtime ecosystem
├── Makefile                    # Master userland build orchestrator
├── mk/                         # Modular rules (applications.mk, lib.mk, toolchain.mk, disk.mk)
├── applications/               # Userland apps: DOOM, TCC, MicroPython, NASM, text editor, 3D demos
├── lib/                        # Userspace libraries: libc, libm, libstdc++, libapp, TinyGL, CRT stubs
├── include/                    # Complete C99/POSIX/GL standard library headers
├── assets/fonts/               # Console font assets and IFNT builders
├── load_to_disk.sh             # Ready-to-use disk image loader script
└── tools/
    ├── load_applications.py    # Automatic disk population & filesystem formatting utility
    ├── disk_editor.py          # Direct IPO_FS disk partition reader and editor
    ├── build_font_db.py        # Console font database (.fnt) compiler
    └── create_live_image.py    # Hybrid Live ISO/USB builder
```

## 🔨 Build Commands

### 1. Compile Kernel & Bootloader (`IPO_OS`)
```bash
cd IPO_OS
make all
```
Performs a two-pass kernel link (generating the `generate_ksyms.py` symbol table), compiles kernel HAL, drivers, and bootloader, and builds the bootable **`build/IPO_OS.img`**.

### 2. Compile Applications & Populate Virtual Disk (`IPO_OS_Software`)
```bash
cd ../IPO_OS_Software
make all
./load_to_disk.sh ../IPO_OS/build/disks/disk.img --format
```
Compiles userland libraries (`libc.a`, `libm.a`, `libstdc++.a`, `libapp.a`), applications (DOOM, editor, 3D demos), in-OS toolchains (TinyCC, Lua, MicroPython, NASM, GNU binutils), font databases, and formats/populates the 512 MB `disk.img` partition with IPO_FS.

### 3. Clean Build Artifacts
```bash
make clean
```
Removes all compiled `.o`, `.bin`, `.elf`, and generated symbol files.

## ⚙️ Makefile Configuration Flags

| Flag | Default | Description |
| :--- | :--- | :--- |
| `DEBUG` | `0` | When set to `1`, compiles with `-g -O0` and enables verbose serial debugging |
| `NET_MODE` | `tap` | Network mode: `tap` (bridged host TAP, default) or `user` (QEMU SLIRP NAT) |
| `SERIAL_LOG` | `1` | Mirrors all kernel console output to UART COM1 (`0x3F8`) |

### Example Invocations:
```bash
# Build in debug mode and run in QEMU with GDB stub:
make run DEBUG=1 QEMU_ARGS="-s -S"

# Run with user SLIRP NAT networking:
make run NET_MODE=user
```
