# Архитектура операційної системи IPO_OS

**IPO_OS** — це независимая 32-битная монолитная операційна система для архитектуры x86, разработанная для работы на физическом компьютерном оборудовании та в виртуальных машинах (QEMU).

## 🗺️ Карта фізичної пам'яті x86

<LocalizedDiagram id="memory_map" />

- `0x00000000`–`0x000003FF` (1 КБ): Таблица векторов переривань (IVT реального режиму).
- `0x00000400`–`0x000004FF` (256 Б): Область данных BIOS (BDA).
- `0x00000500`–`0x00007BFF`: Scratch RAM, очереди дескрипторов пристроїв, стек Boot ROM.
- `0x00007C00`–`0x00007DFF`: Область загрузки сектора MBR (Контракт 3).
- `0x0009FC00`–`0x0009FFFF`: Расширенная область данных BIOS (EBDA) та таблицы ACPI 1.0.
- `0x000A0000`–`0x000BFFFF`: Видеопам'ять графики VGA (A0000) та текстового режима (B8000).
- `0x000C0000`–`0x000FFFFF`: Shadow RAM (BIOS ROM, Pamela PAM0..PAM6 write-protected).
- `0x00100000`–`0x007FFFFF`: Ядро операційної системи (`kernel.bin`), таблицы IDT/GDT, буфери Sound Blaster 16 DMA (`0x600000`).
- `0x00800000`+: Простір завантаження активного користувацького застосунку (плоский бінарний формат, динамічний стек 256 КБ у `kmalloc`, купа `sbrk` від `0x08000000`).

## 🗄️ Файлова система IPO_FS (64-битная архитектура)

<LocalizedDiagram id="fs_layout" />

- **Суперблок:** Расположен в LBA 2048 с сигнатурой `'IPO_FS\0\0'`. Содержит 64-битные счетчики блоков та инодов.
- **Битовые карты:** Независимые битовые карты блоков данных та инодов.
- **Иноды (128 байт):** 4 встроенных экстента за 24 байта для непрерывного размещения данных на диску. Поддержка цепочек блоков экстентов для файлів произвольного розміра.
