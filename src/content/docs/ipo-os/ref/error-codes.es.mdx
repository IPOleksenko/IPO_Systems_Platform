# Referencia de Códigos de Error

In **IPO_OS**, kernel system calls at the hardware interrupt level (`int 0x80`) return `0` (or a positive integer count: bytes transferred, file descriptor index, or process ID) on success, and `-1` on error (`IPO_SYSCALL_ENOSYS = 0xFFFFFFFFu` or `-1`).

The userland C runtime library (`libc.a`, `src/userland/libc/sys.c`) catches syscall errors, sets the global `errno` variable to a standard positive code defined in `<errno.h>` (`applications/include/errno.h`), and returns `-1` (or `NULL` for memory allocators).

## 🛠️ Resolución de Errores Comunes

### `EFAULT` (`14`)
- Occurs when a buffer pointer passed to `read()`, `write()`, `stat()`, or `print()` points into kernel memory below `0x800000`, or when the user buffer spans into an unmapped page.
- **Fix:** Allocate memory on the heap with `malloc()` or ensure local buffers are properly sized on the stack.

### `EMFILE` (`24`)
- Occurs when the task opens more than 64 file descriptors without closing them.
- **Fix:** Verify every branch calling `ipo_open()` (`IPO_SYSCALL_FS_OPEN` `0x1011`) invokes `ipo_close()` (`IPO_SYSCALL_FS_CLOSE` `0x1018`).
