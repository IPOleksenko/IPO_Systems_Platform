# Справочник кодов ошибок

В операционной системе **IPO_OS** системные вызовы ядра на уровне прерывания `int 0x80` возвращают `0` (или неотрицательное число: количество байт, дескриптор, PID) при успехе и `-1` при ошибке (код `IPO_SYSCALL_ENOSYS = 0xFFFFFFFFu` или `-1`).

Пользовательская стандартная библиотека C (`libc.a`, `src/userland/libc/sys.c`) перехватывает ошибки системных вызовов и устанавливает значение глобальной переменной `errno` в одну из стандартных положительных констант, объявленных в заголовочном файле `<errno.h>` (`applications/include/errno.h`).

## 📋 Таблица кодов ошибок POSIX (`<errno.h>`)

| Значение `errno` | Имя константы | Описание и типичные причины |
| :--- | :--- | :--- |
| `0` | `0` (Success) | Успешно; операция выполнена без ошибок. |
| `1` | `EPERM` | Операция запрещена; недостаточно прав процесса. |
| `2` | `ENOENT` | Файл, каталог или дескриптор inode не найден. |
| `3` | `ESRCH` | Процесс с указанным PID не найден в диспетчере процессов. |
| `4` | `EINTR` | Системный вызов прерван сигналом или внешним событием. |
| `5` | `EIO` | Аппаратный сбой ввода/вывода (дефектный сектор ATA, таймаут шины). |
| `6` | `ENXIO` | Устройство или адрес ввода-вывода не существует. |
| `9` | `EBADF` | Некорректный или закрытый файловый дескриптор. |
| `11` | `EAGAIN` | Ресурс временно недоступен; повторите операцию. |
| `12` | `ENOMEM` | Закончилась память кучи (`sbrk` не смог выделить память). |
| `13` | `EACCES` | Доступ запрещён (попытка записи в файл только для чтения). |
| `14` | `EFAULT` | Ошибка адреса памяти; указатель буфера выходит за границы памяти процесса. |
| `16` | `EBUSY` | Устройство или ресурс заняты другим процессом. |
| `17` | `EEXIST` | Файл или каталог с таким именем уже существует на диске. |
| `20` | `ENOTDIR` | Часть указанного пути не является каталогом. |
| `21` | `EISDIR` | Попытка чтения или записи каталога как обычного файла. |
| `22` | `EINVAL` | Недопустимый аргумент, неверный флаг или некорректный параметр. |
| `24` | `EMFILE` | Превышен лимит открытых файлов процесса (максимум 64 дескриптора). |
| `28` | `ENOSPC` | В файловой системе IPO_FS закончились свободные блоки. |
| `30` | `EROFS` | Попытка изменения файловой системы, смонтированной только для чтения. |
| `32` | `EPIPE` | Обрыв канала или закрытие соединения сокета. |
| `38` | `ENOSYS` | Системный вызов не поддерживается или не зарегистрирован в ядре. |

## 🛠️ Устранение типичных ошибок

### `EFAULT` (`14`)
- Возникает, когда указатель на буфер, переданный в `read()`, `write()`, `stat()` или `print()`, указывает на память ядра ниже `0x800000`, либо если буфер попадает на невыделенную страницу.
- **Решение:** Выделяйте память через `malloc()` либо используйте локальные массивы в стеке процесса.

### `EMFILE` (`24`)
- Процесс открыл более 64 дескрипторов файлов без их закрытия.
- **Решение:** Проверьте все ветвления кода, вызывающие `ipo_open()` (`IPO_SYSCALL_FS_OPEN` `0x1011`), и обеспечьте обязательный вызов `ipo_close()` (`IPO_SYSCALL_FS_CLOSE` `0x1018`).
