# Полный справочник системных вызовов

В операционной системе **IPO_OS**, исполняющейся в плоском 32-битном защищенном режиме, системные вызовы через программный шлюз прерываний `int 0x80` (флаги IDT `0xEE`) служат аппаратно изолированным интерфейсом между процессами и привилегированными сервисами ядра.

## 🏛️ Соглашение о вызовах ядра (ABI Calling Convention)

При вызове прерывания `int 0x80` процессор сохраняет в стек ядра регистры `SS`, `ESP`, `EFLAGS`, `CS`, `EIP`, после чего ядро ожидает следующие параметры в регистрах x86:

| Регистр | Назначение | Описание |
| :--- | :--- | :--- |
| **`EAX`** | **Syscall Number** | Уникальный 32-битный номер системного вызова (например, `0x1011` для `open`) |
| **`EBX`** | **Argument Count** | Количество передаваемых параметров (`argc`, от 0 до 5) |
| **`ECX`** | **Arguments Pointer** | Указатель на массив аргументов в стеке пользователя (`const uint32_t *argv`) |
| **`EDX`** | *Резерв ядра* | Сохраняется обработчиком прерывания в стеке задачи |
| **`ESI`** | *Резерв ядра* | Сохраняется обработчиком прерывания в стеке задачи |
| **`EDI`** | *Резерв ядра* | Сохраняется обработчиком прерывания в стеке задачи |

<Callout type="note" title="Возвращаемое значение в EAX">
- **Успех:** Регистр `EAX` содержит $0$ или положительное число (число прочитанных/записанных байт, файловый дескриптор $\ge 0$, выделенный адрес памяти или PID).
- **Ошибка:** Регистр `EAX` содержит отрицательное число `-errno` (например, `-ENOENT`, `-EBADF`, `-ENOMEM`).
</Callout>

## 📁 Группа 1: Файловая система и хранилище IPO_FS

Подсистема VFS предоставляет 64-битные файловые операции для работы с дисковым пулом IPO_FS.

### `0x1010` — `IPO_SYSCALL_FS_CREATE`
- **C-сигнатура:** `int ipo_create(const char *path, uint8_t type);`
- **Параметры:** `args[0]` = канонический путь, `args[1]` = тип (`0x1` — каталог, `0x2` — файл).
- **Возврат:** `0` при успешном создании, либо `-EEXIST`, `-ENOSPC`, `-EINVAL`.

### `0x1011` — `IPO_SYSCALL_FS_OPEN`
- **C-сигнатура:** `int ipo_open(const char *path);`
- **Параметры:** `args[0]` = путь к целевому файлу.
- **Возврат:** Дескриптор файла `fd >= 0`, либо `-ENOENT`, `-EMFILE`.

### `0x1012` — `IPO_SYSCALL_FS_READ`
- **C-сигнатура:** `int ipo_read(int fd, void *buf, uint32_t count, uint32_t offset);`
- **Параметры:** `args[0]` = `fd`, `args[1]` = буфер, `args[2]` = число байт, `args[3]` = смещение в файле.
- **Возврат:** Количество фактически прочитанных байт, `0` при достижении конца файла (EOF), либо `-EBADF`.

### `0x1013` — `IPO_SYSCALL_FS_WRITE`
- **C-сигнатура:** `int ipo_write(int fd, const void *buf, uint32_t count, uint32_t offset);`
- **Параметры:** `args[0]` = `fd`, `args[1]` = буфер данных, `args[2]` = число байт, `args[3]` = смещение.
- **Возврат:** Число записанных байт, либо отрицательный код ошибки (`-ENOSPC`, `-EROFS`).

### `0x1014` — `IPO_SYSCALL_FS_DELETE`
- **C-сигнатура:** `int ipo_delete(const char *path);`
- **Параметры:** `args[0]` = путь к файлу или пустой директории.
- **Возврат:** `0` при успехе, либо `-ENOENT`, `-ENOTEMPTY`.

### `0x1015` — `IPO_SYSCALL_FS_STAT`
- **C-сигнатура:** `int ipo_stat(const char *path, struct ipo_inode *st);`
- **Параметры:** `args[0]` = путь к файлу, `args[1]` = указатель на структуру `struct ipo_inode`.
- **Возврат:** `0` при успехе (структура заполнена данными о размере, иноде, правах и экстентах).

### `0x1016` — `IPO_SYSCALL_FS_LIST`
- **C-сигнатура:** `int ipo_list_dir(const char *path, char *buf, int size);`
- **Параметры:** `args[0]` = путь к каталогу, `args[1]` = буфер, `args[2]` = вместимость буфера.
- **Возврат:** Количество записей каталога.

### `0x1017` — `IPO_SYSCALL_FS_RENAME`
- **C-сигнатура:** `int ipo_rename(const char *src, const char *dst);`
- **Параметры:** `args[0]` = старый путь, `args[1]` = новый путь.
- **Возврат:** `0` при успехе.

### `0x1018` — `IPO_SYSCALL_FS_CLOSE`
- **C-сигнатура:** `int ipo_close(int fd);`
- **Параметры:** `args[0]` = закрываемый файловый дескриптор.
- **Возврат:** `0` при успехе, либо `-EBADF`.

### `0x1019` — `IPO_SYSCALL_FS_SEEK`
- **C-сигнатура:** `int ipo_seek(int fd, int32_t offset, int whence);`
- **Параметры:** `args[0]` = `fd`, `args[1]` = смещение, `args[2]` = база (`0` = SEEK_SET, `1` = SEEK_CUR, `2` = SEEK_END).
- **Возврат:** Новое абсолютное смещение в файле.

### `0x1064` — `IPO_SYSCALL_FS_STATVFS`
- **C-сигнатура:** `int ipo_statvfs(ipo_fs_usage_t *usage_out);`
- **Параметры:** `args[0]` = указатель на структуру `ipo_fs_usage_t`.
- **Возврат:** `0` при успехе (заполняет общее, занятое и свободное число блоков и инодов в пуле хранения).

## ⚙️ Группа 2: Управление процессами и многозадачность

Управление жизненным циклом вытесняющих процессов ядра, виртуальными рабочими столами и асинхронными задачами.

### `0x1020` — `IPO_SYSCALL_EXEC`
- **C-сигнатура:** `int ipo_exec(const char *path, int argc, char **argv);`
- **Параметры:** `args[0]` = путь к бинарнику, `args[1]` = `argc`, `args[2]` = `argv`.
- **Возврат:** `PID` созданного процесса ($\ge 1$), либо `-ENOENT`, `-ENOEXEC`.

### `0x1023` — `IPO_SYSCALL_PROCESS_YIELD`
- **C-сигнатура:** `int ipo_yield(void);`
- **Назначение:** Добровольная уступка кванта процессора следующему процессу в очереди планировщика Round-Robin.

### `0x1024` — `IPO_SYSCALL_PROCESS_IS_FOREGROUND`
- **C-сигнатура:** `int ipo_is_foreground(void);`
- **Возврат:** `1` если процесс владеет активной консолью/терминалом, `0` если запущен в фоне.

### `0x1025` — `IPO_SYSCALL_GETCWD`
- **C-сигнатура:** `int ipo_getcwd(char *buf, uint32_t size);`
- **Возврат:** Длина скопированной строки текущего пути.

### `0x1026` — `IPO_SYSCALL_CHDIR`
- **C-сигнатура:** `int ipo_chdir(const char *path);`
- **Возврат:** `0` при успехе, либо `-ENOENT`.

### `0x1027` — `IPO_SYSCALL_GET_EXIT_CODE`
- **C-сигнатура:** `int ipo_get_exit_code(void);`
- **Возврат:** Код возврата последнего завершенного дочернего процесса (используется для конвейеров `|` в shell).

### `0x1028` — `IPO_SYSCALL_PROCESS_IS_BATCH_ACTIVE`
- **C-сигнатура:** `int ipo_is_batch_active(void);`
- **Возврат:** `1` если система выполняет составную команду пакетного режима (`run`), `0` в интерактивном режиме.

### `0x1029` — `IPO_SYSCALL_SET_RETURN_VALUE`
- **C-сигнатура:** `int ipo_set_return_value(int type, ...);`
- **Аргументы:** `args[0]` = тип возврата (`PROC_RET_INT`, `PROC_RET_STRING`, `PROC_RET_STRUCT`, `PROC_RET_POINTER`), `args[1]` = значение или указатель, `args[2]` = размер или имя типа, `args[3]` = имя типа.
- **Возвращает:** `0` при успехе или отрицательный код ошибки.
- **Назначение:** Явная установка типизированного возвращаемого значения для передачи структурированных данных через конвейер (`run`).

### `0x102A` — `IPO_SYSCALL_GET_RETURN_VALUE`
- **C-сигнатура:** `int ipo_get_return_value(char *buf, uint32_t max_len);`
- **Аргументы:** `args[0]` = указатель на буфер, `args[1]` = максимальная длина.
- **Возвращает:** Длину скопированной строки или отрицательный код ошибки.
- **Назначение:** Получение отформатированной строки возвращаемого значения последнего завершённого дочернего процесса.

### `0x1030` — `IPO_SYSCALL_ASYNC_START`
- **C-сигнатура:** `int ipo_async_start(const char *task_name, uint32_t interval_ms, void (*task_fn)(void));`
- **Назначение:** Регистрация периодической асинхронной задачи ядра с интервалом, заданным вызывающей стороной.
- **Возврат:** Идентификатор задачи `task_id >= 0`.

### `0x1031` — `IPO_SYSCALL_ASYNC_STOP`
- **C-сигнатура:** `int ipo_async_stop(int task_id);`
- **Назначение:** Остановка и удаление периодической асинхронной задачи.

### `0x107C` — `IPO_SYSCALL_GETPID`
- **C-сигнатура:** `int ipo_getpid(void);`
- **Возврат:** Уникальный числовой идентификатор текущего процесса (`PID`).

### `0x1080` — `IPO_SYSCALL_PROCESS_SWITCH_FG`
- **C-сигнатура:** `int ipo_process_switch_fg(uint32_t pid);`
- **Назначение:** Переключение фокуса ввода терминала и активного экранного буфера на процесс с указанным PID.

### `0xFFFF` — `IPO_SYSCALL_EXIT`
- **C-сигнатура:** `void ipo_exit(int status);`
- **Параметры:** `args[0]` = код завершения (`status`).
- **Поведение:** Не возвращает управление. Процесс немедленно уничтожается, открытые файлы закрываются, стек и куча освобождаются.

## 🧠 Группа 3: Управление памятью и кучей

Управление линейным адресным пространством процесса пользователя.

### `0x1045` — `IPO_SYSCALL_SBRK`
- **C-сигнатура:** `void *ipo_sbrk(int32_t increment);`
- **Параметры:** `args[0]` = приращение границы кучи в байтах.
- **Возврат:** Предыдущий указатель границы кучи (`break`), либо `(void*)-1` при нехватке свободной физической памяти.
- **Применение:** Основа реализации `malloc()` и `free()` в стандартной библиотеке `libc`.

### `0x1040` — `IPO_SYSCALL_STACK_GROW`
- **C-сигнатура:** `int ipo_stack_grow(uint32_t bytes);`
- **Назначение:** Динамическое увеличение максимального предела выделения стека процесса.

### `0x1041` — `IPO_SYSCALL_STACK_SHRINK`
- **C-сигнатура:** `int ipo_stack_shrink(uint32_t bytes);`
- **Назначение:** Освобождение неиспользуемой верхней памяти стека.

### `0x1047` — `IPO_SYSCALL_FREE`
- **C-сигнатура:** `void ipo_kfree(void *ptr);`
- **Назначение:** Освобождение динамических буферов, выделенных ядром для пространства пользователя.

## 🖥️ Группа 4: Терминал и текстовый ввод/вывод

### `0x1001` — `IPO_SYSCALL_PRINT`
- **C-сигнатура:** `int ipo_print(const char *text);`
- **Параметры:** `args[0]` = указатель на строку с завершающим нулем.
- **Поведение:** Выводит строку в активное окно консоли и дублирует в COM1 UART (115200 8N1).

### `0x1002` — `IPO_SYSCALL_WRITE`
- **C-сигнатура:** `int ipo_write(int fd, const void *buf, uint32_t count, uint32_t offset);`
- **Параметры:** `args[0]` = дескриптор (`1` = stdout, `2` = stderr), `args[1]` = буфер, `args[2]` = байты, `args[3]` = смещение.

### `0x1021` — `IPO_SYSCALL_READ`
- **C-сигнатура:** `int ipo_read_line(char *buf, uint32_t max_len);`
- **Параметры:** `args[0]` = буфер назначения (или `char**` при динамическом выделении), `args[1]` = максимальная длина (`0` для автовыделения через `kmalloc`).
- **Возврат:** Длина введенной строки.

### `0x1022` — `IPO_SYSCALL_TERMINAL_INPUT`
- **C-сигнатура:** `int ipo_terminal_input(const char *text, int auto_execute);`
- **Параметры:** `args[0]` = вставляемый текст, `args[1]` = `1` для автоматического выполнения (нажатие Enter) или `0` для подстановки в строку ввода.

## 🗄️ Группа 5: Разделяемые системные переменные ядра

Механизм легковесного межпроцессного обмена переменными (IPC).

### `0x1042` — `IPO_SYSCALL_VAR_SET`
- **C-сигнатура:** `int ipo_var_set(const char *name, const void *val, uint32_t sz);`
- **Макросы:** `IPO_VAR_SET(name, val)`, `IPO_VAR_SET_STR(name, str)`.

### `0x1043` — `IPO_SYSCALL_VAR_GET`
- **C-сигнатура:** `int ipo_var_get(const char *name, void *buf, uint32_t sz);`
- **Макросы:** `IPO_VAR_GET(name, &out_var)`, `IPO_VAR_GET_STR(name, buf, sz)`.

### `0x1044` — `IPO_SYSCALL_VAR_DELETE`
- **C-сигнатура:** `int ipo_var_delete(const char *name);`
- **Назначение:** Удаление переменной из глобальной таблицы ядра.

## ⌨️ Группа 6: Раскладки клавиатуры и шрифты

Управление интернационализацией, переключением языков и загружаемыми шрифтами VGA.

- **`0x1050` `IPO_SYSCALL_KEYMAP_SET`:** Регистрация новой динамической раскладки с таблицей сканкодов и глифами шрифта.
- **`0x1051` `IPO_SYSCALL_KEYMAP_GET`:** Получение идентификатора активной раскладки.
- **`0x1052` `IPO_SYSCALL_FONT_LOAD`:** Загрузка файла шрифта `.fnt` в знакогенератор VGA.
- **`0x1053` `IPO_SYSCALL_KEYMAP_DISABLE`:** Отключение раскладки из цикла переключения.
- **`0x1054` `IPO_SYSCALL_KEYMAP_ENABLE`:** Включение отключенной раскладки.
- **`0x1055` `IPO_SYSCALL_KEYMAP_REMOVE`:** Полное удаление раскладки из ядра.
- **`0x1056` `IPO_SYSCALL_KEYMAP_TRANSLATE`:** Преобразование сканкода PS/2 в символ активной раскладки.
- **`0x1057` `IPO_SYSCALL_KEYMAP_IS_ACTIVE`:** Проверка активности раскладки.
- **`0x1058` `IPO_SYSCALL_KEYMAP_CYCLE_NEXT`:** Переключение на следующую включенную раскладку.
- **`0x1059` `IPO_SYSCALL_KEYMAP_CYCLE_PREV`:** Переключение на предыдущую раскладку.
- **`0x105A` `IPO_SYSCALL_KEYMAP_GET_NAME`:** Получение текстовой метки раскладки ("EN", "RU", "UA", "ZH").
- **`0x105B` `IPO_SYSCALL_FONT_GET_INFO`:** Получение имени шрифта и числа загруженных глифов.
- **`0x105C` `IPO_SYSCALL_VGA_GLYPH`:** Отрисовка произвольного глифа Unicode на экране VGA.
- **`0x105D` `IPO_SYSCALL_VGA_SET_MODE`:** Переключение видеорежима (0x03 — текст, 0x13 — VGA 320x200x256, 0x118 — VBE).
- **`0x105E` `IPO_SYSCALL_VGA_GET_MODE`:** Запрос текущего активного видеорежима.

## 🧩 Группа 7: Динамические драйверы устройств

- **`0x1060` `IPO_SYSCALL_DRIVER_REGISTER`:** Регистрация динамического драйвера со структурой хуков `driver_t`.
- **`0x1061` `IPO_SYSCALL_DRIVER_UNREGISTER`:** Выгрузка динамического драйвера по имени.
- **`0x1062` `IPO_SYSCALL_DRIVER_LIST`:** Вывод списка всех зарегистрированных драйверов ядра.
- **`0x1063` `IPO_SYSCALL_DRIVER_SET_DESC`:** Установка текстового описания драйвера.

## 🪟 Группа 8: Оконный менеджер (Window Manager)

Композитор WM обновляется из активного цикла процесса/консоли; фиксированного ограничения 60 FPS нет:

- **`0x1070` `IPO_SYSCALL_WM_CREATE_WINDOW`:** Создание окна с рамкой, заголовком, буфером пикселей и колбэками.
- **`0x1071` `IPO_SYSCALL_WM_DESTROY_WINDOW`:** Закрытие и удаление окна.
- **`0x1072` `IPO_SYSCALL_WM_SESSION_START`:** Запуск графической сессии (VGA 320x200x256, выделение backbuffer, старт композитора).
- **`0x1073` `IPO_SYSCALL_WM_SESSION_STOP`:** Остановка графической сессии и возврат в текстовый режим 80x25.
- **`0x1074` `IPO_SYSCALL_WM_SESSION_ACTIVE`:** Проверка активности графической сессии.
- **`0x1075` `IPO_SYSCALL_WM_GET_COUNT`:** Количество активных окон на рабочем столе.
- **`0x1076` `IPO_SYSCALL_WM_GET_FOCUSED`:** Получение дескриптора окна с фокусом ввода.
- **`0x1077` `IPO_SYSCALL_WM_SET_FOCUS`:** Поднятие окна на вершину Z-order и передача фокуса.
- **`0x1078` `IPO_SYSCALL_WM_FOCUS_NEXT`:** Переключение фокуса на следующее окно (Alt+Tab).
- **`0x1079` `IPO_SYSCALL_WM_FOCUS_PREV`:** Переключение фокуса на предыдущее окно.
- **`0x107A` `IPO_SYSCALL_WM_INVALIDATE`:** Пометка окна dirty для перерисовки в следующем кадре.
- **`0x107B` `IPO_SYSCALL_WM_IS_VALID`:** Проверка существования окна в цепочке композитора.
- **`0x107D` `IPO_SYSCALL_WM_TOGGLE_MAXIMIZE`:** Разворачивание окна на весь экран или восстановление размера.
- **`0x107E` `IPO_SYSCALL_WM_RESIZE`:** Изменение геометрических размеров окна и перевыделение буфера.
- **`0x107F` `IPO_SYSCALL_WM_GET_LIST`:** Получение указателя на двусвязный список окон.

## ⏱️ Группа 9: Системные и управляющие вызовы

- **`0x0001` `IPO_SYSCALL_REGISTER`:** Динамическая регистрация нового системного вызова в таблице ядра.
- **`0x0002` `IPO_SYSCALL_CALL`:** Косвенный вызов системной функции.
- **`0x1046` `IPO_SYSCALL_TIME`:** Получение системного аптайма в секундах от старта ядра.
- **`0x105F` `IPO_SYSCALL_SYSTEM_INTERRUPT`:** Аппаратное управление системой: выключение питания через ACPI, аппаратная перезагрузка через контроллер клавиатуры 8042/порт 0x92, вызов паники ядра.

## 🌐 Группа 10: Сетевой стек и сокеты POSIX (`net/socket.h`)

Сетевые функции реализованы через высокоуровневый POSIX-совместимый интерфейс сокетов, транслируемый в вызовы драйвера сетевой карты Realtek RTL8139 и TCP/IP стека:

```c
#include <net/socket.h>

// Создание сокета
int socket(int domain, int type, int protocol); // AF_INET, SOCK_STREAM / SOCK_DGRAM

// Привязка к локальному адресу и порту
int bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen);

// Перевод в режим ожидания соединений
int listen(int sockfd, int backlog);

// Принятие входящего TCP-соединения
int accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen);

// Установка исходящего TCP-соединения
int connect(int sockfd, const struct sockaddr *addr, socklen_t addrlen);

// Отправка и прием данных
ssize_t send(int sockfd, const void *buf, size_t len, int flags);
ssize_t recv(int sockfd, void *buf, size_t len, int flags);

// Закрытие сокета
int close(int sockfd);

// Подключение к хосту по доменному имени или строковому IP
int connect_endpoint(int sockfd, const char *host_or_ip, uint16_t port);
```

## ⌨️ Группа 11: Системные вызовы клавиатуры и аппаратного ввода

Низкоуровневый доступ к контроллеру клавиатуры PS/2 8042 для интерактивных игр и приложений:

- **`0x10A0` `IPO_SYSCALL_KBD_GET_SCANCODE`:** `uint8_t ipo_kbd_get_scancode(void);` Неблокирующее чтение очередного аппаратного скан-кода клавиши.
- **`0x10A1` `IPO_SYSCALL_KBD_WAIT_SCANCODE`:** `uint8_t ipo_kbd_wait_scancode(void);` Блокировка вызывающего процесса до момента нажатия клавиши.
- **`0x10A2` `IPO_SYSCALL_KBD_SET_APP_MODE`:** `void ipo_kbd_set_app_mode(bool enabled);` Перенаправление потока событий клавиатуры напрямую в очередь процесса.
- **`0x10A3` `IPO_SYSCALL_KBD_FLUSH`:** `void ipo_kbd_flush(void);` Очистка очередей клавиатуры ядра и аппаратных буферов 8042.
- **`0x10A4` `IPO_SYSCALL_KBD_GET_MODIFIERS`:** `uint32_t ipo_kbd_get_modifiers(void);` Получение битовой маски активных модификаторов (Shift, Ctrl, Alt, CapsLock, NumLock).
- **`0x10A5` `IPO_SYSCALL_KBD_POLL`:** `void ipo_kbd_poll(void);` Опрос портов контроллера 8042 и диспетчеризация ожидающих событий.
- **`0x10A6` `IPO_SYSCALL_KBD_GET_KEY_STRING`:** `int ipo_kbd_get_key_string(uint8_t scancode, char *buf, uint32_t max_len);` Преобразование скан-кода в текстовое название клавиши.

## 🎨 Группа 13: Системные вызовы аппаратного VGA и курсора

Прямое управление регистрами текстового и графического контроллера VGA:

- **`0x10C0` `IPO_SYSCALL_VGA_SET_CURSOR`:** `void ipo_vga_set_cursor(uint16_t pos);` Установка позиции текстового курсора через порты CRTC `0x3D4`/`0x3D5`.
- **`0x10C1` `IPO_SYSCALL_VGA_GET_CURSOR`:** `uint16_t ipo_vga_get_cursor(void);` Чтение текущей позиции курсора из регистров CRTC.
- **`0x10C2` `IPO_SYSCALL_VGA_SHOW_CURSOR`:** `void ipo_vga_show_cursor(void);` Включение аппаратного мигающего текстового курсора.
- **`0x10C3` `IPO_SYSCALL_VGA_HIDE_CURSOR`:** `void ipo_vga_hide_cursor(void);` Скрытие аппаратного текстового курсора.
- **`0x10C4` `IPO_SYSCALL_VGA_SET_PALETTE`:** `void ipo_vga_set_palette(uint8_t index, uint8_t r, uint8_t g, uint8_t b);` Запись 6-битных компонент цвета RGB в регистры палитры VGA DAC (`0x3C8`/`0x3C9`).

## 🎵 Группа 14: Аудиоядро и потоковое воспроизведение

Управление аппаратным DSP Sound Blaster 16 и кольцевыми буферами воспроизведения звука:

- **`0x10D0` `IPO_SYSCALL_AUDIO_INIT`:** `bool ipo_audio_init(void);` Инициализация DSP Sound Blaster 16, DMA канала 5 и системного аудиомикшера.
- **`0x10D1` `IPO_SYSCALL_AUDIO_TICK`:** `void ipo_audio_tick(void);` Шаг микширования аудиопотоков и пополнение буферов DMA.
- **`0x10D2` `IPO_SYSCALL_AUDIO_STOP_ALL`:** `void ipo_audio_stop_all(void);` Остановка всех играющих аудиопотоков и отключение DMA Sound Blaster 16.
- **`0x10D3` `IPO_SYSCALL_AUDIO_STREAM_CREATE`:** `audio_stream_t *ipo_audio_stream_create(int format, int channels, uint32_t sample_rate, const void *data, size_t size);` Создание статического аудиопотока в памяти.
- **`0x10D4` `IPO_SYSCALL_AUDIO_STREAM_CREATE_RING`:** `audio_stream_t *ipo_audio_stream_create_ring(int format, int channels, uint32_t sample_rate, const void *data, size_t size, size_t ring_size);` Создание непрерывного кольцевого буферизованного аудиопотока.
- **`0x10D5` `IPO_SYSCALL_AUDIO_STREAM_DESTROY`:** `void ipo_audio_stream_destroy(audio_stream_t *stream);` Остановка и освобождение ресурсов аудиопотока.
- **`0x10D6` `IPO_SYSCALL_AUDIO_STREAM_PLAY`:** `void ipo_audio_stream_play(audio_stream_t *stream);` Запуск или возобновление воспроизведения аудиопотока.
- **`0x10D7` `IPO_SYSCALL_AUDIO_STREAM_PAUSE`:** `void ipo_audio_stream_pause(audio_stream_t *stream);` Приостановка воспроизведения аудиопотока с сохранением позиции.
- **`0x10D8` `IPO_SYSCALL_AUDIO_STREAM_STOP`:** `void ipo_audio_stream_stop(audio_stream_t *stream);` Остановка воспроизведения и сброс указателя на начало.
- **`0x10D9` `IPO_SYSCALL_AUDIO_STREAM_SEEK`:** `void ipo_audio_stream_seek(audio_stream_t *stream, double fraction);` Перемотка аудиопотока в относительную позицию (`0.0`..`1.0`).
- **`0x10DA` `IPO_SYSCALL_AUDIO_STREAM_SET_VOL`:** `void ipo_audio_stream_set_volume(audio_stream_t *stream, float volume);` Установка громкости аудиопотока (`0.0`..`1.0`).
- **`0x10DB` `IPO_SYSCALL_AUDIO_STREAM_PROGRESS`:** `void ipo_audio_stream_progress(audio_stream_t *stream, double *out_progress);` Запрос прогресса воспроизведения аудиопотока.
- **`0x10DC` `IPO_SYSCALL_AUDIO_STREAM_UPDATE`:** `void ipo_audio_stream_update_buffered(audio_stream_t *stream, size_t new_size, bool loop);` Запись новой порции сэмплов в кольцевой аудиопоток.
