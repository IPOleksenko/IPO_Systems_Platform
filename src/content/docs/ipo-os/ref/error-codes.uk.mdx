# Довідник кодів помилок

В операційній системі **IPO_OS** системні виклики ядра на рівні переривання `int 0x80` повертають `0` (або невід'ємне число: кількість байт, дескриптор, PID) при успіху та `-1` при помилці (код `IPO_SYSCALL_ENOSYS = 0xFFFFFFFFu` або `-1`).

Користувацька стандартна бібліотека C (`libc.a`, `src/userland/libc/sys.c`) перехоплює помилки системних викликів і встановлює значення глобальної змінної `errno` в одну зі стандартних додатних констант, оголошених у заголовку `<errno.h>` (`applications/include/errno.h`).

## 📋 Таблиця кодів помилок POSIX (`<errno.h>`)

| Значення `errno` | Ім'я константи | Опис та типові причини |
| :--- | :--- | :--- |
| `0` | `0` (Success) | Успішно; операція виконана без помилок. |
| `1` | `EPERM` | Операція заборонена; недостатньо прав процесу. |
| `2` | `ENOENT` | Файл, каталог або дескриптор inode не знайдено. |
| `3` | `ESRCH` | Процес із вказаним PID не знайдено в диспетчері процесів. |
| `4` | `EINTR` | Системний виклик перервано сигналом або зовнішньою подією. |
| `5` | `EIO` | Апаратний збій введення/виведення (дефектний сектор ATA, таймаут шини). |
| `6` | `ENXIO` | Пристрій або адреса введення-виведення не існує. |
| `9` | `EBADF` | Некоректний або закритий файловий дескриптор. |
| `11` | `EAGAIN` | Ресурс тимчасово недоступний; повторіть операцію. |
| `12` | `ENOMEM` | Закінчилася пам'ять купи (`sbrk` не зміг виділити пам'ять). |
| `13` | `EACCES` | Доступ заборонено (спроба запису у файл тільки для читання). |
| `14` | `EFAULT` | Помилка адреси пам'яті; вказівник буфера виходить за межі пам'яті процесу. |
| `16` | `EBUSY` | Пристрій або ресурс зайняті іншим процесом. |
| `17` | `EEXIST` | Файл або каталог із таким ім'ям уже існує на диску. |
| `20` | `ENOTDIR` | Частина вказаного шляху не є каталогом. |
| `21` | `EISDIR` | Спроба читання або запису каталогу як звичайного файлу. |
| `22` | `EINVAL` | Неприпустимий аргумент, невірний прапорець або некоректний параметр. |
| `24` | `EMFILE` | Перевищено ліміт відкритих файлів процесу (максимум 64 дескриптори). |
| `28` | `ENOSPC` | У файловій системі IPO_FS закінчилися вільні блоки. |
| `30` | `EROFS` | Спроба зміни файлової системи, змонтованої тільки для читання. |
| `32` | `EPIPE` | Обрив каналу або закриття з'єднання сокета. |
| `38` | `ENOSYS` | Системний виклик не підтримується або не зареєстрований у ядрі. |

## 🛠️ Усунення типових помилок

### `EFAULT` (`14`)
- Виникає, коли вказівник на буфер, переданий у `read()`, `write()`, `stat()` або `print()`, вказує на пам'ять ядра нижче `0x800000`, або якщо буфер потрапляє на невиділену сторінку.
- **Рішення:** Виділяйте пам'ять через `malloc()` або використовуйте локальні масиви в стеку процесу.

### `EMFILE` (`24`)
- Процес відкрив понад 64 дескриптори файлів без їх закриття.
- **Рішення:** Перевірте всі розгалуження коду, що викликають `ipo_open()` (`IPO_SYSCALL_FS_OPEN` `0x1011`), і забезпечте обов'язковий виклик `ipo_close()` (`IPO_SYSCALL_FS_CLOSE` `0x1018`).
