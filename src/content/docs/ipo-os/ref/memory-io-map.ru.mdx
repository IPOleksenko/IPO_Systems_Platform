# Карта памяти и портов ввода-вывода

На этой странице документирована полная аппаратная карта физической памяти и портов ввода-вывода, используемая в IPO_OS, IPO_Boot_ROM и IPO_Firmware.

---

## 🗺️ Физическая карта памяти

| Диапазон адресов | Размер | Назначение / Содержимое | Область |
| :--- | :--- | :--- | :--- |
| `0x00000000 - 0x000003FF` | 1 КБ | Таблица векторов прерываний реального режима (IVT) | Ядро |
| `0x00000400 - 0x000004FF` | 256 Б | Область данных BIOS (BDA) | Только чтение |
| `0x00000500 - 0x00005FFF` | ~22 КБ | Базовая конвенциональная память / буферы | Ядро |
| `0x00006000 - 0x000063FF` | 1 КБ | **Массив записей BIOS E820** (`e820_entry_t`, до 32 записей по 20 байт) | Слот передачи |
| `0x00007C00 - 0x00007DFF` | 512 Б | Буфер сектора MBR (`boot.asm`: 446 Б код + 64 Б таблица разделов + `0xAA55`) | Загрузка |
| `0x00008000 - 0x000080FF` | 256 Б | **Трамплин SMP AP (`smp_trampoline.asm`)** и почтовый ящик (`0x80F0`–`0x80FC`) | SMP Загрузка |
| `0x00008FE0 - 0x00008FF7` | 24 Б | **Заголовок карты памяти E820** (`'E820'`, число записей, указатель `0x6000`, объём RAM в `0x8FF0`) | Слот передачи |
| `0x00010000 - 0x0007FFFF` | ~448 КБ | **Бинарный образ ядра IPO_OS** (`.text`, `.rodata`, `.data`, `.bss`) | Ядро |
| `0x00080000 - 0x0009FBFF` | ~127 КБ | Буферы начальной загрузки ядра | Ядро |
| `0x0009FC00 - 0x0009FFFF` | 1 КБ | Расширенная область BIOS (EBDA) / Таблицы ACPI и MP | Только чтение |
| `0x000A0000 - 0x000BFFFF` | 128 КБ | Видеопамять VRAM (`0xA0000` граф. режим VGA, `0xB8000` текстовый буфер VGA) | Консоль VRAM |
| `0x000C0000 - 0x000C7FFF` | 32 КБ | Область расширения Video BIOS ROM | Только чтение |
| `0x000F0000 - 0x000FFFFF` | 64 КБ | **Образ IPO_Firmware / Boot_ROM** (PAM Shadow RAM) | Только чтение |
| `0x00100000 - 0x004FFFFF` | ~4 МБ | Буферы VFS, дисковый кэш ATA | Ядро |
| `0x00500000 - 0x0050FFFF` | 64 КБ | **Стек ядра BSP** (`0x500000`, задан в `entry32.asm`) | Ядро |
| `0x00800000 - 0x00FFFFFF` | 8 МБ | **Образ активного процесса** (`PROCESS_HEAP_START`, ELF32 / `.bin`, стек `0x00A00000`) | Процесс |
| `0x01000000 - 0x04FFFFFF` | 64 МБ | **Пул кучи ядра (`kmalloc`)** (динамические буферы, модули `.kmd`, стеки AP 16 КБ и процессов 256 КБ) | Куча ядра |
| `0x05000000 - 0x07FFFFFF` | 48 МБ | **Физический аллокатор регионов (`memory_map_alloc`)** | Ядро PMM |
| `0x08000000 - Верх RAM` | Переменн.| **Секционированные пользовательские кучи (`sbrk`)** (`0x08000000 + (pid-1)*512M`) | Кучи процессов |
| `0xFEE00000 - 0xFEE00FFF` | 4 КБ | **Регистры MMIO контроллера Local APIC** (ID ядра, SVR, TPR, EOI, ICR `INIT-SIPI-SIPI` и IPI `0xE0`) | SMP MMIO |

## 🔌 Карта портов ввода-вывода

| Диапазон портов | Устройство / Контроллер | Функция |
| :--- | :--- | :--- |
| `0x0020 - 0x0021` | Ведущий контроллер 8259A PIC | Командный регистр и маска прерываний |
| `0x0040 - 0x0043` | Таймер 8254 PIT | Данные канала 0 (1000 Гц), командный регистр (`0x43`) |
| `0x0060, 0x0064` | Контроллер PS/2 8042 | Порт данных (`0x60`), регистр статуса/команд (`0x64`) |
| `0x0080` | Диагностический порт | Шестнадцатеричный вывод POST (для плат диагностики) |
| `0x0092` | Порт управления System Control A | Вентиль Fast A20 (Бит 1), быстрый сброс (Бит 0) |
| `0x00A0 - 0x00A1` | Ведомый контроллер 8259A PIC | Командный регистр и маска прерываний |
| `0x0170 - 0x0177` | Вторичный канал ATA IDE | Регистры данных, ошибок, счётчика секторов, LBA |
| `0x01CE - 0x01CF` | Графика Bochs VBE | Регистр индекса (`0x1CE`), регистр данных (`0x1CF`) |
| `0x01F0 - 0x01F7` | Первичный канал ATA IDE | Регистры данных, ошибок, счётчика секторов, LBA |
| `0x0376` | Управление вторичным ATA | Регистр управления устройством / альтернативный статус |
| `0x03D4 - 0x03D5` | Видеоконтроллер VGA CRTC | Регистр индекса CRTC (`0x3D4`), регистр данных (`0x3D5`) |
| `0x03F6` | Управление первичным ATA | Регистр управления устройством / альтернативный статус |
| `0x03F8 - 0x03FF` | Последовательный порт COM1 | Приём/передача UART 16550A, делители скорости (115200 8N1) |
| `0x0CF8 - 0x0CFC` | Хост-мост PCI | Адрес конфигурации (`0xCF8`), данные (`0xCFC`) |
