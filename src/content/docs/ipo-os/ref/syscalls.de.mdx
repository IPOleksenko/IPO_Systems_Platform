# Complete Systemaufrufs Referenz

In **IPO_OS**, system calls serve as the primary protected gateway between processes and privileged kernel subsystem services in flat 32-bit Protected Mode. Syscalls are triggered via the x86 software interrupt gate `int 0x80` (IDT flags `0xEE`).

---

## 🏛️ Kernel ABI Calling Convention

When `int 0x80` is triggered, the CPU transfers execution to IDT gate `0x80` (`syscall_isr_entry` in `src/kernel/arch/x86/syscall.asm`), which marshals parameters into the C dispatcher with the following register state:

| Register | Role | Description |
| :--- | :--- | :--- |
| **`EAX`** | **Syscall Number** | Unique 32-bit Systemaufruf identifier (e.g., `0x1011` for `open`) |
| **`EBX`** | **Argument Count** | Number of arguments passed (`argc`, from 0 to 5) |
| **`ECX`** | **Arguments Pointer** | Pointer to stack array of 32-bit values (`const uint32_t *argv`) |
| **`EDX`** | *Kernel Preserved* | Preserved by interrupt frame across context switch |
| **`ESI`** | *Kernel Preserved* | Preserved by interrupt frame across context switch |
| **`EDI`** | *Kernel Preserved* | Preserved by interrupt frame across context switch |

<Callout type="note" title="Return Value in EAX">
- **Success:** `EAX` contains $0$ or positive integer (bytes transferred, file descriptor $\ge 0$, allocated memory pointer, or PID).
- **Error:** `EAX` contains negative `-errno` (e.g. `-ENOENT`, `-EBADF`, `-ENOMEM`).
</Callout>

## 📁 Group 1: Filesystem & IPO_FS Storage

VFS subsystem providing 64-bit storage operations on IPO_FS:

### `0x1010` — `IPO_SYSCALL_FS_CREATE`
- **C Signature:** `int ipo_create(const char *path, uint8_t type);`
- **Arguments:** `args[0]` = canonical path, `args[1]` = type (`0x1` = directory, `0x2` = file).
- **Returns:** `0` on success, or negative error code (`-EEXIST`, `-ENOSPC`, `-EINVAL`).

### `0x1011` — `IPO_SYSCALL_FS_OPEN`
- **C Signature:** `int ipo_open(const char *path);`
- **Arguments:** `args[0]` = path to target file.
- **Returns:** File descriptor `fd >= 0`, or negative error code (`-ENOENT`, `-EMFILE`).

### `0x1012` — `IPO_SYSCALL_FS_READ`
- **C Signature:** `int ipo_read(int fd, void *buf, uint32_t count, uint32_t offset);`
- **Arguments:** `args[0]` = `fd`, `args[1]` = destination buffer, `args[2]` = byte count, `args[3]` = file offset.
- **Returns:** Actual bytes read, `0` on EOF, or negative error code.

### `0x1013` — `IPO_SYSCALL_FS_WRITE`
- **C Signature:** `int ipo_write(int fd, const void *buf, uint32_t count, uint32_t offset);`
- **Arguments:** `args[0]` = `fd`, `args[1]` = source buffer, `args[2]` = byte count, `args[3]` = file offset.
- **Returns:** Bytes written to disk, or negative error code (`-ENOSPC`, `-EROFS`).

### `0x1014` — `IPO_SYSCALL_FS_DELETE`
- **C Signature:** `int ipo_delete(const char *path);`
- **Arguments:** `args[0]` = path to file or empty directory.
- **Returns:** `0` on success, or negative error code (`-ENOENT`, `-ENOTEMPTY`).

### `0x1015` — `IPO_SYSCALL_FS_STAT`
- **C Signature:** `int ipo_stat(const char *path, struct ipo_inode *st);`
- **Arguments:** `args[0]` = target path, `args[1]` = pointer to `struct ipo_inode`.
- **Returns:** `0` on success with populated inode size, extents, and permissions.

### `0x1016` — `IPO_SYSCALL_FS_LIST`
- **C Signature:** `int ipo_list_dir(const char *path, char *buf, int size);`
- **Arguments:** `args[0]` = directory path, `args[1]` = output buffer, `args[2]` = buffer capacity.
- **Returns:** Count of directory entries written.

### `0x1017` — `IPO_SYSCALL_FS_RENAME`
- **C Signature:** `int ipo_rename(const char *src, const char *dst);`
- **Arguments:** `args[0]` = source path, `args[1]` = destination path.
- **Returns:** `0` on success.

### `0x1018` — `IPO_SYSCALL_FS_CLOSE`
- **C Signature:** `int ipo_close(int fd);`
- **Arguments:** `args[0]` = file descriptor to release.
- **Returns:** `0` on success, or `-EBADF`.

### `0x1019` — `IPO_SYSCALL_FS_SEEK`
- **C Signature:** `int ipo_seek(int fd, int32_t offset, int whence);`
- **Arguments:** `args[0]` = `fd`, `args[1]` = offset delta, `args[2]` = whence (`0` = SEEK_SET, `1` = SEEK_CUR, `2` = SEEK_END).
- **Returns:** New absolute byte position within file.

## ⚙️ Group 2: Process Management & Multitasking

### `0x1020` — `IPO_SYSCALL_EXEC`
- **C Signature:** `int ipo_exec(const char *path, int argc, char **argv);`
- **Arguments:** `args[0]` = binary path, `args[1]` = `argc`, `args[2]` = `argv`.
- **Returns:** PID of spawned process ($\ge 1$), or negative error code.

### `0x1023` — `IPO_SYSCALL_PROCESS_YIELD`
- **C Signature:** `int ipo_yield(void);`
- **Purpose:** Voluntarily yields remaining CPU time slice to the scheduler.

### `0x1024` — `IPO_SYSCALL_PROCESS_IS_FOREGROUND`
- **C Signature:** `int ipo_is_foreground(void);`
- **Returns:** `1` if process currently owns terminal focus/display, `0` if background task.

### `0x1025` — `IPO_SYSCALL_GETCWD`
- **C Signature:** `int ipo_getcwd(char *buf, uint32_t size);`
- **Returns:** Copied path string length.

### `0x1026` — `IPO_SYSCALL_CHDIR`
- **C Signature:** `int ipo_chdir(const char *path);`
- **Returns:** `0` on success, or `-ENOENT`.

### `0x1027` — `IPO_SYSCALL_GET_EXIT_CODE`
- **C Signature:** `int ipo_get_exit_code(void);`
- **Returns:** Exit status code of most recently finished child process.

### `0x1028` — `IPO_SYSCALL_PROCESS_IS_BATCH_ACTIVE`
- **C Signature:** `int ipo_is_batch_active(void);`
- **Returns:** `1` if multitasking pipeline operator (`run`) is active, `0` in single task mode.

### `0x1030` — `IPO_SYSCALL_ASYNC_START`
- **C Signature:** `int ipo_async_start(void *task_fn, void *arg);`
- **Purpose:** Registers recurring kernel async task (e.g. 60 FPS WM compositor or network polling).
- **Returns:** Task ID handle `task_id >= 0`.

### `0x1031` — `IPO_SYSCALL_ASYNC_STOP`
- **C Signature:** `int ipo_async_stop(int task_id);`
- **Purpose:** Stops and deregisters recurring async task.

### `0x107C` — `IPO_SYSCALL_GETPID`
- **C Signature:** `int ipo_getpid(void);`
- **Returns:** Unique process ID (`PID`).

### `0x1080` — `IPO_SYSCALL_PROCESS_SWITCH_FG`
- **C Signature:** `int ipo_process_switch_fg(uint32_t pid);`
- **Purpose:** Switches active foreground terminal display and input to target PID.

### `0xFFFF` — `IPO_SYSCALL_EXIT`
- **C Signature:** `void ipo_exit(int status);`
- **Arguments:** `args[0]` = exit code status.
- **Behavior:** Never returns. Calling process is terminated and memory reclaimed.

## 🧠 Group 3: Speicherverwaltung & Heap

### `0x1045` — `IPO_SYSCALL_SBRK`
- **C Signature:** `void *ipo_sbrk(int32_t increment);`
- **Arguments:** `args[0]` = byte increment to move process heap break.
- **Returns:** Previous break address, or `(void*)-1` on out-of-memory.
- **Usage:** Prerequisite for userspace `malloc()` and `free()`.

### `0x1040` — `IPO_SYSCALL_STACK_GROW`
- **C Signature:** `int ipo_stack_grow(uint32_t bytes);`
- **Purpose:** Expands process stack memory allocation ceiling.

### `0x1041` — `IPO_SYSCALL_STACK_SHRINK`
- **C Signature:** `int ipo_stack_shrink(uint32_t bytes);`
- **Purpose:** Reclaims unused process stack memory.

### `0x1047` — `IPO_SYSCALL_FREE`
- **C Signature:** `void ipo_kfree(void *ptr);`
- **Purpose:** Releases kernel-allocated dynamic buffers returned to userspace.

## 🖥️ Group 4: Terminal & Console I/O

### `0x1001` — `IPO_SYSCALL_PRINT`
- **C Signature:** `int ipo_print(const char *text);`
- **Arguments:** `args[0]` = null-terminated string pointer.
- **Behavior:** Outputs text to active VGA screen and mirrors to COM1 serial.

### `0x1002` — `IPO_SYSCALL_WRITE`
- **C Signature:** `int ipo_write(int fd, const void *buf, uint32_t count, uint32_t offset);`
- **Arguments:** `args[0]` = `fd` (`1`=stdout, `2`=stderr), `args[1]` = buffer, `args[2]` = count, `args[3]` = offset.

### `0x1021` — `IPO_SYSCALL_READ`
- **C Signature:** `int ipo_read_line(char *buf, uint32_t max_len);`
- **Arguments:** `args[0]` = destination buffer (or `char**` for dynamic allocation), `args[1]` = capacity (`0` for dynamic alloc via `kmalloc`).
- **Returns:** Length of input line.

### `0x1022` — `IPO_SYSCALL_TERMINAL_INPUT`
- **C Signature:** `int ipo_terminal_input(const char *text, int auto_execute);`
- **Arguments:** `args[0]` = text string, `args[1]` = `1` to simulate Enter, `0` for buffer insertion.

## 🗄️ Group 5: Shared Kernel System Variables

Inter-process lightweight state sharing:

### `0x1042` — `IPO_SYSCALL_VAR_SET`
- **C Signature:** `int ipo_var_set(const char *name, const void *val, uint32_t sz);`
- **Convenience Macros:** `IPO_VAR_SET(name, val)`, `IPO_VAR_SET_STR(name, str)`.

### `0x1043` — `IPO_SYSCALL_VAR_GET`
- **C Signature:** `int ipo_var_get(const char *name, void *buf, uint32_t sz);`
- **Convenience Macros:** `IPO_VAR_GET(name, &out_var)`, `IPO_VAR_GET_STR(name, buf, sz)`.

### `0x1044` — `IPO_SYSCALL_VAR_DELETE`
- **C Signature:** `int ipo_var_delete(const char *name);`
- **Purpose:** Deletes shared variable from kernel table.

## ⌨️ Group 6: Keyboard Layouts & Fonts

- **`0x1050` `IPO_SYSCALL_KEYMAP_SET`:** Registers new layout with scancode map and unicode glyphs.
- **`0x1051` `IPO_SYSCALL_KEYMAP_GET`:** Gets active layout name.
- **`0x1052` `IPO_SYSCALL_FONT_LOAD`:** Loads bitmap font `.fnt` into VGA character generator.
- **`0x1053` `IPO_SYSCALL_KEYMAP_DISABLE`:** Disables layout from switching rotation.
- **`0x1054` `IPO_SYSCALL_KEYMAP_ENABLE`:** Re-enables layout.
- **`0x1055` `IPO_SYSCALL_KEYMAP_REMOVE`:** Completely deletes layout.
- **`0x1056` `IPO_SYSCALL_KEYMAP_TRANSLATE`:** Translates scancode through active keymap.
- **`0x1057` `IPO_SYSCALL_KEYMAP_IS_ACTIVE`:** Checks if layout is active.
- **`0x1058` `IPO_SYSCALL_KEYMAP_CYCLE_NEXT`:** Cycles to next enabled layout.
- **`0x1059` `IPO_SYSCALL_KEYMAP_CYCLE_PREV`:** Cycles to previous enabled layout.
- **`0x105A` `IPO_SYSCALL_KEYMAP_GET_NAME`:** Gets layout abbreviation ("EN", "RU", "UA", "ZH").
- **`0x105B` `IPO_SYSCALL_FONT_GET_INFO`:** Returns font name and glyph count.
- **`0x105C` `IPO_SYSCALL_VGA_GLYPH`:** Renders custom glyph to screen.
- **`0x105D` `IPO_SYSCALL_VGA_SET_MODE`:** Switches video mode (0x03=Text, 0x13=VGA 320x200, 0x118=VBE).
- **`0x105E` `IPO_SYSCALL_VGA_GET_MODE`:** Queries active video mode.

## 🧩 Group 7: Dynamic Runtime Drivers

- **`0x1060` `IPO_SYSCALL_DRIVER_REGISTER`:** Registers loadable driver with `driver_t`.
- **`0x1061` `IPO_SYSCALL_DRIVER_UNREGISTER`:** Unloads driver by name.
- **`0x1062` `IPO_SYSCALL_DRIVER_LIST`:** Lists active registered drivers.
- **`0x1063` `IPO_SYSCALL_DRIVER_SET_DESC`:** Sets driver descriptive metadata.

## 🪟 Group 8: Fenstermanager (WM)

Desktop Fenstermanager running as 60 FPS persistent kernel async task:

- **`0x1070` `IPO_SYSCALL_WM_CREATE_WINDOW`:** Creates managed desktop window with titlebar, borders, framebuffer, and event callbacks.
- **`0x1071` `IPO_SYSCALL_WM_DESTROY_WINDOW`:** Destroys window and frees framebuffer.
- **`0x1072` `IPO_SYSCALL_WM_SESSION_START`:** Enters VGA Mode 13h, allocates backbuffer, starts 60 FPS compositor task.
- **`0x1073` `IPO_SYSCALL_WM_SESSION_STOP`:** Stops compositor, restores 80x25 text mode.
- **`0x1074` `IPO_SYSCALL_WM_SESSION_ACTIVE`:** Returns true if GUI session active.
- **`0x1075` `IPO_SYSCALL_WM_GET_COUNT`:** Returns total registered windows count.
- **`0x1076` `IPO_SYSCALL_WM_GET_FOCUSED`:** Returns pointer to focused window.
- **`0x1077` `IPO_SYSCALL_WM_SET_FOCUS`:** Sets active window focus.
- **`0x1078` `IPO_SYSCALL_WM_FOCUS_NEXT`:** Cycles focus forward (Alt+Tab).
- **`0x1079` `IPO_SYSCALL_WM_FOCUS_PREV`:** Cycles focus backward.
- **`0x107A` `IPO_SYSCALL_WM_INVALIDATE`:** Marks window dirty for next compositor frame.
- **`0x107B` `IPO_SYSCALL_WM_IS_VALID`:** Validates window handle.
- **`0x107D` `IPO_SYSCALL_WM_TOGGLE_MAXIMIZE`:** Toggles fullscreen maximized state.
- **`0x107E` `IPO_SYSCALL_WM_RESIZE`:** Resizes window dimensions and reallocates framebuffer.
- **`0x107F` `IPO_SYSCALL_WM_GET_LIST`:** Returns pointer to active window linked list.

## ⏱️ Group 9: System Control & Timer

- **`0x0001` `IPO_SYSCALL_REGISTER`:** Dynamic syscall registration.
- **`0x0002` `IPO_SYSCALL_CALL`:** Indirect syscall invocation.
- **`0x1046` `IPO_SYSCALL_TIME`:** Returns system uptime in milliseconds.
- **`0x105F` `IPO_SYSCALL_SYSTEM_INTERRUPT`:** Hardware system controls: ACPI shutdown, 8042 reboot, kernel panic dump.
