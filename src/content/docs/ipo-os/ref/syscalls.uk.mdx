# Полный довідник системних викликів

В операційній системі **IPO_OS**, що виконується в плоскому 32-бітному захищеному режимі, системні виклики через програмний шлюз переривань `int 0x80` (прапорці IDT `0xEE`) слугують апаратно ізольованим інтерфейсом між процесами та привілейованими сервісами ядра.

## 🏛️ Соглашение про вызовах ядра (ABI Calling Convention)

При вызове переривання `int 0x80` процесор сохраняет в стек ядра регістры `SS`, `ESP`, `EFLAGS`, `CS`, `EIP`, після чего ядро ожидает следующие параметри в регістрах x86:

| Регістр | Назначення | Описание |
| :--- | :--- | :--- |
| **`EAX`** | **Syscall Number** | Уникальный 32-битный номер системного виклику (наприклад, `0x1011` для `open`) |
| **`EBX`** | **Argument Count** | Количество передаваемых параметрів (`argc`, від 0 до 5) |
| **`ECX`** | **Arguments Pointer** | Вказівник на массив аргументов в стеку користувача (`const uint32_t *argv`) |
| **`EDX`** | *Резерв ядра* | Сохраняется обработчиком переривання в стеку задачи |
| **`ESI`** | *Резерв ядра* | Сохраняется обработчиком переривання в стеку задачи |
| **`EDI`** | *Резерв ядра* | Сохраняется обработчиком переривання в стеку задачи |

<Callout type="note" title="Возвращаемое значення в EAX">
- **Успех:** Регістр `EAX` містить $0$ або положительное число (число прочитанных/записанных байт, файлівый дескриптор $\ge 0$, выделенный адреси пам'яті або PID).
- **Ошибка:** Регістр `EAX` містить отрицательное число `-errno` (наприклад, `-ENOENT`, `-EBADF`, `-ENOMEM`).
</Callout>

## 📁 Группа 1: Файлова система та хранилище IPO_FS

Подсистема VFS предоставляет 64-битные файлівые операции для работы с дисківым пулом IPO_FS.

### `0x1010` — `IPO_SYSCALL_FS_CREATE`
- **C-сигнатура:** `int ipo_create(const char *path, uint8_t type);`
- **Параметры:** `args[0]` = канонический путь, `args[1]` = тип (`0x1` — каталог, `0x2` — файл).
- **Возврат:** `0` при успешном создании, либо `-EEXIST`, `-ENOSPC`, `-EINVAL`.

### `0x1011` — `IPO_SYSCALL_FS_OPEN`
- **C-сигнатура:** `int ipo_open(const char *path);`
- **Параметры:** `args[0]` = путь до целевому файлу.
- **Возврат:** Дескриптор файлу `fd >= 0`, либо `-ENOENT`, `-EMFILE`.

### `0x1012` — `IPO_SYSCALL_FS_READ`
- **C-сигнатура:** `int ipo_read(int fd, void *buf, uint32_t count, uint32_t offset);`
- **Параметры:** `args[0]` = `fd`, `args[1]` = буфер, `args[2]` = число байт, `args[3]` = смещение в файлі.
- **Возврат:** Количество фактически прочитанных байт, `0` при достижении конца файлу (EOF), либо `-EBADF`.

### `0x1013` — `IPO_SYSCALL_FS_WRITE`
- **C-сигнатура:** `int ipo_write(int fd, const void *buf, uint32_t count, uint32_t offset);`
- **Параметры:** `args[0]` = `fd`, `args[1]` = буфер данных, `args[2]` = число байт, `args[3]` = смещение.
- **Возврат:** Число записанных байт, либо отрицательный код помилки (`-ENOSPC`, `-EROFS`).

### `0x1014` — `IPO_SYSCALL_FS_DELETE`
- **C-сигнатура:** `int ipo_delete(const char *path);`
- **Параметры:** `args[0]` = путь до файлу або пустой директории.
- **Возврат:** `0` при успехе, либо `-ENOENT`, `-ENOTEMPTY`.

### `0x1015` — `IPO_SYSCALL_FS_STAT`
- **C-сигнатура:** `int ipo_stat(const char *path, struct ipo_inode *st);`
- **Параметры:** `args[0]` = путь до файлу, `args[1]` = вказівник на структуру `struct ipo_inode`.
- **Возврат:** `0` при успехе (структура заполнена данными про розміре, иноде, правах та экстентах).

### `0x1016` — `IPO_SYSCALL_FS_LIST`
- **C-сигнатура:** `int ipo_list_dir(const char *path, char *buf, int size);`
- **Параметры:** `args[0]` = путь до каталогу, `args[1]` = буфер, `args[2]` = вместимость буфера.
- **Возврат:** Количество записей каталога.

### `0x1017` — `IPO_SYSCALL_FS_RENAME`
- **C-сигнатура:** `int ipo_rename(const char *src, const char *dst);`
- **Параметры:** `args[0]` = старый путь, `args[1]` = новый путь.
- **Возврат:** `0` при успехе.

### `0x1018` — `IPO_SYSCALL_FS_CLOSE`
- **C-сигнатура:** `int ipo_close(int fd);`
- **Параметры:** `args[0]` = закрываемый файлівый дескриптор.
- **Возврат:** `0` при успехе, либо `-EBADF`.

### `0x1019` — `IPO_SYSCALL_FS_SEEK`
- **C-сигнатура:** `int ipo_seek(int fd, int32_t offset, int whence);`
- **Параметры:** `args[0]` = `fd`, `args[1]` = смещение, `args[2]` = база (`0` = SEEK_SET, `1` = SEEK_CUR, `2` = SEEK_END).
- **Возврат:** Новое абсолютное смещение в файлі.

## ⚙️ Группа 2: Управление процессами та многозадачность

Управление жизненным циклом вытесняющих процессов ядра, виртуальными рабочими столами та асинхронными задачами.

### `0x1020` — `IPO_SYSCALL_EXEC`
- **C-сигнатура:** `int ipo_exec(const char *path, int argc, char **argv);`
- **Параметры:** `args[0]` = путь до бинарнику, `args[1]` = `argc`, `args[2]` = `argv`.
- **Возврат:** `PID` созданного процесса ($\ge 1$), либо `-ENOENT`, `-ENOEXEC`.

### `0x1023` — `IPO_SYSCALL_PROCESS_YIELD`
- **C-сигнатура:** `int ipo_yield(void);`
- **Назначення:** Добровольная уступка кванта процесора следующему процессу в очереди планировщика Round-Robin.

### `0x1024` — `IPO_SYSCALL_PROCESS_IS_FOREGROUND`
- **C-сигнатура:** `int ipo_is_foreground(void);`
- **Возврат:** `1` якщо процесс владеет активной консолью/терминалом, `0` якщо запущен в фоне.

### `0x1025` — `IPO_SYSCALL_GETCWD`
- **C-сигнатура:** `int ipo_getcwd(char *buf, uint32_t size);`
- **Возврат:** Длина скопированной рядка текущего пути.

### `0x1026` — `IPO_SYSCALL_CHDIR`
- **C-сигнатура:** `int ipo_chdir(const char *path);`
- **Возврат:** `0` при успехе, либо `-ENOENT`.

### `0x1027` — `IPO_SYSCALL_GET_EXIT_CODE`
- **C-сигнатура:** `int ipo_get_exit_code(void);`
- **Возврат:** Код возврата последнего завершенного дочернего процесса (используется для конвейеров `|` в shell).

### `0x1028` — `IPO_SYSCALL_PROCESS_IS_BATCH_ACTIVE`
- **C-сигнатура:** `int ipo_is_batch_active(void);`
- **Возврат:** `1` якщо система выполняет составную команду пакетного режима (`run`), `0` в интерактивном режиме.

### `0x1030` — `IPO_SYSCALL_ASYNC_START`
- **C-сигнатура:** `int ipo_async_start(void *task_fn, void *arg);`
- **Назначення:** Регістрация периодической асинхронной задачи ядра (наприклад, фоновый композитор WM с частотой 60 FPS або опрос сети).
- **Возврат:** Идентификатор задачи `task_id >= 0`.

### `0x1031` — `IPO_SYSCALL_ASYNC_STOP`
- **C-сигнатура:** `int ipo_async_stop(int task_id);`
- **Назначення:** Остановка та видалення периодической асинхронной задачи.

### `0x107C` — `IPO_SYSCALL_GETPID`
- **C-сигнатура:** `int ipo_getpid(void);`
- **Возврат:** Уникальный числовой идентификатор текущего процесса (`PID`).

### `0x1080` — `IPO_SYSCALL_PROCESS_SWITCH_FG`
- **C-сигнатура:** `int ipo_process_switch_fg(uint32_t pid);`
- **Назначення:** Переключение фокуса ввода терминала та активного экранного буфера на процесс с указанным PID.

### `0xFFFF` — `IPO_SYSCALL_EXIT`
- **C-сигнатура:** `void ipo_exit(int status);`
- **Параметры:** `args[0]` = код завершения (`status`).
- **Поведение:** Не повертає управление. Процесс немедленно уничтожается, открытые файли закрываются, стек та куча освобождаются.

## 🧠 Группа 3: Керування пам'яттю та кучей

Управление линейным адресиным пространством процесса користувача.

### `0x1045` — `IPO_SYSCALL_SBRK`
- **C-сигнатура:** `void *ipo_sbrk(int32_t increment);`
- **Параметры:** `args[0]` = приращение границы кучи в байтах.
- **Возврат:** Предыдущий вказівник границы кучи (`break`), либо `(void*)-1` при нехватке свободной фізичної пам'яті.
- **Применение:** Основа реализации `malloc()` та `free()` в стандартной библиотеке `libc`.

### `0x1040` — `IPO_SYSCALL_STACK_GROW`
- **C-сигнатура:** `int ipo_stack_grow(uint32_t bytes);`
- **Назначення:** Динамическое увеличение максимального предела выделения стека процесса.

### `0x1041` — `IPO_SYSCALL_STACK_SHRINK`
- **C-сигнатура:** `int ipo_stack_shrink(uint32_t bytes);`
- **Назначення:** Освобождение неиспользуемой верхней пам'яті стека.

### `0x1047` — `IPO_SYSCALL_FREE`
- **C-сигнатура:** `void ipo_kfree(void *ptr);`
- **Назначення:** Освобождение динамических буферів, выделенных ядром для пространства користувача.

## 🖥️ Группа 4: Терминал та текстовый ввод/вывод

### `0x1001` — `IPO_SYSCALL_PRINT`
- **C-сигнатура:** `int ipo_print(const char *text);`
- **Параметры:** `args[0]` = вказівник на рядок с завершающим нулем.
- **Поведение:** Выводит рядок в активное окно консоли та дублирует в COM1 UART (115200 8N1).

### `0x1002` — `IPO_SYSCALL_WRITE`
- **C-сигнатура:** `int ipo_write(int fd, const void *buf, uint32_t count, uint32_t offset);`
- **Параметры:** `args[0]` = дескриптор (`1` = stdout, `2` = stderr), `args[1]` = буфер, `args[2]` = байты, `args[3]` = смещение.

### `0x1021` — `IPO_SYSCALL_READ`
- **C-сигнатура:** `int ipo_read_line(char *buf, uint32_t max_len);`
- **Параметры:** `args[0]` = буфер назначення (или `char**` при динамическом выделении), `args[1]` = максимальная длина (`0` для автовыделения через `kmalloc`).
- **Возврат:** Длина введенной рядка.

### `0x1022` — `IPO_SYSCALL_TERMINAL_INPUT`
- **C-сигнатура:** `int ipo_terminal_input(const char *text, int auto_execute);`
- **Параметры:** `args[0]` = вставляемый текст, `args[1]` = `1` для автоматического виконання (нажатие Enter) або `0` для подстановки в рядок ввода.

## 🗄️ Группа 5: Розділяемые системные переменные ядра

Механизм легковесного межпроцессного обмена переменными (IPC).

### `0x1042` — `IPO_SYSCALL_VAR_SET`
- **C-сигнатура:** `int ipo_var_set(const char *name, const void *val, uint32_t sz);`
- **Макросы:** `IPO_VAR_SET(name, val)`, `IPO_VAR_SET_STR(name, str)`.

### `0x1043` — `IPO_SYSCALL_VAR_GET`
- **C-сигнатура:** `int ipo_var_get(const char *name, void *buf, uint32_t sz);`
- **Макросы:** `IPO_VAR_GET(name, &out_var)`, `IPO_VAR_GET_STR(name, buf, sz)`.

### `0x1044` — `IPO_SYSCALL_VAR_DELETE`
- **C-сигнатура:** `int ipo_var_delete(const char *name);`
- **Назначення:** Видалення переменной з глобальной таблицы ядра.

## ⌨️ Группа 6: Раскладки клавиатуры та шрифты

Управление интернационализацией, переключением языков та загружаемыми шрифтами VGA.

- **`0x1050` `IPO_SYSCALL_KEYMAP_SET`:** Регістрация новой динамической раскладки с таблицей сканкодов та глифами шрифта.
- **`0x1051` `IPO_SYSCALL_KEYMAP_GET`:** Получение идентификатора активной раскладки.
- **`0x1052` `IPO_SYSCALL_FONT_LOAD`:** Загрузка файлу шрифта `.fnt` в знакогенератор VGA.
- **`0x1053` `IPO_SYSCALL_KEYMAP_DISABLE`:** Вимкнення раскладки з цикла переключения.
- **`0x1054` `IPO_SYSCALL_KEYMAP_ENABLE`:** Увімкнення отключенной раскладки.
- **`0x1055` `IPO_SYSCALL_KEYMAP_REMOVE`:** Полное видалення раскладки з ядра.
- **`0x1056` `IPO_SYSCALL_KEYMAP_TRANSLATE`:** Преобразование сканкода PS/2 в символ активной раскладки.
- **`0x1057` `IPO_SYSCALL_KEYMAP_IS_ACTIVE`:** Перевірка активности раскладки.
- **`0x1058` `IPO_SYSCALL_KEYMAP_CYCLE_NEXT`:** Переключение на следующую включенную раскладку.
- **`0x1059` `IPO_SYSCALL_KEYMAP_CYCLE_PREV`:** Переключение на предыдущую раскладку.
- **`0x105A` `IPO_SYSCALL_KEYMAP_GET_NAME`:** Получение текстовой метки раскладки ("EN", "RU", "UA", "ZH").
- **`0x105B` `IPO_SYSCALL_FONT_GET_INFO`:** Получение имени шрифта та числа загруженных глифов.
- **`0x105C` `IPO_SYSCALL_VGA_GLYPH`:** Отрисовка произвольного глифа Unicode на экране VGA.
- **`0x105D` `IPO_SYSCALL_VGA_SET_MODE`:** Переключение видеорежима (0x03 — текст, 0x13 — VGA 320x200x256, 0x118 — VBE).
- **`0x105E` `IPO_SYSCALL_VGA_GET_MODE`:** Запрос текущего активного видеорежима.

## 🧩 Группа 7: Динамические драйвери пристроїв

- **`0x1060` `IPO_SYSCALL_DRIVER_REGISTER`:** Регістрация динамического драйвера со структурою хуков `driver_t`.
- **`0x1061` `IPO_SYSCALL_DRIVER_UNREGISTER`:** Выгрузка динамического драйвера за имени.
- **`0x1062` `IPO_SYSCALL_DRIVER_LIST`:** Вывод списка всіх зарегістрированных драйверів ядра.
- **`0x1063` `IPO_SYSCALL_DRIVER_SET_DESC`:** Установка текстового описания драйвера.

## 🪟 Группа 8: Віконний менеджер (Window Manager)

Віконний менеджер функционирует як постоянная асинхронная задача ядра с частотой обновления 60 FPS:

- **`0x1070` `IPO_SYSCALL_WM_CREATE_WINDOW`:** Створення окна с рамкой, заголовком, буфером пикселей та колбэками.
- **`0x1071` `IPO_SYSCALL_WM_DESTROY_WINDOW`:** Закрытие та видалення окна.
- **`0x1072` `IPO_SYSCALL_WM_SESSION_START`:** Запуск графической сессии (VGA 320x200x256, выделение backbuffer, старт композитора).
- **`0x1073` `IPO_SYSCALL_WM_SESSION_STOP`:** Остановка графической сессии та возврат в текстовый режим 80x25.
- **`0x1074` `IPO_SYSCALL_WM_SESSION_ACTIVE`:** Перевірка активности графической сессии.
- **`0x1075` `IPO_SYSCALL_WM_GET_COUNT`:** Количество активных окон на рабочем столе.
- **`0x1076` `IPO_SYSCALL_WM_GET_FOCUSED`:** Получение дескриптора окна с фокусом ввода.
- **`0x1077` `IPO_SYSCALL_WM_SET_FOCUS`:** Поднятие окна на вершину Z-order та передача фокуса.
- **`0x1078` `IPO_SYSCALL_WM_FOCUS_NEXT`:** Переключение фокуса на следующее окно (Alt+Tab).
- **`0x1079` `IPO_SYSCALL_WM_FOCUS_PREV`:** Переключение фокуса на предыдущее окно.
- **`0x107A` `IPO_SYSCALL_WM_INVALIDATE`:** Пометка окна dirty для перерисовки в следующем кадре.
- **`0x107B` `IPO_SYSCALL_WM_IS_VALID`:** Перевірка существования окна в цепочке композитора.
- **`0x107D` `IPO_SYSCALL_WM_TOGGLE_MAXIMIZE`:** Разворачивание окна на весь экран або відновлення розміра.
- **`0x107E` `IPO_SYSCALL_WM_RESIZE`:** Изменение геометрических розміров окна та перевыделение буфера.
- **`0x107F` `IPO_SYSCALL_WM_GET_LIST`:** Получение вказівника на двусвязный список окон.

## ⏱️ Группа 9: Системные та управляющие вызовы

- **`0x0001` `IPO_SYSCALL_REGISTER`:** Динамическая регістрация нового системного виклику в таблице ядра.
- **`0x0002` `IPO_SYSCALL_CALL`:** Косвенный вызов системной функції.
- **`0x1046` `IPO_SYSCALL_TIME`:** Получение системного аптайма в миллисекундах від старта ядра.
- **`0x105F` `IPO_SYSCALL_SYSTEM_INTERRUPT`:** Аппаратное управление системой: выключение питания через ACPI, аппаратная перезагрузка через контролер клавиатуры 8042/порт 0x92, вызов паники ядра.

## 🌐 Группа 10: Мережевий стек та сокеты POSIX (`net/socket.h`)

Сетевые функції реализованы через высокоуровневый POSIX-совместимый интерфейс сокетов, транслируемый в вызовы драйвера сетевой карты Realtek RTL8139 та TCP/IP стека:

```c
#include <net/socket.h>

// Створення сокета
int socket(int domain, int type, int protocol); // AF_INET, SOCK_STREAM / SOCK_DGRAM

// Прив'язка до локальної адреси та порту
int bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen);

// Переведення в режим очікування з'єднань
int listen(int sockfd, int backlog);

// Прийняття вхідного TCP-з'єднання
int accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen);

// Встановлення вихідного TCP-з'єднання
int connect(int sockfd, const struct sockaddr *addr, socklen_t addrlen);

// Відправлення та прийом даних
ssize_t send(int sockfd, const void *buf, size_t len, int flags);
ssize_t recv(int sockfd, void *buf, size_t len, int flags);
```
