# Стандартная библиотека C и среда выполнения

Поскольку стандартная библиотека GNU C (`glibc`) стандарта POSIX предполагает полноценное окружение ядра Linux с сигналами, потоками и динамическим загрузчиком, приложения IPO_OS линкуются с легковесной автономной средой выполнения C (`libc.a`).

---

## 📚 Поддерживаемые заголовочные файлы и функции

### 1. Форматированный ввод-вывод (`<stdio.h>`)
- `int printf(const char *format, ...)`: выводит форматированную строку в активную консоль и последовательный порт COM1. Поддерживает спецификаторы формата: `%s`, `%c`, `%d`, `%i`, `%u`, `%x`, `%X`, `%p`, `%%`.
- `int snprintf(char *str, size_t size, const char *format, ...)`: безопасное форматирование строк в буфер памяти.
- `int puts(const char *s)`: выводит строку с добавлением перевода строки.
- `int putchar(int c)`: выводит одиночный символ ASCII.

### 2. Утилиты строк и памяти (`<string.h>`)
- `size_t strlen(const char *s)`
- `int strcmp(const char *s1, const char *s2)`
- `int strncmp(const char *s1, const char *s2, size_t n)`
- `char *strcpy(char *dest, const char *src)`
- `char *strncpy(char *dest, const char *src, size_t n)`
- `void *memset(void *s, int c, size_t n)`
- `void *memcpy(void *dest, const void *src, size_t n)`
- `void *memmove(void *dest, const void *src, size_t n)`

### 3. Управление динамической памятью (`<stdlib.h>`)
- `void *malloc(size_t size)`: динамически выделяет память в куче процесса.
- `void free(void *ptr)`: возвращает блок памяти обратно в пул свободной памяти.
- `void *realloc(void *ptr, size_t size)`: изменяет размер ранее выделенного блока.
- `void *calloc(size_t nmemb, size_t size)`: выделяет и обнуляет память.
- `int atoi(const char *nptr)`: преобразует строку ASCII в целое число.
- `void exit(int status)`: сбрасывает буферы и завершает процесс через `IPO_SYSCALL_EXIT`.

## 🧱 Диспетчер динамической памяти

В файле `src/userland/libc/stdlib.c` управление динамической памятью реализовано через двусвязный список блоков с выравниванием по 8 байт, работающий поверх системного вызова `sbrk` (`IPO_SYSCALL_SBRK` `0x1045`):

```c
#define BLOCK_MAGIC 0x4D414C43 /* "MALC" */

typedef struct block_hdr {
    size_t size;               /* Размер полезной нагрузки в байтах */
    uint32_t magic;
    int is_free;
    struct block_hdr *next;
    struct block_hdr *prev;
} block_hdr_t;

#define HDR_SIZE sizeof(block_hdr_t)
#define ALIGN8(s) (((s) + 7u) & ~7u)
```

### Стратегия выделения памяти:
1. **Повторное использование (Free-List):** Сканирует список освобождённых блоков, проверяя сигнатуру `BLOCK_MAGIC`. Если найден блок подходящего размера, он используется повторно.
2. **Блочное расширение у ядра:** Когда куча исчерпана, память запрашивается у ядра блоками по **64 КБ** (`65536` байт), чтобы минимизировать накладные расходы системных вызовов.
3. **Контроль целостности:** Функция `free()` проверяет условие `magic == BLOCK_MAGIC` перед возвратом блока в список свободных, мгновенно выявляя повреждение памяти или попытки повторного освобождения (double-free).

## 🚫 Отличия рантайма IPO_OS от Linux glibc

| Возможность | Linux `glibc` | IPO_OS `libipo` |
| :--- | :--- | :--- |
| **Потоки** | Полные потоки POSIX pthreads | Кооперативные асинхронные задачи (`IPO_SYSCALL_ASYNC_START`) |
| **Локализация / Wide Chars** | Сложные таблицы локалей | Прямая передача UTF-8 и ASCII |
| **Динамическая линковка** | `dlopen()`, `dlsym()` | Статические плоские бинарные файлы с базой `0x800000` |
| **Файловые дескрипторы** | `read(fd, buf, count)` | `ipo_read(fd, buf, count, offset)` с явным 64-битным смещением |
| **Сигналы** | Более 32 сигналов POSIX | Перехват исключений CPU и выход через `process_crash_exit` |
