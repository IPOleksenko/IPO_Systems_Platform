# Пользовательский интерфейс, Shell, GUI и Мультимедиа

Операционная система **IPO_OS** предоставляет богатый спектр пользовательских интерфейсов:
1. **Консольный терминал Shell:** 27+ встроенных команд, фоновые виртуальные рабочие пространства (`run &`), конвейеры (`|`), история и ANSI-цвета.
2. **Оконный менеджер (Window Manager):** 2D рабочий стол в VGA Mode 13h (320x200x256), оконный композитинг 60 FPS, программный курсор мыши PS/2, события мыши и клавиатуры.
3. **3D Графика TinyGL (OpenGL 1.1):** Программный 3D растеризатор в ядре, поддержка Z-буфера, освещения, текстурирования и полигональных моделей.
4. **Звуковая подсистема:** Аппаратный драйвер Sound Blaster 16 (DSP, 16-бит DMA, 22050 Гц стерео микшер) и эмуляция PC Speaker PWM.

### ⚡ Многозадачные операторы команды `run`

Команда `run` позволяет конструировать сложные конвейеры выполнения:

```bash
# 1. Оператор '&' — запуск в ОТДЕЛЬНЫХ виртуальных рабочих столах (workspaces)
# Переключение между рабочими столами: Ctrl + Page Up / Ctrl + Page Down
run edit & player & hosting_server

# 2. Оператор '&&' — асинхронный параллельный запуск в ЕДИНОМ рабочем столе
# Позволяет запустить несколько GUI окон на одном общем десктопе
run wm_demo && wm_demo2 && wm_fullscreen

# 3. Оператор '|' — конвейер (ожидает завершения левой программы и передает код возврата)
run test_sb16 | player sound.raw

# 4. Оператор ';' — последовательное выполнение программ
run setfont /fonts/terminus.fnt ; startx
```

### ⌨️ Горячие клавиши терминала
- **`Ctrl + Page Up` / `Ctrl + Page Down`:** Переключение между независимыми виртуальными экранами многозадачности.
- **`Ctrl + Left Shift` / `Ctrl + Right Shift`:** Циклическое переключение активной раскладки клавиатуры.
- **`Alt + Left/Right Shift`:** Альтернативная комбинация смены языка ввода.
- **`Ctrl + C`:** Прерывание активного foreground-процесса или закрытие рабочего стола.
- **`Page Up` / `Page Down`:** Прокрутка истории терминала (до 128 строк scrollback-буфера).
- **`Стрелки Вверх / Вниз`:** Навигация по истории ранее введенных команд.

## 🪟 2. Оконный менеджер (Window Manager)

Оконный менеджер активируется командой `startx` и работает как постоянная асинхронная задача ядра с частотой кадров 60 FPS (тик каждые 16 мс):

### Структура окна (`wm_window_t`)
Каждое окно содержит:
- Собственный пиксельный буфер (`uint8_t *framebuf`) в памяти
- Координаты `(x, y)` и размеры `(w, h)`
- Заголовок окна и цветовую палитру (рамка, заголовок, фон)
- Колбэк отрисовки `draw_cb(wm_window_t *win)`
- Колбэк событий `event_cb(wm_window_t *win, uint32_t event, uint32_t data)`

### События оконного менеджера:
- `WM_EVENT_CLICK` — клик левой кнопкой мыши внутри окна
- `WM_EVENT_KEY_DOWN` / `WM_EVENT_KEY_UP` — нажатие и отпускание клавиши
- `WM_EVENT_FOCUS_IN` / `WM_EVENT_FOCUS_OUT` — получение и потеря фокуса ввода
- `WM_EVENT_MOVE` / `WM_EVENT_RESIZE` — перемещение или изменение размеров окна
- `WM_EVENT_CLOSE` — нажатие кнопки закрытия

<Callout type="tip" title="Кнопка аварийного выхода [✕]">
В левом нижнем углу графического экрана всегда отображается системная кнопка `[✕]`. Клик по ней левой кнопкой мыши или нажатие клавиши `ESC` гарантированно завершает графическую сессию и возвращает терминал в текстовый режим 80x25.
</Callout>

## 🧊 3. 3D Графический движок TinyGL (OpenGL 1.1)

IPO_OS включает встроенный в ядро программный 3D растеризатор **TinyGL**, реализующий спецификацию OpenGL 1.1 без необходимости наличия аппаратного GPU:

### Возможности TinyGL:
- **Матричные преобразования:** `glMatrixMode(GL_PROJECTION)`, `glLoadIdentity()`, `gluPerspective()`, `glTranslatef()`, `glRotatef()`, `glScalef()`.
- **Геометрические примитивы:** `GL_POINTS`, `GL_LINES`, `GL_TRIANGLES`, `GL_QUADS`, `GL_POLYGON`.
- **Освещение и материалы:** До 8 источников света (`GL_LIGHT0`), расчет диффузного, фонового и зеркального света, нормали вершин `glNormal3f()`.
- **Буфер глубины:** 16-битный аппаратный Z-буфер для корректного удаления невидимых граней.
- **Текстурирование:** Билинейная фильтрация текстур, форматы 2D текстур.
- **Блендинг и прозрачность:** Поддержка `glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA)`.

### Демонстрационные 3D приложения, входящие в состав ОС:
1. `gl_gears` — Классические вращающиеся шестерни OpenGL с расчетом FPS.
2. `gl_teapot` — Знаменитый чайник из Юты (Utah Teapot) с расчетом освещения и нормалей.
3. `gl_cube` — Цветной вращающийся 3D-куб.
4. `gl_fog` — Демонстрация объемного тумана.
5. `gl_blend` — Прозрачные пересекающиеся плоскости.
6. `gl_stencil` — Демонстрация работы с буфером трафарета.

## 🔊 4. Звуковая подсистема (Sound Blaster 16 и PC Speaker)

IPO_OS имеет двухуровневую аудиосистему:

### 1. Sound Blaster 16 (Аппаратный DSP)
- Базовый порт ввода-вывода: `0x220` (сброс, статус, чтение, запись).
- 16-битный DMA-контроллер: **Канал 5** (порты `0xD4`, `0xD6`, `0xC4`, `0x8B`, `0xC6`).
- Двойная аппаратная буферизация (Ping-Pong DMA buffers по адресам `0x600000` и `0x610000`).
- Стандартная частота дискретизации: **22050 Гц**, 16-бит, стерео.
- Программный микшер: Одновременное воспроизведение нескольких потоков с автоматическим ресемплингом и нормализацией громкости. Поддерживаемые форматы: `U8`, `S16`, `S24`, `S32`, `F32`.

### 2. PC Speaker PWM (Аппаратный таймер 2)
- При отсутствии платы Sound Blaster 16 аудиоядро автоматически переключается на встроенный динамик ПК (порты `0x42`, `0x43`, `0x61`).
- Реализован алгоритм **Zero-Crossing Rate Tracker**, анализирующий аудиопоток в реальном времени и генерирующий эквивалентные частоты на системном динамике.

### Программы для работы со звуком:
- `player <file.raw>` — Консольный аудиоплеер для воспроизведения звуковых файлов.
- `test_sb16` — Программа тестирования DSP, DMA и микшера Sound Blaster 16.
- `sound_test` / `audio_test` — Тестирование генератора частот и полифонии.
