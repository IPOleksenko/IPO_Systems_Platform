# Настройка инструментария разработки

Для разработки пользовательских программ под IPO_OS требуются 32-битный x86 компилятор C, ассемблер Netwide Assembler (NASM), утилиты GNU binutils и сборщик Make. Поскольку IPO_OS является независимой bare-metal системой без Linux glibc, программы компилируются в автономном режиме freestanding (`-ffreestanding -m32 -nostdlib`).

---

## 🛠️ Необходимые пакеты

| Инструмент | Минимальная версия | Назначение |
| :--- | :--- | :--- |
| **GCC** (или `i686-elf-gcc`) | 9.0+ | Компиляция 32-битного C кода с флагами freestanding |
| **NASM** | 2.14+ | Ассемблирование x86 подпрограмм и точки входа |
| **GNU binutils** (`ld`, `objcopy`) | 2.30+ | Компоновка и извлечение плоского бинарного файла из ELF |
| **GNU Make** | 4.0+ | Автоматизация многофайловой сборки |
| **Python** | 3.8+ | Запуск утилиты `disk_editor.py` для записи бинарников в образ |

## 📦 Установка в различных операционных системах

### Ubuntu / Debian Linux
В 64-битных версиях Debian и Ubuntu необходимо установить пакет `gcc-multilib` для генерации 32-битного кода:

```bash
sudo apt update
sudo apt install -y build-essential gcc-multilib g++-multilib nasm make python3
```

Проверка поддержки 32-битного режима:
```bash
gcc -m32 -v
nasm -v
```

### Arch Linux / Manjaro
```bash
sudo pacman -S base-devel multilib-devel nasm python
```

### macOS (Apple Silicon / Intel)
Встроенный компилятор Apple Clang не умеет собирать 32-битные ELF бинарники. Требуется установить кросс-компилятор `i686-elf`:

```bash
# Через Homebrew с тап-репозиториями кросс-компиляции
brew install x86_64-elf-binutils nasm

# Либо собрать связку i686-elf-gcc из исходников
```

### Windows (WSL2)
Рекомендуется использовать подсистему **WSL2** с дистрибутивом Ubuntu:
```bash
wsl --install -d Ubuntu
# В консоли WSL:
sudo apt update && sudo apt install -y build-essential gcc-multilib nasm make python3
```

## 📁 Структура каталогов проекта приложения

Каждое приложение для IPO_OS обычно организовано по следующей схеме:

```
my_app/
├── Makefile             # Сборка и создание плоского бинарного файла
├── app.ld               # Скрипт компоновщика (базовый адрес 0x800000)
├── entry.s              # Начальная точка входа, вызывающая main()
├── include/
│   ├── syscall.h        # Номера системных вызовов IPO_OS
│   └── stdio.h          # Заголовочные файлы базового ввода/вывода
└── src/
    └── main.c           # Точка входа приложения
```

## ⚙️ Критические флаги компилятора и линковщика

При компиляции нативного кода для IPO_OS строго обязательны следующие флаги:

```bash
CFLAGS = -m32 \
         -O2 \
         -ffreestanding \
         -fno-pic -fno-pie \
         -fno-builtin \
         -nostdlib -nostartfiles \
         -fno-stack-protector \
         -Wall -Wextra
```

### Обоснование флагов:
- `-m32`: Генерация 32-битных инструкций x86 и 32-битных адресов.
- `-ffreestanding`: Указывает GCC не рассчитывать на окружение стандартной библиотеки C.
- `-fno-pic -fno-pie`: Отключает позиционно-независимый код; бинарник линкуется по фиксированному адресу `0x800000`.
- `-nostdlib -nostartfiles`: Запрещает линковщику подключать стандартные файлы инициализации `crt0.o` и библиотеку `libc.so`.
- `-fno-stack-protector`: Исключает обращения к символам канарейки стека `__stack_chk_fail` операционной системы хоста.
