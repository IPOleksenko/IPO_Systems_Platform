# Користувачский интерфейс, Shell, GUI та Мультимедиа

Операційна система **IPO_OS** предоставляет богатый спектр користувачских интерфейсов:
1. **Консольный терминал Shell:** 27+ встроенных команд, фоновые виртуальные рабочие пространства (`run &`), конвейеры (`|`), история та ANSI-цвета.
2. **Віконний менеджер (Window Manager):** 2D рабочий стол в VGA Mode 13h (320x200x256), оконный композитинг 60 FPS, программный курсор мыши PS/2, события мыши та клавиатуры.
3. **3D Графика TinyGL (OpenGL 1.1):** Программный 3D растеризатор в ядрі, поддержка Z-буфера, освещения, текстурирования та полигональных моделей.
4. **Звуковая подсистема:** Аппаратный драйвер Sound Blaster 16 (DSP, 16-бит DMA, 22050 Гц стерео микшер) та эмуляция PC Speaker PWM.

### ⚡ Многозадачные операторы команди `run`

Команда `run` дозволяє конструировать сложные конвейеры виконання:

```bash
# 1. Оператор '&' — запуск в ОКРЕМИХ віртуальних робочих столах (workspaces)
# Перемикання між робочими столами: Ctrl + Page Up / Ctrl + Page Down
run edit & player & hosting_server

# 2. Оператор '&&' — асинхронний паралельний запуск в ЄДИНОМУ робочому столі
# Дозволяє запустити кілька GUI вікон на одному спільному десктопі
run wm_demo && wm_demo2 && wm_fullscreen

# 3. Оператор '|' — конвеєр (очікує завершення лівої програми та передає код повернення)
run test_sb16 | player sound.raw

# 4. Оператор ';' — послідовне виконання програм
run setfont /fonts/terminus.fnt ; startx
```

### ⌨️ Горячие клавиши терминала
- **`Ctrl + Page Up` / `Ctrl + Page Down`:** Переключение між независимыми виртуальными экранами многозадачности.
- **`Ctrl + Left Shift` / `Ctrl + Right Shift`:** Циклическое переключение активной раскладки клавиатуры.
- **`Alt + Left/Right Shift`:** Альтернативная комбинация смены языка ввода.
- **`Ctrl + C`:** Переривання активного foreground-процесса або закрытие рабочего стола.
- **`Page Up` / `Page Down`:** Прокрутка истории терминала (до 128 рядків scrollback-буфера).
- **`Стрелки Вверх / Вниз`:** Навигация за истории ранее введенных команд.

## 🪟 2. Віконний менеджер (Window Manager)

Віконний менеджер активируется командой `startx` та работает як постоянная асинхронная задача ядра с частотой кадров 60 FPS (тик каждые 16 мс):

### Структура окна (`wm_window_t`)
Каждое окно содержит:
- Собственный пиксельный буфер (`uint8_t *framebuf`) в пам'яті
- Координаты `(x, y)` та розміры `(w, h)`
- Заголовок окна та цветовую палитру (рамка, заголовок, фон)
- Колбэк отрисовки `draw_cb(wm_window_t *win)`
- Колбэк событий `event_cb(wm_window_t *win, uint32_t event, uint32_t data)`

### События віконного менеджера:
- `WM_EVENT_CLICK` — клик левой кнопкой мыши внутри окна
- `WM_EVENT_KEY_DOWN` / `WM_EVENT_KEY_UP` — нажатие та отпускание клавиши
- `WM_EVENT_FOCUS_IN` / `WM_EVENT_FOCUS_OUT` — получение та потеря фокуса ввода
- `WM_EVENT_MOVE` / `WM_EVENT_RESIZE` — перемещение або изменение розміров окна
- `WM_EVENT_CLOSE` — нажатие кнопки закрытия

<Callout type="tip" title="Кнопка аварийного выхода [✕]">
В левом нижнем углу графического экрана завжди отображается системная кнопка `[✕]`. Клик за ней левой кнопкой мыши або нажатие клавиши `ESC` гарантированно завершает графическую сессию та повертає терминал в текстовый режим 80x25.
</Callout>

## 🧊 3. 3D Графический движок TinyGL (OpenGL 1.1)

IPO_OS містить встроенный в ядро программный 3D растеризатор **TinyGL**, реализующий спецификацию OpenGL 1.1 без необходимости наличия аппаратного GPU:

### Возможности TinyGL:
- **Матричные преобразования:** `glMatrixMode(GL_PROJECTION)`, `glLoadIdentity()`, `gluPerspective()`, `glTranslatef()`, `glRotatef()`, `glScalef()`.
- **Геометрические примитивы:** `GL_POINTS`, `GL_LINES`, `GL_TRIANGLES`, `GL_QUADS`, `GL_POLYGON`.
- **Освещение та материалы:** До 8 источников света (`GL_LIGHT0`), расчет диффузного, фонового та зеркального света, нормали вершин `glNormal3f()`.
- **Буфер глубины:** 16-битный аппаратный Z-буфер для корректного видалення невидимых граней.
- **Текстурирование:** Билинейная фильтрация текстур, форматы 2D текстур.
- **Блендинг та прозрачность:** Поддержка `glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA)`.

### Демонстрационные 3D додатки, входящие в состав ОС:
1. `gl_gears` — Классические вращающиеся шестерни OpenGL с расчетом FPS.
2. `gl_teapot` — Знаменитый чайник з Юты (Utah Teapot) с расчетом освещения та нормалей.
3. `gl_cube` — Цветной вращающийся 3D-куб.
4. `gl_fog` — Демонстрация объемного тумана.
5. `gl_blend` — Прозрачные пересекающиеся плоскости.
6. `gl_stencil` — Демонстрация работы с буфером трафарета.

## 🔊 4. Звуковая подсистема (Sound Blaster 16 та PC Speaker)

IPO_OS имеет двухуровневую аудиосистему:

### 1. Sound Blaster 16 (Аппаратный DSP)
- Базовый порт ввода-вывода: `0x220` (сброс, статус, читання, запис).
- 16-битный DMA-контролер: **Канал 5** (порти `0xD4`, `0xD6`, `0xC4`, `0x8B`, `0xC6`).
- Двойная аппаратная буферизация (Ping-Pong DMA buffers за адресиам `0x600000` та `0x610000`).
- Стандартная частота дискретизации: **22050 Гц**, 16-бит, стерео.
- Программный микшер: Одновременное воспроизведение нескольких потоков с автоматическим ресемплингом та нормализацией громкости. Поддерживаемые форматы: `U8`, `S16`, `S24`, `S32`, `F32`.

### 2. PC Speaker PWM (Аппаратный таймер 2)
- При отсутствии платы Sound Blaster 16 аудиоядро автоматически переключается на встроенный динамик ПК (порти `0x42`, `0x43`, `0x61`).
- Реализован алгоритм **Zero-Crossing Rate Tracker**, анализирующий аудиопоток в реальном времени та генерирующий эквивалентные частоты на системном динамике.

### Программы для работы со звуком:
- `player <file.raw>` — Консольный аудиоплеер для воспроизведения звуковых файлів.
- `test_sb16` — Программа тестування DSP, DMA та микшера Sound Blaster 16.
- `sound_test` / `audio_test` — Тестування генератора частот та полифонии.
