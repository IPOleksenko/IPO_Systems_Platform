## ⚙️ 7. Ассемблирование программ с помощью NASM

Netwide Assembler (NASM) портирован на IPO_OS и позволяет транслировать ассемблерный код в исполняемые файлы:

```bash
# 1. Написание ассемблерного исходника
echo '[BITS 32] section .entry global _start _start: mov eax, 0xFFFF int 0x80' > test.asm

# 2. Ассемблирование в ELF
nasm -f elf32 -o test.o test.asm

# 3. Линковка в исполняемый бинарник
ld -T /lib/linker.ld -o test test.o
```
