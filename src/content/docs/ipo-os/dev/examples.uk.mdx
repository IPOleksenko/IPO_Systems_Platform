## ⚙️ 7. Ассемблирование программ с помощью NASM

Netwide Assembler (NASM) портирован на IPO_OS та дозволяє транслировать ассемблерный код в исполняемые файли:

```bash
# 1. Написання асемблерного вихідного коду
echo '[BITS 32] section .entry global _start _start: mov eax, 0xFFFF int 0x80' > test.asm

# 2. Асемблювання в ELF
nasm -f elf32 -o test.o test.asm

# 3. Лінкування у виконуваний бінарник
ld -T /lib/linker.ld -o test test.o
```
