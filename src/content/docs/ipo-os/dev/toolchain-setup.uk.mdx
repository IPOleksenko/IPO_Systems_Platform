# Налаштування инструментария разработки

Для разработки користувацьких програм під IPO_OS требуются 32-битный x86 компилятор C, ассемблер Netwide Assembler (NASM), утилиты GNU binutils та сборщик Make. Поскольку IPO_OS є независимой bare-metal системой без Linux glibc, программы компилируются в автономном режиме freestanding (`-ffreestanding -m32 -nostdlib`).

---

## 🛠️ Необходимые пакети

| Инструмент | Минимальная версия | Назначення |
| :--- | :--- | :--- |
| **GCC** (или `i686-elf-gcc`) | 9.0+ | Компиляция 32-битного C кода с флагами freestanding |
| **NASM** | 2.14+ | Ассемблирование x86 подпрограмм та точки входу |
| **GNU binutils** (`ld`, `objcopy`) | 2.30+ | Компоновка та извлечение плоского бинарного файлу з ELF |
| **GNU Make** | 4.0+ | Автоматизация многофайлівой збирання |
| **Python** | 3.8+ | Запуск утилиты `disk_editor.py` для запису бинарников в образ |

## 📦 Установка в различных операційних системах

### Ubuntu / Debian Linux
В 64-битных версиях Debian та Ubuntu необхідно установить пакет `gcc-multilib` для генерации 32-битного кода:

```bash
sudo apt update
sudo apt install -y build-essential gcc-multilib g++-multilib nasm make python3
```

Перевірка поддержки 32-битного режима:
```bash
gcc -m32 -v
nasm -v
```

### Arch Linux / Manjaro
```bash
sudo pacman -S base-devel multilib-devel nasm python
```

### macOS (Apple Silicon / Intel)
Встроенный компилятор Apple Clang не умеет собирать 32-битные ELF бинарники. Требуется установить кросс-компилятор `i686-elf`:

```bash
# Через Homebrew з тап-репозиторіями крос-компіляції
brew install x86_64-elf-binutils nasm

# Або зібрати зв'язку i686-elf-gcc з вихідних сирців
```

### Windows (WSL2)
Рекомендуется использовать подсистему **WSL2** с дистрибутивом Ubuntu:
```bash
wsl --install -d Ubuntu
# У консолі WSL:
sudo apt update && sudo apt install -y build-essential gcc-multilib nasm make python3
```

## 📁 Структура каталогов проекта додатки

Каждое додаток для IPO_OS обычно организовано за следующей схеме:

```
my_app/
├── Makefile             # Збирання та створення плоского бінарного файлу
├── app.ld               # Скрипт компонувальника (базова адреса 0x800000)
├── entry.s              # Початкова точка входу, що викликає main()
├── include/
│   ├── syscall.h        # Номери системних викликів IPO_OS
│   └── stdio.h          # Заголовні файли базового вводу/виводу
└── src/
    └── main.c           # Точка входу застосунку
```

## ⚙️ Критические флаги компилятора та линковщика

При компиляции нативного кода для IPO_OS строго обязательны следующие флаги:

```bash
CFLAGS = -m32 \
         -O2 \
         -ffreestanding \
         -fno-pic -fno-pie \
         -fno-builtin \
         -nostdlib -nostartfiles \
         -fno-stack-protector \
         -Wall -Wextra
```

### Обоснование флагов:
- `-m32`: Генерация 32-битных инструкций x86 та 32-битных адресиов.
- `-ffreestanding`: Указывает GCC не рассчитывать на окружение стандартной библиотеки C.
- `-fno-pic -fno-pie`: Отключает позиционно-независимый код; бинарник линкуется за фиксированному адресиу `0x800000`.
- `-nostdlib -nostartfiles`: Запрещает линковщику подключать стандартные файли ініціалізації `crt0.o` та библиотеку `libc.so`.
- `-fno-stack-protector`: Исключает обращения до символам канарейки стека `__stack_chk_fail` операційної системи хоста.
