### How Assembly Dispatches System Calls:
1. `push msg`: Pushes the address of the string buffer onto the stack.
2. `mov ecx, esp`: Sets `ECX` to point to the arguments array on the stack.
3. `mov eax, 0x1001`: Sets `EAX` to the system call number (`IPO_SYSCALL_PRINT`).
4. `mov ebx, 1`: Sets `EBX` to the argument count (`1`).
5. `int 0x80`: Triggers the software interrupt trap gate, executing the kernel dispatcher.

## 🔨 3. Compiling the C Application

To compile `main.c`, we need the startup stub `entry.s` and linker script `app.ld`:

```bash
# 1. Compile C source code with freestanding flags
gcc -m32 -O2 -ffreestanding -fno-pie -fno-pic -nostdlib -Isrc/include -c main.c -o main.o

# 2. Assemble entry stub
gcc -m32 -c applications/entry.s -o entry.o

# 3. Compile kernel printf runtime for user applications
gcc -m32 -c src/kernel/stdio/printf.c -o app_printf.o -DIPO_APP -Isrc/include

# 4. Link into temporary ELF binary mapped at 0x800000
gcc -m32 -Wl,-T,applications/app.ld -nostdlib entry.o main.o app_printf.o -o hello.elf

# 5. Extract raw flat binary with initialized .bss
objcopy -O binary --set-section-flags .bss=alloc,load,contents hello.elf hello.bin
```

---

## 🚀 4. Deploying to the Storage Disk

Copy `hello.bin` into the `/applications` directory of your IPO_OS disk:

```bash
python3 disk_editor.py put hello.bin /applications/hello.bin
```

---

## 🖥️ 5. Running in the Shell

Start IPO_OS in QEMU:
```bash
make run
```

At the interactive prompt (`> `), invoke your binary:
```
> /applications/hello.bin
Hello, World!
> /applications/hello.bin test_arg1 test_arg2
Hello, test_arg1
Hello, test_arg2
> 
```
