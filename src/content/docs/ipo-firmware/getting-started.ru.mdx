# Сборка и цепочечная загрузка

В этом руководстве описывается процесс компиляции бинарного образа **IPO_Firmware** и его тестирование в эмуляторе QEMU с различными топологиями накопителей.

---

## 🛠️ Необходимые утилиты

Для сборки IPO_Firmware требуются:
- **NASM 2.14+** (ассемблер Netwide Assembler)
- **Python 3.8+** (для упаковки ROM через `tools/build_rom.py`)
- **GNU Make 4.0+**
- **QEMU** (`qemu-system-i386`)

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y build-essential nasm make python3 qemu-system-x86
```

---

## 🔨 Компиляция IPO_Firmware

В каталоге репозитория `IPO_Firmware`:

```bash
# Сборка образа прошивки
make all
```

Компилируются следующие модули:
- `src/entry.asm` (точка входа по Контракту 2 по адресу `0xF000:0004`)
- `src/ivt.asm` (обработчики таблицы векторов прерываний реального режима)
- `src/pci_scan.asm`, `src/ahci.asm`, `src/nvme.asm` (многошинный поиск накопителей)
- `src/chainload.asm` (чтение сектора 0 и передача управления по Контракту 3)

Цель `make` по умолчанию (`all`) создает временный payload Contract 2 размером менее 32 КБ в `build/.bin/firmware.bin` и упаковывает его в `build/firmware.bin`. Payload встраивается во внешний образ IPO_Boot_ROM только если задан `ROM_BIN` (например, через `make run BOOTROM=path/to/bootrom.bin`); иначе он служит только промежуточным входным файлом для самостоятельного образа BIOS. Размер самостоятельного образа — 256 КБ, а упакованный образ сохраняет размер переданного Boot ROM. Размер образа IPO_Firmware не задается параметром `FLASH_SIZE` из IPO_Boot_ROM.

## 🖥️ Запуск IPO_Firmware в QEMU

Для запуска IPO_Firmware автономно или с образом операционной системы передайте загрузочный образ `build/firmware.bin` в параметр `-bios` (или используйте `make run`):

### 1. Загрузка с классическим накопителем ATA IDE
```bash
qemu-system-i386 \
    -bios build/firmware.bin \
    -drive file=path/to/IPO_OS.img,format=raw,if=ide,index=0 \
    -serial stdio
```
Или напрямую через Makefile проекта:
```bash
make run OS=path/to/IPO_OS.img
```

### 2. Загрузка через контроллер AHCI SATA
```bash
qemu-system-i386 \
    -bios build/firmware.bin \
    -device ahci,id=ahci0 \
    -drive file=path/to/IPO_OS.img,format=raw,if=none,id=disk0 \
    -device ide-hd,bus=ahci0.0,drive=disk0 \
    -serial stdio
```

### 3. Загрузка с современного накопителя NVMe
```bash
qemu-system-i386 \
    -bios build/firmware.bin \
    -drive file=path/to/IPO_OS.img,format=raw,if=none,id=nvm0 \
    -device nvme,serial=IPO_NVME0,drive=nvm0 \
    -serial stdio
```

[IPO_Firmware] Fast A20 Gate activated and verified
[IPO_Firmware] Memory map prepared (E820/E801 ready)
[IPO_Firmware] PS/2 keyboard controller configured (Set 2 -> Set 1 translation)

[IPO_Firmware] Probing drive 0x80
