# Діагностика накопителей та відновлення

Если IPO_Firmware не удаётся обнаружить подключённые жёсткие диски або загрузочный сектор, прошивка записывает код помилки в порт `0x80` та передаёт подробный лог стану оборудования в последовательный порт COM1.

---

## 🛑 Расшифровка кода помилки `0xEE` (`FW_ERR_NO_BOOT`)

Самый распространённый код остановки — **`0xEE`**, означающий, что контролеры накопителей были успішно найдены та настроены, но **ни один з дисків не містить валидного сектора MBR** (сигнатуры `0x55AA` в байте 510).

```
[IPO_Firmware] Сканування накопичувачів на наявність MBR...
  Диск 0x80 (ATA IDE Master): Сектор 0 зчитано, сигнатура = 0x0000 (ПОМИЛКА)
  Диск 0x81 (AHCI Port 0): Сектор 0 зчитано, сигнатура = 0x0000 (ПОМИЛКА)
  Диск 0x82: Не підключений
  Диск 0x83: Не підключений
*** ЗУПИНКА (0xEE): Завантажувальні диски не знайдено! ***
```

### Способы устранения:
1. **Перевірка сигнатуры MBR:** Проверьте нулевой сектор дисківого образа утилитой `hexdump`:
   ```bash
   hexdump -C -n 512 build/IPO_OS.img | tail -n 2
   # Останні два байти ПОВИННІ бути: 55 aa
   ```
2. **Перевірка параметрів запуска QEMU:** Убедитесь, что в рядку запуска присутствует параметр `-drive file=...,format=raw,if=ide`.
3. **Повторная разметка диска:** Заново инициализируйте дисківый образ та запишите завантажувач:
   ```bash
   make disk
   ```

## 🔌 Діагностика аппаратных контролеров

### 1. Таймауты связи портів AHCI
Если зависание происходит на этапе `FW_STORAGE_PROBE` (`0x28`):
- **Причина:** Порт SATA контролера AHCI не фиксирует физический линк (`PxSSTS.DET != 3`).
- **Решение:** Проверьте надёжность підключення SATA-кабелей та подачу питания на накопитель.

### 2. Контролер NVMe не переходить в статус готовности
- **Причина:** Контролер NVMe не выставил флаг готовности `CSTS.RDY = 1` в течение отведённого таймаута регістра `CAP.TO`.
- **Решение:** Убедитесь, что базовый регістр PCIe BAR0 отображён в пам'ять выше 1 МБ та включён бит Bus Mastering в командном регістре PCI.

## 📺 Поведение при отсутствии загрузочного диска

При отсутствии загрузочных носителей прошивка не зависает молча:
1. Выводит POST-код `0xEE` в порт `0x80`.
2. Выводит текстовое предупреждение на экран:
   ```
   ==================================================
     IPO_Firmware: Завантажувальні накопичувачі не знайдено!
     Перевірено диски: 0x80 (IDE), 0x81 (AHCI), 0x82 (NVMe)
     Підключіть накопичувач та натисніть [F1] для повтору.
   ==================================================
   ```
3. Опрашивает переривання клавиатуры (`INT 16h, AH=00h`), позволяя подключить флешку або диск та повторить попытку без выключения питания.
