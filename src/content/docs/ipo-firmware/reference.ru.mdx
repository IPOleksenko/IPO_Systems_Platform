## 🤝 Спецификация Контракта 3 (Firmware $\to$ Загрузчик ОС)

Контракт 3 представляет собой классический стандарт передачи управления сектору MBR в архитектуре PC BIOS.

### 1. Загрузка загрузочного сектора (MBR)
- **Целевой адрес:** Ровно по физическому адресу `0x0000:7C00` (512 байт).
- **Правило валидации:** Байт 510 равен `0x55`, а байт 511 равен `0xAA`. Если значение слова отличается от `0xAA55`, сектор бракуется.

### 2. Состояние регистров CPU при входе (`0x0000:7C00`)

| Регистр | Значение при передаче | Описание |
| :--- | :--- | :--- |
| **`CS:IP`** | `0x0000:0x7C00` | Адрес выполнения в реальном режиме |
| **`DL`** | `0x80` (или `0x81`..`0x83`) | Номер загрузочного BIOS-диска |
| **`SS:SP`** | `0x0000:0x7C00` | Указатель стека расположен безопасно под MBR |
| **`DS`, `ES`**| `0x0000` | Базовые сегменты данных обнулены |
| **`EFLAGS`** | `0x00000202` | **`IF = 1`** (Аппаратные прерывания разрешены) |
| **Линия A20**| **Открыта** | Бит 20 активен; циклическое заворачивание отключено |
| **Таблица IVT**| **Готова** | Прерывания INT 10h–1Ah готовы к вызовам из загрузчика |

## 🗄️ Структура области памяти EBDA (`0x0009FC00`)

Расширенная область данных BIOS занимает 1 КБ непосредственно под границей 640 КБ:

```
Смещение    Размер  Поле                Содержимое
0x0000      8 Б     acpi_rsdp_sig       "RSD PTR "
0x0008      1 Б     checksum            8-битная контрольная сумма RSDP
0x0009      6 Б     oem_id              "IPO   "
0x000F      1 Б     revision            0 (ACPI 1.0)
0x0010      4 Б     rsdt_address        Физический адрес таблицы RSDT (0x0009FC40)
0x0014      44 Б    reserved            Очереди драйверов контроллеров накопителей
```
