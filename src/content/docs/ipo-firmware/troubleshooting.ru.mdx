# Диагностика накопителей и восстановление

Если IPO_Firmware не удаётся обнаружить подключённые жёсткие диски или загрузочный сектор, прошивка записывает код ошибки в порт `0x80` и передаёт подробный лог состояния оборудования в последовательный порт COM1.

---

## 🛑 Расшифровка кода ошибки `0xEE` (`FW_ERR_NO_BOOT`)

Самый распространённый код остановки — **`0xEE`**, означающий, что контроллеры накопителей были успешно найдены и настроены, но **ни один из дисков не содержит валидного сектора MBR** (сигнатуры `0x55AA` в байте 510).

```
[IPO_Firmware] Сканирование накопителей на наличие MBR...
  Диск 0x80 (ATA IDE Master): Сектор 0 считан, сигнатура = 0x0000 (ОШИБКА)
  Диск 0x81 (AHCI Port 0): Сектор 0 считан, сигнатура = 0x0000 (ОШИБКА)
  Диск 0x82: Не подключен
  Диск 0x83: Не подключен
*** ОСТАНОВКА (0xEE): Загрузочные диски не найдены! ***
```

### Способы устранения:
1. **Проверка сигнатуры MBR:** Проверьте нулевой сектор дискового образа утилитой `hexdump`:
   ```bash
   hexdump -C -n 512 build/IPO_OS.img | tail -n 2
   # Последние два байта ОБЯЗАНЫ быть: 55 aa
   ```
2. **Проверка параметров запуска QEMU:** Убедитесь, что в строке запуска присутствует параметр `-drive file=...,format=raw,if=ide`.
3. **Повторная разметка диска:** Заново инициализируйте дисковый образ и запишите загрузчик:
   ```bash
   make disk
   ```

## 🔌 Диагностика аппаратных контроллеров

### 1. Таймауты связи портов AHCI
Если зависание происходит на этапе `FW_STORAGE_PROBE` (`0x28`):
- **Причина:** Порт SATA контроллера AHCI не фиксирует физический линк (`PxSSTS.DET != 3`).
- **Решение:** Проверьте надёжность подключения SATA-кабелей и подачу питания на накопитель.

### 2. Контроллер NVMe не переходит в статус готовности
- **Причина:** Контроллер NVMe не выставил флаг готовности `CSTS.RDY = 1` в течение отведённого таймаута регистра `CAP.TO`.
- **Решение:** Убедитесь, что базовый регистр PCIe BAR0 отображён в память выше 1 МБ и включён бит Bus Mastering в командном регистре PCI.

## 📺 Поведение при отсутствии загрузочного диска

При отсутствии загрузочных носителей прошивка не зависает молча:
1. Выводит POST-код `0xEE` в порт `0x80`.
2. Выводит текстовое предупреждение на экран:
   ```
   ==================================================
     IPO_Firmware: Загрузочные накопители не найдены!
     Проверены диски: 0x80 (IDE), 0x81 (AHCI), 0x82 (NVMe)
     Подключите накопитель и нажмите [F1] для повтора.
   ==================================================
   ```
3. Опрашивает прерывание клавиатуры (`INT 16h, AH=00h`), позволяя подключить флешку или диск и повторить попытку без выключения питания.
