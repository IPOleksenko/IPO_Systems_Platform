## 📋 Таблица векторов прерываний реального режима (IVT)

При старте первый килобайт физической оперативной памяти (`0x0000:0000`..`0x0000:03FF`) заполняется 256 4-байтными дальними указателями `FAR` (`Segment:Offset`), связывающими базовые сервисы прерываний BIOS:

```
Карта памяти IVT (0x00000000 .. 0x000003FF):
Вектор      Адрес           Целевой сервис
INT 10h     0x0000:0x0040   Сервисы видеодисплея (VBIOS и телетайп)
INT 13h     0x0000:0x004C   Сервисы блочного дискового ввода-вывода (CHS и LBA)
INT 15h     0x0000:0x0054   Конфигурация системы и карта памяти (E820)
INT 16h     0x0000:0x0058   Сервисы ввода с клавиатуры (PS/2)
INT 1Ah     0x0000:0x0068   Сервисы часов реального времени (RTC) и таймера
```

## 🗄️ Конфигурация областей BDA и EBDA

### 1. BIOS Data Area (BDA) по адресу `0x0000:0400`
- `0x0400 - 0x0407`: Базовые адреса портов ввода-вывода последовательных портов COM1..COM4.
- `0x0410`: Слово установленного аппаратного оборудования (equipment word).
- `0x0413`: Объём базовой конвенциональной памяти в КБ (обычно `639` или `640`).
- `0x041E - 0x043D`: Кольцевой FIFO-буфер клавиатуры.

### 2. Extended BIOS Data Area (EBDA) по адресу `0x0009FC00`
Зарезервированный сегмент памяти размером 1 КБ, содержащий:
- Структуру ACPI Root System Description Pointer (**RSDP**) (сигнатура `"RSD PTR "`).
- Внутренние структуры состояния драйверов для активных контроллеров накопителей.

## 🔍 Многошинное обнаружение накопителей (`src/pci_scan.asm`)

Написанная на 100% на ассемблере NASM, IPO_Firmware сканирует шины PCI 0..3 через порты ввода-вывода `0x0CF8` (Address) и `0x0CFC` (Data):

```asm
pci_scan_devices:
    ; Сканирует шины PCI 0..3 в поисках критического для загрузки оборудования
    ; Сохраняет флаги обнаруженного оборудования в Scratch RAM (0x0000:0x0540..0x056F)
    mov     byte [es:SCRATCH_AHCI_FOUND], 0
    mov     byte [es:SCRATCH_USB_FOUND], 0
    mov     byte [es:SCRATCH_VGA_FOUND], 0
```

### Сканируемые подсистемы накопителей:
1. **ATA IDE:** Классические контроллеры Parallel ATA на первичных портах `0x1F0` и вторичных `0x170`.
2. **AHCI SATA:** Контроллеры Serial ATA (`pci_class == 0x01:0x06`), настраиваемые через регистры ABAR.
3. **NVMe Express:** Контроллеры PCIe Non-Volatile Memory (`pci_class == 0x01:0x08`), инициализируемые очередями Admin Submission/Completion.
4. **USB EHCI:** Хост-контроллеры, сконфигурированные с протоколом Bulk-Only Transport.

Обнаруженным дискам последовательно присваиваются номера BIOS, начиная с `0x80` (`0x80`, `0x81`, `0x82`).
