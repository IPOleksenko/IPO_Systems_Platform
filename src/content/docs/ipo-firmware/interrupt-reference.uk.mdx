# Довідник переривань BIOS (INT 10h–1Ah)

В этом довіднике описаны программные векторы переривань реального режиму, предоставляемые **IPO_Firmware** системным завантажувачам та программам этапа начального старта.

---

## 📺 INT 10h — Видеосервисы экрана

### `AH = 0Eh` — Телетайпный вывод символа
Выводит ASCII-символ на экран та сдвигает позицию курсора.
- **Вход:** `AH = 0Eh`, `AL = Символ`, `BH = Номер страницы (0)`, `BL = Атрибут цвета`
- **Выход:** Символ отображается на экране та дублируется в порт COM1.

### `AH = 00h` — Установка видеорежима
- **Вход:** `AH = 00h`, `AL = Номер режима` (`03h` = текстовый режим 80x25, 16 цветов).
- **Выход:** Экран очищается та переинициализируется.

### `AX = 4F02h` — Установка режима VESA VBE
- **Вход:** `AX = 4F02h`, `BX = Номер режима VBE | 0x4000` (бит 14 містить линейный буфер LFB).
- **Выход:** `AX = 004Fh` при успешном переключении.

## 💾 INT 13h — Дисковые сервисы

### `AH = 42h` — Расширенное читання LBA
Читання цепочки секторів 512 байт за 64-битному адресиу LBA.

- **Вход:**
  - `AH = 42h`
  - `DL = Номер диска` (`0x80` = Диск 0, `0x81` = Диск 1)
  - `DS:SI = Указатель на структуру пакета адреса диска (DAP)`
- **Выход:**
  - `CF = 0` при успехе, `AH = 0`
  - `CF = 1` при ошибке, `AH = Код ошибки`

```c
struct disk_address_packet {
    uint8_t  packet_size;   /* Розмір структури (завжди 16 / 0x10) */
    uint8_t  reserved;      /* Зарезервовано (0) */
    uint16_t block_count;   /* Кількість секторів для зчитування по 512 байтів */
    uint16_t buffer_offset; /* Зміщення цільового буфера в пам'яті */
    uint16_t buffer_segment;/* Сегмент цільового буфера в пам'яті */
    uint64_t lba_start;     /* Початкова 64-бітна адреса блока LBA */
} __attribute__((packed));
```

### `AH = 02h` — Классическое читання секторів CHS
- **Вход:** `AH = 02h`, `AL = Число секторов`, `CH = Цилиндр (мл)`, `CL = Сектор / Цилиндр (ст)`, `DH = Головка`, `DL = Диск`, `ES:BX = Буфер`.
- **Выход:** `CF = 0` при успехе.

## ⚙️ INT 15h — Системные сервисы та пам'ять

### `AX = E820h` — Опрос карты фізичної пам'яті
Базовый сервис для обнаружения диапазонов оперативної пам'яті:

- **Вход:**
  - `EAX = 0x0000E820`
  - `EBX = Токен продолжения` (начинается с `0`)
  - `ES:DI = Указатель на 24-байтный буфер записи E820`
  - `ECX = Размер буфера` (`20` або `24` байта)
  - `EDX = 0x534D4150` (магическая сигнатура `'SMAP'`)
- **Выход:**
  - `CF = 0` при успехе
  - `EAX = 0x534D4150` (`'SMAP'`)
  - `EBX = Значение токена для следующего вызова` (`0` — конец карты)

```c
struct e820_entry {
    uint64_t base_address;
    uint64_t length;
    uint32_t type;          /* 1 = Доступна RAM, 2 = Зарезервовано, 3 = ACPI */
    uint32_t extended_attr; /* Атрибути ACPI 3.0 */
} __attribute__((packed));
```

### `AX = 2401h` — Открытие вентиля Fast A20
- **Вход:** `AX = 2401h`
- **Выход:** `CF = 0`, `AH = 0` при успехе.

---

## ⌨️ INT 16h — Сервисы клавиатуры

- **`AH = 00h` (Читання клавиши):** Блокирует CPU до нажатия. Возвращает `AH = Сканкод`, `AL = ASCII-символ`.
- **`AH = 01h` (Перевірка буфера):** Неблокирующий вызов. Устанавливает `ZF = 1`, якщо буфер пуст, або `ZF = 0`, якщо символ готов.

---

## ⏱️ INT 1Ah — Часы реального времени RTC

- **`AH = 00h` (Читання счётчика тиков):** Возвращает `CX:DX = Число тиков таймера с полуночи` (18.2 Гц).
- **`AH = 02h` (Читання времени CMOS RTC):** Возвращает `CH = Часы (BCD)`, `CL = Минуты (BCD)`, `DH = Секунды (BCD)`.
