# Збирання та цепочечная загрузка

В этом керівництві описывается процесс компиляции бинарного образа **IPO_Firmware** та его тестування в эмуляторе QEMU с различными топологиями накопителей.

---

## 🛠️ Необходимые утилиты

Для збирання IPO_Firmware требуются:
- **NASM 2.14+** (асемблер Netwide Assembler)
- **Python 3.8+** (для пакування ROM через `tools/build_rom.py`)
- **GNU Make 4.0+**
- **QEMU** (`qemu-system-i386`)

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y build-essential nasm make python3 qemu-system-x86
```

---

## 🔨 Компиляция IPO_Firmware

В каталоге репозитория `IPO_Firmware`:

```bash
# Збирання образу прошивки
make all
```

Компілюються наступні модулі:
- `src/entry.asm` (точка входу за Контрактом 2 за адресою `0xF000:0004`)
- `src/ivt.asm` (обробники таблиці векторів переривань реального режиму)
- `src/pci_scan.asm`, `src/ahci.asm`, `src/nvme.asm` (багатошинний пошук накопичувачів)
- `src/chainload.asm` (читання сектору 0 і передача управління за Контрактом 3)

Ціль `make` за замовчуванням (`all`) створює тимчасовий payload Contract 2 розміром до 32 КБ у `build/.bin/firmware.bin` та пакує його в `build/firmware.bin`. Payload вбудовується у зовнішній образ IPO_Boot_ROM лише якщо задано `ROM_BIN` (наприклад, через `make run BOOTROM=path/to/bootrom.bin`); інакше це лише проміжний вхідний файл для автономного образу BIOS. Розмір автономного образу — 256 КБ, а упакований образ зберігає розмір переданого Boot ROM. Розмір образу IPO_Firmware не задається параметром `FLASH_SIZE` з IPO_Boot_ROM.

## 🖥️ Запуск IPO_Firmware в QEMU

Для запуску IPO_Firmware автономно або з образом операційної системи передайте завантажувальний образ `build/firmware.bin` у параметр `-bios` (або використовуйте `make run`):

### 1. Завантаження з класичним накопичувачем ATA IDE
```bash
qemu-system-i386 \
    -bios build/firmware.bin \
    -drive file=path/to/IPO_OS.img,format=raw,if=ide,index=0 \
    -serial stdio
```
Або безпосередньо через Makefile проєкту:
```bash
make run OS=path/to/IPO_OS.img
```

### 2. Завантаження через контролер AHCI SATA
```bash
qemu-system-i386 \
    -bios build/firmware.bin \
    -device ahci,id=ahci0 \
    -drive file=path/to/IPO_OS.img,format=raw,if=none,id=disk0 \
    -device ide-hd,bus=ahci0.0,drive=disk0 \
    -serial stdio
```

### 3. Завантаження з сучасного накопичувача NVMe
```bash
qemu-system-i386 \
    -bios build/firmware.bin \
    -drive file=path/to/IPO_OS.img,format=raw,if=none,id=nvm0 \
    -device nvme,serial=IPO_NVME0,drive=nvm0 \
    -serial stdio
```
