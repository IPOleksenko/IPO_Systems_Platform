# Обзор и архитектура

**IPO_Firmware** — это независимая реализация System BIOS для архитектуры x86. Работая в традиционной теневой области оперативной памяти материнской платы (`0xF0000`..`0xFFFFF`), прошивка связывает низкоуровневую инициализацию чипсета и загрузчик операционной системы.

## 🚪 Точка входа и Контракт 2

IPO_Firmware получает управление от **IPO_Boot_ROM** по физическому адресу `0xF000:0004` (Контракт 2) после калибровки памяти DRAM и блокировки регистров теневой памяти PAM в режим Read-Only.

На момент входа:
- Процессор находится в **16-битном реальном режиме**.
- Аппаратные прерывания замаскированы (`IF = 0`).
- Указатель стека `%sp` указывает на начальную область в базовой памяти DRAM (`SS:SP = 0x0000:0x7C00`).

## 🎯 Основные задачи IPO_Firmware

1. **Таблица векторов прерываний (IVT):** Инициализация 256 шлюзов прерываний по адресам `0x0000:0000`..`0x0000:03FF` со стандартными сервисами BIOS (`INT 10h` Видео, `INT 13h` Диск, `INT 15h` Память, `INT 16h` Клавиатура).
2. **Области данных BIOS:** Размещение структуры BDA (256 байт по адресу `0x0000:0400`) и расширенной области EBDA по адресу `0x0009FC00`.
3. **Активация линии A20:** Открытие вентиля Fast A20 через порт `0x92` для снятия ограничений реального режима на адресацию памяти выше 1 МБ.
4. **Многошинное обнаружение накопителей:** Сканирование шины PCI (`0xCF8`/`0xCFC`) для поиска контроллеров накопителей (ATA IDE, AHCI, NVMe, USB BOT) и их регистрация с номерами дисков `0x80`, `0x81` и т.д.
5. **Передача управления по Контракту 3:** Загрузка нулевого сектора (MBR) с первого загрузочного накопителя по адресу `0x0000:7C00`, валидация сигнатуры `0x55AA` и прыжок с регистром `%dl = 0x80`.
