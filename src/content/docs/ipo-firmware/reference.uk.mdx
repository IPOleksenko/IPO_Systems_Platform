## 🤝 Спецификация Контракта 3 (Firmware $\to$ Завантажувач ОС)

Контракт 3 представляет собой классический стандарт передачі керування сектору MBR в архитектуре PC BIOS.

### 1. Загрузка загрузочного сектора (MBR)
- **Целевой адреси:** Ровно за физическому адресиу `0x0000:7C00` (512 байт).
- **Правило валидации:** Байт 510 равен `0x55`, а байт 511 равен `0xAA`. Если значення слова отличается від `0xAA55`, сектор бракуется.

### 2. Стан регістров CPU при входе (`0x0000:7C00`)

| Регістр | Значення при передаче | Описание |
| :--- | :--- | :--- |
| **`CS:IP`** | `0x0000:0x7C00` | Адреса виконання в реальному режимі |
| **`DL`** | `0x80` (или `0x81`..`0x83`) | Номер загрузочного BIOS-диска |
| **`SS:SP`** | `0x0000:0x7C00` | Вказівник стека розташований безопасно під MBR |
| **`DS`, `ES`**| `0x0000` | Базовые сегменты данных обнулены |
| **`EFLAGS`** | `0x00000202` | **`IF = 1`** (Аппаратные переривання разрешены) |
| **Линия A20**| **Открыта** | Бит 20 активен; циклическое заворачивание отключено |
| **Таблица IVT**| **Готова** | Прерывания INT 10h–1Ah готовы до вызовам з завантажувача |

## 🗄️ Структура области пам'яті EBDA (`0x0009FC00`)

Расширенная область данных BIOS занимает 1 КБ безпосередньо під границей 640 КБ:

```
Зміщення    Розмір  Поле                Вміст
0x0000      8 Б     acpi_rsdp_sig       "RSD PTR "
0x0008      1 Б     checksum            8-бітна контрольна сума RSDP
0x0009      6 Б     oem_id              "IPO   "
0x000F      1 Б     revision            0 (ACPI 1.0)
0x0010      4 Б     rsdt_address        Фізична адреса таблиці RSDT (0x0009FC40)
0x0014      44 Б    reserved            Черги драйверів контролерів накопичувачів
```
