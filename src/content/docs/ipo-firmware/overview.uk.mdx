# Огляд та архитектура

**IPO_Firmware** — це независимая реализация System BIOS для архитектуры x86. Работая в традиционной теневой области оперативної пам'яті материнської плати (`0xF0000`..`0xFFFFF`), прошивка связывает низкоуровневую ініціалізацію чипсета та завантажувач операційної системи.

## 🚪 Точка входу та Контракт 2

IPO_Firmware получает управление від **IPO_Boot_ROM** за физическому адресиу `0xF000:0004` (Контракт 2) після калибровки пам'яті DRAM та блокировки регістров тіньової пам'яті PAM в режим Read-Only.

На момент входа:
- Процесор знаходиться в **16-битном реальному режимі**.
- Аппаратные переривання замаскированы (`IF = 0`).
- Вказівник стека `%sp` вказує на початкову область у базовій пам'яті DRAM (`SS:SP = 0x0000:0x7C00`).

## 🎯 Основные задачи IPO_Firmware

1. **Таблица векторов переривань (IVT):** Ініціалізація 256 шлюзов переривань за адресиам `0x0000:0000`..`0x0000:03FF` со стандартными сервисами BIOS (`INT 10h` Видео, `INT 13h` Диск, `INT 15h` Пам'ять, `INT 16h` Клавиатура).
2. **Области данных BIOS:** Размещение структури BDA (256 байт за адресиу `0x0000:0400`) та расширенной области EBDA за адресиу `0x0009FC00`.
3. **Активация линии A20:** Открытие вентиля Fast A20 через порт `0x92` для снятия ограничений реального режиму на адресиацию пам'яті выше 1 МБ.
4. **Многошинное обнаружение накопителей:** Сканирование шини PCI (`0xCF8`/`0xCFC`) для поиска контролеров накопителей (ATA IDE, AHCI, NVMe, USB BOT) та их регістрация с номерами дисків `0x80`, `0x81` та т.д.
5. **Передача керування за Контракту 3:** Загрузка нулевого сектора (MBR) с первого загрузочного накопителя за адресиу `0x0000:7C00`, валидация сигнатуры `0x55AA` та прыжок с регістром `%dl = 0x80`.
