# Команды сборки и запуск в QEMU

В этой инструкции рассматривается компиляция **IPO_Boot_ROM** из исходных текстов, создание комбинированных образов для микросхем SPI Flash и запуск эмуляции в QEMU.

---

## 🛠️ Необходимые утилиты

Для сборки IPO_Boot_ROM требуются:
- **NASM 2.14+** (Netwide Assembler)
- **GNU Make 4.0+**
- **Python 3.8+** (для выравнивания размеров и расчёта контрольных сумм)

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y nasm make python3 qemu-system-x86
```

---

## 🔨 Сборка бинарного образа Boot ROM

В корневом каталоге проекта `IPO_Boot_ROM`:

```bash
# 1. Компиляция чистого ассемблерного образа
make all
```

Сценарий компилирует:
- `src/reset.asm` (16 байт, строго по смещению `0xFFFFFFF0`)
- `src/car.asm` (настройка Cache-as-RAM через MTRR)
- `src/host_bridge.asm` (динамическое определение CPU и Host Bridge, настройка и блокировка теневой памяти PAM)
- `src/mrc.asm` (определение объема DRAM по расширенным параметрам CMOS, резервное значение 64 МБ и настройка регистров DRAM в Host Bridge)
- `src/payload_call.asm` (валидация сигнатуры прошивки 'IPO' и переход по Контракту 2)

Результат сборки: `build/bootrom.bin` (настраиваемый размер через `FLASH_SIZE`, по умолчанию 4 МБ / 4 194 304 байт) и промежуточные файлы в `build/.bin/`.

---

## 🧩 Формирование единого образа для SPI Flash

По умолчанию команда `make` генерирует `build/bootrom.bin` с размером Flash 4 МБ. `FLASH_SIZE` должен быть не менее 64 КиБ и кратен 16 байтам; размер полезной нагрузки прошивки ограничен 32 КиБ. Для интеграции внешнего бинарника прошивки передайте `FIRMWARE=path/to/firmware.bin`:

```bash
# Сборка 4 МБ Boot ROM со встроенной полезной нагрузкой прошивки
make FIRMWARE=../IPO_Firmware/build/.bin/firmware.bin FLASH_SIZE=4M
```

## 🖥️ Запуск и тестирование в QEMU

Запустить IPO_Boot_ROM можно через параметр `-bios` в QEMU:

```bash
# Тестирование автономного Boot ROM
qemu-system-i386 -bios build/bootrom.bin -serial stdio
```
