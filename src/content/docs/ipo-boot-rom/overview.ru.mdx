# Обзор и вектор аппаратного сброса

**IPO_Boot_ROM** — это программный код первого этапа (ROM-код), который исполняется процессором непосредственно в момент подачи питания или снятия сигнала сброса (RESET#). Находясь на физическом чипе SPI NOR Flash ROM, он выполняет начальную инициализацию кремния и оперативной памяти DRAM.

## ⚡ Аппаратный вектор сброса (`0xFFFFFFF0`)

При выходе процессора x86 из состояния сброса:
- Процессор стартует в **16-битном реальном режиме**, однако базовый адрес теневого дескриптора сегмента кода CS установлен в `0xFFFF0000`.
- Регистр указателя инструкций (`%eip`) инициализируется значением `0x0000FFF0`.
- Первая инструкция процессора всегда считывается по физическому адресу:
**Reset Vector** = `0xFFFF0000` + `0x0000FFF0` = `0xFFFFFFF0`
(за 16 байт до верхней границы 4-гигабайтного адресного пространства 32-битного процессора).

```
Верх 4 ГБ адресного пространства
0xFFFFFFFF +------------------------------------------+
           | 16-байтная зона вектора сброса           |
0xFFFFFFF0 |  -> jmp bootrom_cold_entry (0xFFFF8000)  |  <- Старт CPU
           +------------------------------------------+
           | Физический чип памяти SPI Flash ROM      |
           | (Бинарный образ IPO_Boot_ROM)            |
0xFFF00000 +------------------------------------------+
```

## 🎯 Ключевые задачи IPO_Boot_ROM

1. **Идентификация CPU:** Чтение и вывод строки модели процессора через CPUID; проверка совместимости архитектуры не выполняется.
2. **Настройка Cache-as-RAM (CAR):** Конфигурирование регистров MTRR для организации временного стека в кэше L1/L2 процессора до старта оперативной памяти.
3. **Динамическое определение CPU и Host Bridge:** Вывод модели CPU через CPUID и чтение производителя, устройства и ревизии Host Bridge на шине PCI 0, устройство 0, функция 0 (`0xCF8`/`0xCFC`). Определение использует текущие значения, а не фиксированный список ID; i440FX (`0x8086:0x1237`) и Q35 (`0x8086:0x29C0`) приведены как примеры.
4. **Инициализация DRAM (MRC):** Чтение объема памяти из расширенных параметров CMOS (резервное значение — 64 МБ) и настройка регистров DRAM в Host Bridge. Текущая реализация не выполняет тест памяти с шаблонами.
5. **Теневая память PAM (Shadow RAM):** Разблокировка регистров Programmable Attribute Map, копирование прошивки в область `0xF0000`..`0xFFFFF` и перевод в режим Read-Only.
6. **Передача управления по Контракту 2:** Проверка сигнатуры `'IPO'` (`0x004F5049`) и дальний прыжок на адрес `0xF000:0004`.
