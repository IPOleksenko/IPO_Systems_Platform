## 🤝 Спецификация Контракта 2 (Boot ROM $\to$ Firmware)

Контракт 2 определяет бинарные соглашения при передаче управления от IPO_Boot_ROM к IPO_Firmware в теневой памяти PAM.

### 1. Расположение в памяти и формат заголовка
Бинарный образ прошивки должен располагаться в сегменте `0xF000` со следующим 16-байтным заголовком:

```
Адрес           Смещение Поле           Значение
0x000F0000      0x00     magic          0x004F5049 ("IPO" в ASCII)
0x000F0004      0x04     entry_point    Инструкция дальнего прыжка (jmp start)
0x000F0008      0x08     payload_size   uint32_t размер прошивки в байтах
0x000F000C      0x0C     checksum       uint32_t аддитивная контрольная сумма
```

### 2. Состояние регистров CPU при передаче управления (`0xF000:0004`)

| Регистр | Ожидаемое значение на входе |
| :--- | :--- |
| **`CS:IP`** | `0xF000:0x0004` (Реальный режим адресации) |
| **`EAX`** | Не определён контрактом передачи Contract 2. |
| **`EBX`** | Не определён контрактом передачи Contract 2. |
| **`SS:SP`** | `0x0000:0x7C00` |
| **`SS`** | `0x0000` |
| **`DS`, `ES`** | `0x0000` |
| **`EFLAGS`** | Флаг `IF` сброшен; значения остальных флагов контрактом не заданы. |
| **Статус PAM** | PAM0 настроен с `WE = 0`, `RE = 1`; регистр не считывается обратно для проверки. |
