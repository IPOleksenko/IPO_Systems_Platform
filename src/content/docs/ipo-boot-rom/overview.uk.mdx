# Огляд та вектор апаратного скидання

**IPO_Boot_ROM** — це программный код первого этапа (ROM-код), який исполняется процесором безпосередньо у момент подачи питания або снятия сигнала сброса (RESET#). Находясь на физическом чипе SPI NOR Flash ROM, он выполняет начальную ініціалізацію кремния та оперативної пам'яті DRAM.

## ⚡ Аппаратный вектор сброса (`0xFFFFFFF0`)

При выходе процесора x86 з стану сброса:
- Процесор стартует в **16-битном реальному режимі**, однако базовый адреси теневого дескриптора сегмента кода CS установлен в `0xFFFF0000`.
- Регістр вказівника инструкций (`%eip`) инициализируется значенням `0x0000FFF0`.
- Первая инструкция процесора завжди считывается за физическому адресиу:
**Reset Vector** = `0xFFFF0000` + `0x0000FFF0` = `0xFFFFFFF0`
(за 16 байт до верхней границы 4-гигабайтного адресиного пространства 32-битного процесора).

```
Верх 4 ГБ адресного простору
0xFFFFFFFF +------------------------------------------+
           | 16-байтова зона вектора скидання          |
0xFFFFFFF0 |  -> jmp bootrom_cold_entry (0xFFFF8000)  |  <- Старт CPU
           +------------------------------------------+
           | Фізичний чип пам'яті SPI Flash ROM      |
           | (Бінарний образ IPO_Boot_ROM)            |
0xFFF00000 +------------------------------------------+
```

## 🎯 Ключевые задачи IPO_Boot_ROM

1. **Самотестування CPU:** Перевірка инструкций CPUID, архитектурных флагов.
2. **Налаштування Cache-as-RAM (CAR):** Конфигурирование регістров MTRR для организации временного стека в кэше L1/L2 процесора до старта оперативної пам'яті.
3. **Визначення чипсета:** Сканирование моста PCI Host Bridge (`0xCF8`/`0xCFC`) для идентификации контролера (Intel i440FX `0x8086:0x1237` або Q35 `0x8086:0x29C0`).
4. **Ініціалізація DRAM (MRC):** Налаштування регістров контролера пам'яті та калибровка таймингов шини пам'яті DDR.
5. **Тіньова пам'ять PAM (Shadow RAM):** Разблокировка регістров Programmable Attribute Map, копирование прошивки в область `0xF0000`..`0xFFFFF` та перевод в режим Read-Only.
6. **Передача керування за Контракту 2:** Перевірка сигнатуры `'IPOF'` (`0x464F5049`) та дальний прыжок на адреси `0xF000:0004`.
