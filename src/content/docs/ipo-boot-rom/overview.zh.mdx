# 概述与设计理念 & 复位向量

**IPO_Boot_ROM** is the very first piece of software executed by the central processing unit upon power-on or hardware reset. Residing physically on a SPI NOR Flash ROM chip, it brings bare-metal silicon from cold uninitialized transistors to operational system RAM.

## ⚡ The Hardware 复位向量 (`0xFFFFFFF0`)

When an x86 processor comes out of reset (RESET# pin de-asserted):
- The CPU starts in **16-bit 实模式**, but with hidden descriptor cache base address set to `0xFFFF0000`.
- The Instruction Pointer (`%eip`) is initialized to `0x0000FFF0`.
- Therefore, the very first instruction fetch occurs at physical address:
**复位向量** = `0xFFFF0000` + `0x0000FFF0` = `0xFFFFFFF0`
(16 bytes below the top of 32-bit physical address space).

```
Top of 4 GB Memory Space
0xFFFFFFFF +------------------------------------------+
           | 16-byte Reset Vector Area                |
0xFFFFFFF0 |  -> jmp bootrom_cold_entry (0xFFFF8000)  |  <- CPU starts here
           +------------------------------------------+
           | Physical SPI Flash ROM Contents          |
           | (IPO_Boot_ROM binary payload)            |
0xFFF00000 +------------------------------------------+
```

## 🎯 Primary Responsibilities

1. **CPU Early Self-Test:** Read CPUID, verify architecture compatibility, clear flags.
2. **Cache-as-RAM (CAR):** Configure CPU MTRRs to establish an execution stack in L1/L2 cache without requiring DRAM.
3. **Chipset Identification:** Probe Host-to-PCI Bridge (`0xCF8`/`0xCFC`) to identify chipset (e.g. Intel i440FX `0x8086:0x1237` or Q35 `0x8086:0x29C0`).
4. **Memory 技术参考手册 Code (MRC):** Initialize DRAM controller registers and perform read/write bit-pattern training.
5. **影子内存 (Shadow RAM) Configuration:** Unlock Programmable Attribute Map (PAM) registers, copy firmware payload to `0xF0000`..`0xFFFFF`, lock as read-only.
6. **Contract 2 Handover:** Verify firmware magic signature `'IPOF'` (`0x464F5049`) and jump to `0xF000:0004`.
