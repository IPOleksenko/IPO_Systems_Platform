# Build Commands & QEMU

This guide covers building the **IPO_Boot_ROM** payload from source code, creating composite SPI Flash images, and testing ROM initialization inside QEMU.

---

## 🛠️ Build Prerequisites

Compiling IPO_Boot_ROM requires:
- **NASM 2.14+** (Netwide Assembler)
- **GNU Make 4.0+**
- **Python 3.8+** (for ROM concatenation and checksum padding)

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y nasm make python3 qemu-system-x86
```

---

## 🔨 Building the Boot ROM Binary

Inside the `IPO_Boot_ROM` project root:

```bash
# 1. Compile pure assembly ROM image
make all
```

This compiles:
- `src/reset.asm` (16 bytes placed strictly at `0xFFFFFFF0`)
- `src/car.asm` (Cache-as-RAM MTRR configuration)
- `src/mrc_440fx.asm, src/mrc_q35.asm` (DRAM training code)
- `src/chipset.asm, src/payload_call.asm` (PAM chipset shadowing and Contract 2 handover)

Outputs: `build/bootrom.bin` (configurable via `FLASH_SIZE`, default 4 MB / 4,194,304 bytes).

---

## 🧩 Criação de uma imagem unificada de SPI Flash

Por padrão, o `make` cria uma única imagem unificada `build/bootrom.bin` (padrão de 4 MB, pronta para chips SPI Flash físicos como W25Q32 ou QEMU). Tamanhos padrão e não padrão são suportados (`FLASH_SIZE=256K`, `FLASH_SIZE=4M`, `FLASH_SIZE=8M`). Para incorporar uma carga útil de firmware externa, passe `FIRMWARE=path/to/firmware.bin`:

```bash
# Compilar Boot ROM de 4 MB com carga útil de firmware incorporada
make FIRMWARE=../IPO_Firmware/build/firmware.bin FLASH_SIZE=4M
```

```
4 MB SPI Flash Memory Layout (bootrom.bin):
0x00000000 +---------------------------------------------------+
           | Free / Reserved Flash Storage (3968 KB)           |
0x003F0000 +---------------------------------------------------+
           | IPO_Firmware Payload Slot (32 KB, offset -64 KB)  |
0x003F8000 +---------------------------------------------------+
           | IPO_Boot_ROM Init Code (32 KB, offset -32 KB)     |
0x003FFFF0 | Reset Vector JMP (16 bytes, offset -16 B)         |
0x00400000 +---------------------------------------------------+
```

## 🖥️ Running Emulation in QEMU

You can test IPO_Boot_ROM directly using QEMU's `-bios` parameter:

```bash
# Test standalone Boot ROM
qemu-system-i386 -bios build/bootrom.bin -serial stdio
```
