## 🤝 Спецификация Контракта 2 (Boot ROM $\to$ Firmware)

Контракт 2 определяет бинарные соглашения при передачі керування від IPO_Boot_ROM до IPO_Firmware в тіньової пам'яті PAM.

### 1. Расположение в пам'яті та формат заголовка
Бинарный образ прошивки має располагаться в сегменте `0xF000` со следующим 16-байтным заголовком:

```
Адреса          Зміщення Поле           Значення
0x000F0000      0x00     magic          0x004F5049 ("IPO" в ASCII)
0x000F0004      0x04     entry_point    Інструкція далекого стрибка (jmp start)
0x000F0008      0x08     payload_size   uint32_t розмір прошивки в байтах
0x000F000C      0x0C     checksum       uint32_t адитивна контрольна сума
```

### 2. Стан регістров CPU при передачі керування (`0xF000:0004`)

| Регістр | Ожидаемое значення на входе |
| :--- | :--- |
| **`CS:IP`** | `0xF000:0x0004` (Реальний режим адресиации) |
| **`EAX`** | Не визначено контрактом передачі Contract 2. |
| **`EBX`** | Не визначено контрактом передачі Contract 2. |
| **`SS:SP`** | `0x0000:0x7C00` |
| **`SS`** | `0x0000` |
| **`DS`, `ES`** | `0x0000` |
| **`EFLAGS`** | Прапорець `IF` скинуто; значення інших прапорців контрактом не визначені. |
| **Статус PAM** | PAM0 налаштовано з `WE = 0`, `RE = 1`; регістр не зчитується назад для перевірки. |
