# Діагностика та аппаратные сбои

На реальних материнських платах збої можуть проявлятися чорним екраном або зупиненням завантаження. Поточний код виводить як звичайні маркери поступу через порт `0x80` лише `0x12` і `0x13`; перелічені нижче константи помилок не обов'язково виводяться.

---

## 🛑 Расшифровка кодов помилок порту 0x80

| Hex-код | Обозначення | Причина та способ устранения |
| :--- | :--- | :--- |
| **`0x2E`** | `POST_ERR_NO_CAR` | Defined CAR setup failure code; this does not establish that the current code performs an MTRR capability check. |
| **`0x3E`** | `POST_ERR_UNKNOWN_CS` | Defined constant; current code reports raw PCI host-bridge IDs and does not reject unknown IDs. |
| **`0x4E`** | `POST_ERR_DRAM_FAIL` | Defined constant; current MRC configures DRAM controller registers and does not run a pattern test. |
| **`0x7E`** | `POST_ERR_FW_MAGIC` | Defined constant; current mismatch handling reports a diagnostic and halts without emitting POST code `0x7E`; check the payload at `0xF000:0000`. |

---

## ⚡ Аппаратные сценарии діагностики

### 1. Индикатор порту 0x80 пуст (плата не стартует)
Если плата не выдаёт никаких POST-кодов:
1. **Отсутствует вектор сброса:** Верхние 16 байт чипа SPI (`0xFFFFFFF0`..`0xFFFFFFFF`) не містять валидной команди JMP. Убедитесь, что розмір файлу прошивки в точности равен ёмкости микросхемы (наприклад, 4 194 304 байт для 4 МБ).
2. **Качество пайки / контакта:** При использовании панельки або клипсы проверьте отсутствие замыканий між соседними ножками.
3. **Питание микросхемы:** Замерьте напряжение дежурной линии 3.3V (`+3VSB`) на ножке 8 (VCC) микросхемы флеш-пам'яті.

## 🔬 Перевірка шини SPI осциллографом або логическим анализатором
- **Пин 1 (/CS - Chip Select):** При нажатии кнопки Power/Reset має кратковременно опуститься в логический ноль. Если остаётся высоким, чипсет не инициирует читання ROM.
- **Пин 6 (CLK - Тактовый сигнал):** Наличие серий прямоугольных тактовых импульсов (20–50 МГц).
- **Пин 5 (DI / MOSI):** Передача команди читання `0x03` або Fast Read `0x0B`.
- **Пин 2 (DO / MISO):** Поток данных, возвращаемый чипом SPI в южный мост / PCH.
