# Build Commands & QEMU

This guide covers building the **IPO_Boot_ROM** payload from source code, creating composite SPI Flash images, and testing ROM initialization inside QEMU.

---

## 🛠️ Build Prerequisites

Compiling IPO_Boot_ROM requires:
- **NASM 2.14+** (Netwide Assembler)
- **GCC & GNU Binutils** (`gcc -m32`, `ld -m elf_i386` for 32-bit XIP `romstage`)
- **GNU Make 4.0+**
- **Python 3.8+** (for ROM concatenation and checksum padding)

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y nasm make python3 qemu-system-x86
```

---

## 🔨 Building the Boot ROM Binary

Inside the `IPO_Boot_ROM` project root:

```bash
# 1. Compile pure assembly ROM image
make all
```

This compiles:
- `src/reset.asm` (16 bytes placed strictly at `0xFFFFFFF0`)
- `src/car.asm` (32 KiB Cache-as-RAM MTRR setup + `.car_bypass` fallback)
- `src/romstage.c` / `src/romstage_mrc.c` (32-bit Flash-XIP C hardware & MRC stage)
- `src/host_bridge.asm` (Dynamic CPU & Host Bridge discovery, PAM Shadow RAM configuration and locking)
- `src/mrc.asm` (DRAM size detection from CMOS extended-memory registers, with a 64 MB fallback, and host-bridge DRAM register configuration)
- `src/payload_call.asm` (Firmware magic validation & Contract 2 handover)

Outputs: `build/bootrom.bin` (configurable via `FLASH_SIZE`, default 4 MB / 4,194,304 bytes) and intermediate binaries in `build/.bin/`.

---

## 🧩 Packaging Unified SPI Flash Image

By default, `make` builds `build/bootrom.bin` with a 4 MB flash size. `FLASH_SIZE` must be at least 128 KiB with XIP `romstage` (IEC suffix: `128KiB`..`16MiB`); the bank firmware slot holds 56 KiB (plus extended mode up to 65,520 B). To embed an external firmware payload, pass `FIRMWARE=path/to/firmware.bin`:

```bash
# Build 4 MB Boot ROM with embedded firmware payload
make FIRMWARE=../IPO_Firmware/build/.bin/firmware.bin FLASH_SIZE=4MiBiB
```

```
4 MB SPI Flash Memory Layout (bootrom.bin):
0x00000000 +---------------------------------------------------+
           | 32-bit XIP romstage (phys 4 GiB - FLASH_SIZE) & Free Flash           |
0x003F0000 +---------------------------------------------------+
           | IPO_Firmware Bank Slot (56 KiB, offset -64 KiB)   |
0x003FE000 +---------------------------------------------------+ +---------------------------------------------------+
           | IPO_Boot_ROM Init Code (8 KiB bootblock, offset -8 KiB)     |
0x003FFFF0 | Reset Vector JMP (16 bytes, offset -16 B)         |
0x00400000 +---------------------------------------------------+
```

## 🖥️ Running Emulation in QEMU

You can test IPO_Boot_ROM directly using QEMU's `-bios` parameter:

```bash
# Test standalone Boot ROM
qemu-system-x86_64 -bios build/bootrom.bin -serial stdio
```
