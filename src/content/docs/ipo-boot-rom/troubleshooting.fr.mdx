# Diagnostics & Hardware Failures

On physical motherboards, failures may appear as a black screen or a halted boot. The current code emits only `0x12` and `0x13` as normal Port `0x80` progress markers; the error constants listed below are not necessarily emitted.

---

## 🛑 Decoding Port 0x80 Codes d'erreur

| Hex Code | Meaning | Root Cause & Resolution |
| :--- | :--- | :--- |
| **`0x2E`** | `POST_ERR_NO_CAR` | Defined CAR setup failure code; this does not establish that the current code performs an MTRR capability check. |
| **`0x3E`** | `POST_ERR_UNKNOWN_CS` | Defined constant; current code reports raw PCI host-bridge IDs and does not reject unknown IDs. |
| **`0x4E`** | `POST_ERR_DRAM_FAIL` | Defined constant; current MRC configures DRAM controller registers and does not run a pattern test. |
| **`0x7E`** | `POST_ERR_FW_MAGIC` | Defined constant; current mismatch handling reports a diagnostic and halts without emitting POST code `0x7E`; check the payload at `0xF000:0000`. |

## ⚡ Hardware Dépannage Scenarios

### 1. No Port 0x80 Codes at All (Completely Dead)
If a motherboard shows no codes on a PCI/LPC diagnostic card:
1. **Vecteur de réinitialisation Missing:** The top 16 bytes of the SPI flash chip (`0xFFFFFFF0`..`0xFFFFFFFF`) do not contain a valid JMP instruction. Verify your binary image size matches the physical chip capacity (e.g. exactly 4,194,304 bytes for a 4 MB chip).
2. **Chip Soldering / Contact:** If you desoldered the SPI chip or used a clip, inspect for solder bridges across adjacent pins.
3. **Power Rail Failure:** Verify that the 3.3V standby rail (`+3VSB`) reaches Pin 8 (VCC) of the flash chip when power is plugged in.

---

### 2. Oscilloscope / Logic Analyzer Checks
When troubleshooting custom boards:
- **Pin 1 (/CS - Chip Select):** Must pulse low upon releasing the motherboard reset switch. If it stays high continuously, the chipset's SPI controller has not started reading the ROM.
- **Pin 6 (CLK - Clock):** Should exhibit active square wave clock bursts (typically 20 MHz to 50 MHz).
- **Pin 5 (DI / MOSI):** Carries the standard SPI Read command (`0x03` or Fast Read `0x0B`).
- **Pin 2 (DO / MISO):** Carries the byte data returned by the SPI Flash chip to the chipset.
