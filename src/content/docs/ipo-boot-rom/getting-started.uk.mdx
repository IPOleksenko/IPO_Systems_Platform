# Команды збирання та запуск в QEMU

В цієї инструкции рассматривается компиляция **IPO_Boot_ROM** з исходных текстов, створення комбинированных образов для микросхем SPI Flash та запуск эмуляции в QEMU.

---

## 🛠️ Необходимые утилиты

Для збирання IPO_Boot_ROM требуются:
- **NASM 2.14+** (Netwide Assembler)
- **GNU Make 4.0+**
- **Python 3.8+** (для выравнивания розміров та расчёта контрольных сумм)

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y nasm make python3 qemu-system-x86
```

---

## 🔨 Збирання бинарного образа Boot ROM

В корневом каталоге проекта `IPO_Boot_ROM`:

```bash
# 1. Компіляція чистого асемблерного образу
make all
```

Сценарий компилирует:
- `src/reset.asm` (16 байт, строго за смещению `0xFFFFFFF0`)
- `src/car.asm` (налаштування Cache-as-RAM через MTRR)
- `src/mrc_440fx.asm, src/mrc_q35.asm` (ініціалізація контролера DRAM)
- `src/chipset.asm, src/payload_call.asm` (копирование в тіньову пам'ять PAM та переход за Контракту 2)

Результат збирання: `build/bootrom.bin` (розмір налаштовується через `FLASH_SIZE`, за замовчуванням 4 МБ / 4 194 304 байтів).

---

## 🧩 Формування єдиного образу для SPI Flash

За замовчуванням команда `make` створює єдиний готовий бінарний образ `build/bootrom.bin` (за замовчуванням 4 МБ, готовий для прошивки у фізичні чипи SPI Flash, такі як W25Q32, або для QEMU). Підтримуються будь-які розміри флеш-пам'яті через параметр `FLASH_SIZE` (наприклад, `FLASH_SIZE=256K`, `FLASH_SIZE=4M`, `FLASH_SIZE=8M`). Для інтеграції зовнішнього бінарного файлу прошивки вкажіть `FIRMWARE=path/to/firmware.bin`: 

```bash
# Збирання 4 МБ Boot ROM із вбудованим корисним навантаженням прошивки
make FIRMWARE=../IPO_Firmware/build/firmware.bin FLASH_SIZE=4M
```

```
Карта пам'яті 4 МБ SPI Flash (bootrom.bin):
0x00000000 +---------------------------------------------------+
           | Вільна / Зарезервована область (3968 КБ)          |
0x003F0000 +---------------------------------------------------+
           | Слот корисного навантаження IPO_Firmware (32 КБ)  |
0x003F8000 +---------------------------------------------------+
           | Код ініціалізації IPO_Boot_ROM (32 КБ)            |
0x003FFFF0 | Точка входу скидання Reset Vector JMP (16 байтів) |
0x00400000 +---------------------------------------------------+
```

## 🖥️ Запуск та тестування в QEMU

Запустить IPO_Boot_ROM можна через параметр `-bios` в QEMU:

```bash
# Тестування автономного Boot ROM
qemu-system-i386 -bios build/bootrom.bin -serial stdio
```
