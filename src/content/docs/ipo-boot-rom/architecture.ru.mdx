# Настройка CAR, MRC и теневой памяти PAM

До того как физическая память DRAM сможет сохранить хотя бы один байт данных, процессор x86 обязан выполнить тысячи инструкций инициализации. **IPO_Boot_ROM** координирует эту сложнейшую цепочку действий.

## ⚡ Этап 1: Механика Cache-as-RAM (CAR)

На современных процессорах внешняя память DRAM требует сложной калибровки алгоритмами MRC. Чтобы получить возможность вызывать подпрограммы на языке C и использовать стек до включения DRAM, внутренний кэш L1/L2 процессора переводится в режим временной оперативной памяти (CAR).

### Последовательность настройки MTRR:
1. **Отключение кэширования:** Сброс битов `CD` (Cache Disable) и `NW` (Not Write-through) в регистре `%cr0`.
2. **Конфигурация MSR MTRRdefType (`0x2FF`):**
   - Сброс бита MTRR Enable (Бит 11) для временного отключения активных правил.
   - Установка типа по умолчанию в Uncacheable (`UC`, тип `0x00`).
3. **Настройка переменного регистра MTRR 0 (`MTRRphysBase0` `0x200`, `MTRRphysMask0` `0x201`):**
   - Base = `0x70000` (Режим Write-Back `0x06`).
   - Mask = `0xFFFF8800` (Valid bit 11 set; creates 32 KB window) (Установлен валидный бит 11; задаёт окно кэширования размером 32 КБ (0x70000..0x77FFF, SS:SP = 0x7000:0x8000)).
4. **Включение MTRR:** Установка бита 11 в регистре `MTRRdefType`.
5. **Инициализация области CAR нулями:** Выполнение `rep stosd` по адресам `0x70000`..`0x77FFF`. Так как активен режим Write-Back, процессор аллоцирует строки кэша L1/L2 без обращений к внешней шине памяти!
6. **Установка указателя стека:**
```asm
mov esp, 0x8000   ; Полноценный C-стек внутри кэша CPU!
```

## 🧠 Этап 2: Инициализация памяти (MRC) и тренировка DRAM

Имея рабочий стек в CAR, IPO_Boot_ROM определяет чипсет и настраивает контроллер оперативной памяти:

1. **Идентификация моста Host-to-PCI:**
   - Чтение Vendor/Device ID с шины 0, устройства 0, функции 0 (`0x0CF8` / `0x0CFC`).
   - `0x8086:0x1237` $\to$ Intel i440FX (чипсет PCI/IDE).
   - `0x8086:0x29C0` $\to$ Intel Q35 (чипсет PCI Express).
2. **Конфигурация регистров DRAM:** Установка параметров строк/колонок, задержек CAS Latency и счетчиков регенерации.
3. **Проверка ячеек памяти:**
   - Запись чередующихся битовых шаблонов (`0x55AA55AA` и `0xAA55AA55`).
   - Считывание и подтверждение отсутствия битовых ошибок.

## 🛡️ Этап 3: Теневая память PAM и Контракт 2

После проверки физической памяти DRAM:

1. **Разблокировка регистров PAM:** Регистры Programmable Attribute Map (например, PAM0 чипсета i440FX, регистр `0x59`) управляют сегментом BIOS `0xF0000`..`0xFFFFF`:
   - Устанавливаются биты `WE = 1` (Разрешена запись) и `RE = 1` (Разрешено чтение).
2. **Копирование полезной нагрузки:** Полезная нагрузка `IPO_Firmware` копируется из окна SPI ROM (`0xFFFE0000`) в физическую память RAM по адресу `0x000F0000`.
3. **Перенос стека:** Регистр `%esp` перенаправляется из Cache-as-RAM в физическую конвенциональную память (например, `0x00007C00`).
4. **Сброс CAR:** Отключение регистра MTRR 0 и выполнение инструкции `wbinvd` (Write-Back and Invalidate Cache).
5. **Блокировка PAM в Read-Only:** Конфигурация PAM0 с `WE = 0` (Защита от записи) и `RE = 1` (Чтение из теневой RAM).
6. **Переход по Контракту 2:** Проверка сигнатуры `'IPOF'` (`0x464F5049`) по смещению `0xF000:0000` и дальний переход на точку входа:
```asm
jmp 0xF000:0004       ; Вход в IPO_Firmware (Контракт 2)
```
